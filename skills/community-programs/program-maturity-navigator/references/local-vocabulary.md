# 本地词汇 / Local vocabulary

**这份文件由使用者填写。** 里面的名字属于某个学校或社群的本地制度，不是通用概念。
skill 本身不依赖这些名字，只依赖主干三段与两个轴。

## 怎么填

每行一个名字，四列都要有。**「定义来源」写空着，就说明这个名字还不能用**。

| 本地名称 | 在本地指什么 | 对应的通用位置 | 定义来源 |
|---|---|---|---|
| 学长课堂 | <由使用者填> | 种子 / 孵化 | <谁定的、写在哪> |

| Catena | <由使用者填> | 系列 | |

## Leminar

**目前没有定义，当作空槽留着。**

不要根据字面猜一个。"Lecture 加 Seminar"是猜测，不是定义——
按猜的定义去设计活动，参与者会来到一场和名字不符的活动里。

需要用到它时，向使用者要三样：

1. 参与者在这个形式里**要做什么**
2. 它和 Seminar 的**区别在哪一条**
3. 谁定的、写在哪儿

拿到之后填进上表，并在 Catena Map 里用 `format: custom` 加 `format_note` 记下规则。

## 两条纪律

**一、名字不构成证据。** 一个活动叫「Catena」不等于它到了系列阶段。
位置由痕迹判，见 SKILL.md 第二节。

**二、不要把外校做法写成本地条件。** 别的学校的 Incubator 怎么运作，
和这里的 Incubator 是什么，是两个问题。查不到就写「待确认」。
