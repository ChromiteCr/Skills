# 理想化对照表 / Idealization catalog

题面里每一句"忽略"「视为」「理想」，都是把一段真实物理关掉。这份表回答两个问题：
**关掉的是什么机制**，**在什么条件下这个开关会失灵**。

用法：`competition-scenario-extractor` 逐条标注题面的理想化；
`problem-formalization-coach` 把它们登记成假设；
`physics-mechanism-decomposer` 在机制排序时把被关掉的项拿回来重新比一遍量级。

**表里的"破坏判据"都是无量纲比。** 判据的定义见 `dimensionless-groups.md`。
门槛值是经验分界，不是精确临界值，**结论对该项敏感时必须实算而不是查门槛**。

## 1. 力学

| 理想化 | 关掉的机制 | 破坏判据 | 什么时候必须打开 |
|---|---|---|---|
| 忽略空气阻力 | 黏性阻力与压差阻力 | 阻力功 / 重力功；低速小球看 `Re = ρvd/μ` | 下落时间接近终端速度时间尺度；轻而大的物体（羽毛、气球、纸片）；`Re ≪ 1` 时阻力 `∝ v`，`Re ≫ 10³` 时 `∝ v²`，两者的终端速度对直径的幂次不同（`v_t ∝ d²` 与 `v_t ∝ √d`） |
| 忽略摩擦 | 界面耗散、滚动阻力 | 摩擦功 / 特征能量；`tanθ` 与 `μ_s` 的接近程度 | 斜面角接近 `arctan μ_s`；多次往返累积耗散；测周期这种对耗散不敏感的量则可先忽略 |
| 质点 / 细杆 / 轻绳 | 转动惯量、有限尺寸上的力矩分布、绳的质量与波传播 | 物体尺度 `L` / 运动尺度 `R`；绳质量 / 系统质量 | 需要角动量或转动方程时；绳很长很重时张力沿绳变化 |
| 忽略浮力 | 排开流体的重力 | `ρ_fluid / ρ_body` | 空气中对金属约 `10⁻⁴`，可忽略；空气中对泡沫、水中对任何固体都不行 |
| 刚性 / 不可形变 | 弹性储能、应力波传播 | 形变量 / 尺度；过程时间 / 声波穿越时间 `L/c_s` | 碰撞细节、接触时间、应力集中 |
| 忽略地球自转 | 科里奥利力与离心修正 | 罗斯贝数 `Ro = U/(fL)`，`f = 2Ω sinφ` | 大尺度长时间（气旋、洋流、远程弹道、傅科摆）；实验室尺度 `Ro ≫ 1`，可忽略 |
| 恒定重力 `g` | `g` 随高度与纬度的变化 | `h/R_E`；纬度差 | 高空、卫星、长基线重力测量 |
| 完全弹性 / 完全非弹性碰撞 | 中间程度的恢复系数 | `e = v'_rel / v_rel` 实测值 | 两个极端都要求证据；不测 `e` 就说"近似弹性"是无依据的 |

## 2. 流体与连续介质

| 理想化 | 关掉的机制 | 破坏判据 | 什么时候必须打开 |
|---|---|---|---|
| 无黏 | 黏性耗散与边界层 | `Re` | 任何贴壁问题；分离与尾流；`Re` 大也**不能**在边界层内忽略黏性 |
| 不可压 | 密度随压强变化 | `Ma`，密度相对变化 `≈ Ma²/2` | `Ma ≳ 0.3`；声学问题本身就在研究这一项 |
| 忽略表面张力 | 界面能 | 邦德数 `Bo = ρgL²/σ`；韦伯数 `We = ρU²L/σ` | 尺度接近毛细长度 `√(σ/ρg)`（水约 2.7 mm）；液滴、气泡、薄膜、润湿 |
| 定常流动 | 时间导数项 | 斯特劳哈尔数 `St = fL/U` | 有周期性脱涡（圆柱绕流 `Re` 约 300–2×10⁵ 时 `St ≈ 0.2`）；启动与停止阶段 |
| 层流 | 湍流输运 | `Re`（圆管过渡约 2300） | 过渡与湍流区的阻力、混合、传热都换成另一套标度 |
| 连续介质 | 分子离散性 | 克努森数 `Kn = λ/L` | `Kn ≳ 0.01` 开始滑移，`≳ 1` 完全失效：稀薄气体、微通道、高真空 |

## 3. 热学

| 理想化 | 关掉的机制 | 破坏判据 | 什么时候必须打开 |
|---|---|---|---|
| 理想气体 | 分子体积与分子间引力 | `b/V_m`、`a/(V_m RT)`；或对比压强与对比温度 | 高压、低温、近临界、蒸汽即将凝结 |
| 准静态 | 弛豫未完成 | 德博拉数 `De = τ_relax / τ_process`，准静态要求 `De ≪ 1` | 快速压缩、爆炸、快速开关；注意"快到绝热"和"慢到准静态"是**互相矛盾**的两个要求，必须分别算时间尺度 |
| 绝热 | 漏热 | 过程时间 / 热扩散时间 `L²/α`；或 `Q_leak/Q_process` | 慢过程、导热良好的容器、小体积大表面 |
| 忽略辐射换热 | 斯特藩–玻尔兹曼项 | `h_r/h_conv`，`h_r = εσ(T² + T_s²)(T + T_s)` | 高温；真空或自然对流很弱时辐射可能是主导 |
| 温度均匀（集总参数） | 内部温度梯度 | 毕渥数 `Bi = hL/k_s ≲ 0.1` | 厚的、导热差的物体 |
| 忽略相变潜热 | 熔化/汽化/凝结吸放热 | 潜热 / 显热 `= L/(c_p ΔT)` | 水的汽化潜热约等于把水从 0 °C 加热到 100 °C 所需热量的五倍多，凡涉及蒸发就不能忽略 |
| 常物性 | `μ`、`k`、`c_p`、`ρ` 随温度变化 | 物性在温区两端的相对变化 | 大温差；气体的 `μ` 与 `k` 随 `T` 显著上升 |

## 4. 电磁与波动

| 理想化 | 关掉的机制 | 破坏判据 | 什么时候必须打开 |
|---|---|---|---|
| 无限长导线 / 无限大平板 | 边缘效应 | 边缘尺度 / 特征尺度，如平行板电容器的 `d/L` | 极板间距接近极板尺寸；实测电容总比理想公式大 |
| 集总电路 | 传播延迟与分布参数 | 器件尺度 / 波长 `L/λ` | 高频、长线、天线 |
| 理想导线（零电阻） | 焦耳损耗 | 线阻 / 负载阻值 | 大电流、长导线、低阻负载 |
| 忽略自感 / 互感 | 感生电动势 | `ωL/R`；回路面积与磁通变化率 | 快速开关、大回路、变压器附近；此时 KVL 本身不成立 |
| 静电屏蔽完全 | 趋肤效应有限深度 | 壁厚 / 趋肤深度 `δ = √(2/(ωμσ))` | 低频磁屏蔽尤其困难 |
| 单色光 | 光谱宽度与相干长度 | 光程差 / 相干长度 `l_c ≈ λ²/Δλ` | 白光干涉只能看到几级条纹 |
| 几何光学 | 衍射 | 孔径 / 波长 | 小孔、细缝、望远镜分辨极限 |
| 小振幅 / 线性 | 非线性项 | 振幅 / 特征尺度；`θ²/6`（`sinθ ≈ θ` 的相对误差） | 大振幅摆、非线性光学、大振幅声波 |

## 5. 标注格式

在提取阶段，每条理想化写成一行：

```
原文 | 关掉的机制 | 破坏判据（无量纲比） | 本题条件下的量级 | 结论：可忽略 / 需保留 / 待确认
```

**"本题条件下的量级"填不出来时写【缺失】，不要跳过这一列直接判可忽略。**
题面说"忽略 X"是出题人给的条件，属于【题面】；
但"因此 X 确实可忽略"是一个需要论证的结论，属于【推断】。这两件事不要混。
