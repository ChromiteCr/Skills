# 定律适用条件表 / Law applicability table

**用一条定律，就必须能说出它在这里为什么成立。** 这份表给的是每条常用定律的成立条件，
以及它最常被悄悄破坏的方式。写"由动量守恒"而不写"因为碰撞期间外力冲量相对内力冲量可忽略"，
就是把条件跳过去了。

供 `problem-formalization-coach`、`problem-representation-scout`、
`reference-frame-choice-guide`、`physics-mechanism-decomposer` 按需加载。

## 1. 力学

| 定律 | 成立条件 | 高频的悄悄破坏 |
|---|---|---|
| `F = ma` | 惯性系；**质量恒定**的质点或刚体质心 | 变质量系统（火箭、堆积的链条、漏沙小车）必须回到 `F_ext = dp/dt` 并单独处理被抛出/并入物质携带的动量；直接写 `F = m(t)a` 是错的 |
| `F_ext = dp/dt` | 惯性系；系统边界固定 | 边界随时间变时，要写清哪部分物质在系统内 |
| 动量守恒 | 合外力为零，或**某个方向**上分量为零 | "碰撞瞬间守恒"的真正前提是：碰撞时间 `Δt` 内外力冲量 `F_ext Δt` 远小于动量变化量。碰撞很慢或外力很大（如带弹簧的缓冲）时这条不成立 |
| 机械能守恒 | 只有保守力做功；约束力不做功 | 滑动摩擦、非弹性形变、绳突然绷直、完全非弹性碰撞。**静摩擦不做功只在接触点无相对滑动时成立**（纯滚动可以，打滑不行） |
| 角动量定理 `dL/dt = τ_ext` | 参考点是**惯性系中的固定点**，或系统**质心**（质心加速也成立） | 换到一个加速的、非质心的点，会多出一项 `−M R×A`；绕不同点算力矩却共用一个 `L` |
| 角动量守恒 | 上述参考点下合外力矩为零 | 只在某个轴的分量守恒，被当成矢量守恒 |
| 柯尼希定理 `T = ½MV_cm² + T_rel` | 恒成立（分解，不是近似） | 把 `T_rel` 忘掉，或在非惯性系里直接套用 |
| 刚体定轴 `τ = Iα` | 定轴转动；`I` 对**该轴**计算 | 轴在动、或用了对质心的 `I` 却绕别的轴写方程；平行轴定理 `I = I_cm + Md²` 只适用于**平行**轴 |
| 纯滚动 `v_cm = ωR` | 接触点无相对滑动 | 打滑临界点前后是两个阶段，不能一条方程用到底 |
| 胡克定律 `F = −kx` | 小形变、线弹性区 | 超出弹性极限、橡胶类高分子（非线性且有滞回）、弹簧自身质量不可忽略时 |
| 简谐近似 | 势能在平衡点附近可截断到二阶 `U ≈ ½U''x²` | `U'' = 0` 的平衡点（此时是四次势，周期与振幅有关）；大振幅 |
| 小角近似 `sinθ ≈ θ` | 相对误差 `≈ θ²/6` | 单摆周期的一阶修正是 `T ≈ T₀(1 + θ₀²/16)`，`θ₀ = 30°` 时已偏 1.7 % |

## 2. 流体

| 定律 | 成立条件 | 高频的悄悄破坏 |
|---|---|---|
| 伯努利方程 | 定常 + 不可压 + 无黏 + **沿同一条流线**（流动无旋时才能跨流线用同一常数） | 管路有摩擦损失、有泵或风扇做功、有流动分离、有热交换、跨越激波 |
| 连续性 `ρ₁A₁v₁ = ρ₂A₂v₂` | 定常、单一进出口 | 有储存（非定常）、有分支 |
| 不可压近似 | `Ma ≲ 0.3`（此时密度相对变化 `≈ Ma²/2 ≈ 4.5 %`） | 高速气流、爆炸、声学中的密度扰动本身就是研究对象 |
| 静压 `p = ρgh` | 静止、密度均匀、重力场均匀 | 加速的容器（等压面不再水平）、分层流体、大高度差的大气 |
| 斯托克斯阻力 `F = 6πμRv` | 球体、`Re ≪ 1`、无界流体 | `Re ≳ 1` 后阻力律换成二次型；靠近壁面时系数变化 |
| 连续介质假设 | `Kn = λ/L ≲ 0.01` | 稀薄气体、微纳尺度通道、真空系统 |

## 3. 热学

| 定律 | 成立条件 | 高频的悄悄破坏 |
|---|---|---|
| 热力学第一定律 `ΔU = Q − W` | **恒成立** | 但 `W = ∫p dV` 只在准静态（系统内压强处处有定义且等于外压）下成立；自由膨胀不能这么算 |
| 理想气体 `pV = nRT` | 分子体积与分子间作用可忽略：`b/V_m ≪ 1` 且 `a/(V_m RT) ≪ 1` | 高压、低温、近临界点 |
| 等温/绝热过程公式 | 准静态；绝热还要求真的隔热且过程足够快于漏热 | "很快所以绝热"和"很慢所以准静态"是**互相冲突**的两个要求，必须分别用时间尺度论证 |
| 熵增 `ΔS ≥ 0` | 孤立系统 | 非孤立系统要连同环境一起算 |
| 牛顿冷却 `Q̇ = hA(T − T_∞)` | `h` 在所考察温差内近似常数 | 自然对流下 `h` 本身依赖 `ΔT`；辐射项在大温差下不能并进常数 `h` |
| 集总参数（物体内部温度均匀） | `Bi = hL/k ≲ 0.1` | 厚导热差的物体，内部温度梯度不可忽略 |
| 辐射 `Q̇ = εσA(T⁴ − T_s⁴)` | 灰体、已知发射率、视角因子为 1 | 发射率随温度和表面状态变；几何遮挡；等效换热系数 `h_r = εσ(T² + T_s²)(T + T_s)` 只是把它线性化的记号，不是新物理 |

## 4. 电磁

| 定律 | 成立条件 | 高频的悄悄破坏 |
|---|---|---|
| 高斯定律 `∮E·dA = Q_enc/ε₀` | **恒成立**（麦克斯韦方程之一） | 但**用它解出 `E` 需要足够的对称性**。没有对称性时定律照样成立却解不出来，这不是定律失效 |
| 安培环路定律 `∮B·dl = μ₀I_enc` | **恒定电流** | 电容器充电、任何随时间变化的场，必须补位移电流 `μ₀ε₀ ∂Φ_E/∂t` |
| 法拉第定律 `ε = −dΦ/dt` | 恒成立 | 回路自身在变形/移动时，要说清 `Φ` 是对哪个回路算的；"通量法"和"动生 `∫(v×B)·dl`"必须二选一，不能相加 |
| 基尔霍夫电压定律 | 准静态：回路**不被变化的磁通穿过** | 有互感、变压器、高频、大回路面积时 KVL 不成立，必须写成法拉第定律 |
| 欧姆定律 `U = IR` | 线性元件，温度稳定 | 灯丝（`R` 随 `T` 变）、二极管、气体放电、超导 |
| 库仑定律 | 静止点电荷；真空或均匀线性各向同性介质 | 运动电荷（要用推迟势与磁场）；介质非线性或有极化历史 |
| 静电屏蔽 | 导体内部静电平衡 | 变化场下屏蔽效果由趋肤深度 `δ = √(2/(ωμσ))` 决定，不是无条件的 |
| 集总电路近似 | 器件尺度 `≪` 波长 | 高频信号线、天线：必须用传输线或场的语言 |

## 5. 波动与光学

| 定律 | 成立条件 | 高频的悄悄破坏 |
|---|---|---|
| 叠加原理 | 介质线性 | 大振幅、非线性光学、激波 |
| 斯涅尔定律 | 界面平整（起伏 `≪ λ`）、线性介质、给定波长 | 粗糙面（散射）；色散介质下每个波长的 `n` 不同 |
| 几何光学 | 结构尺度 `≫ λ` | 孔径接近波长时必须用衍射 |
| 光程差干涉条件 | 相干、偏振方向有重叠、光程差 `<` 相干长度 | 白光的相干长度只有几个波长量级 |
| 经典多普勒公式 | `v ≪ c`，且**声源与观察者的速度要分别代入**（介质提供优先参考系） | 光的多普勒不能用声学公式——真空中没有介质，必须用相对论形式 |

## 6. 什么时候不能再用非相对论、非量子的写法

| 判据 | 门槛 | 后果 |
|---|---|---|
| `β = v/c` | `β = 0.1` 时 `γ − 1 ≈ 0.50 %`；`β = 0.5` 时 `≈ 15 %` | 动能必须写 `(γ−1)mc²`；速度不再相加 |
| 引力红移 / 时空曲率 | `GM/(rc²)` | 地表约 `7×10⁻¹⁰`，GPS 必须修正，地面实验通常不必 |
| 德布罗意波长 `λ = h/p` 与体系尺度之比 | `λ/L` 不小时 | 必须用量子力学 |
| 热涨落 `k_BT` 与能级间距之比 | `k_BT ≪ ΔE` 时自由度冻结 | 双原子分子室温下振动自由度冻结，`C_V` 不是 `7R/2` |
| 简并度 `nλ_T³` | `≳ 1` | 玻尔兹曼统计失效，要用费米/玻色统计 |

## 7. 使用方式

在 `problem-formalization-coach` 的定律台账里，每条定律至少填三格：

```
定律 | 用在哪一步 | 本题为什么满足它的条件 | 如果条件被破坏，先失效的是哪个结论
```

第三格写不出来，就说明这一步还没想清楚，不要往下推。
