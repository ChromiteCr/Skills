# 物理证据契约 / Physics evidence contract

`physics` 分类下所有 skill 共用的标注规则。任何一条进入推导、估算或结论的量，
都必须带一个状态标签；标签随交接保留，除非出现新证据。

Shared by every skill under `physics/`. Every quantity that enters a derivation,
an estimate or a conclusion carries a status tag.

## 1. 状态标签 / Status tags

| 标签 | 含义 | 附带要求 |
|---|---|---|
| **【题面】** | 原题、附件或实验记录明确给出 | 写出处（第几问、哪张表、哪行日志） |
| **【使用者提供】** | 使用者补充，原始材料没写 | 不自动升级为【题面】 |
| **【定义】** | 由定义直接得到，不是物理内容 | 例：`a ≡ dv/dt`、`ρ ≡ m/V` |
| **【标准值】** | 公认常数或材料参数 | 必须写来源与查阅日期；见第 3 节 |
| **【推断】** | 由上下文推出 | 写明依据，以及什么证据能推翻它 |
| **【估算】** | 数量级估计 | 写明估法与所用锚点；只能写成 `~10^n` |
| **【待确认】** | 存在两个以上合理解释 | 写明不同解释会改变什么 |
| **【缺失】** | 后续步骤必需，但材料里没有 | 写明缺了它哪一步做不下去 |

**"教科书上都这么做"不能把【推断】升级为【题面】。** 常见做法说明的是习惯，不是本题条件。

## 2. 有效数字与精度纪律 / Significant figures

1. **乘除**：结果的有效位数不超过输入中最少的那一个。**加减**：看小数位而不是有效位。
2. `10 m` 与 `10.0 m` 不是同一条件。题面写 `10 m` 时不要报 `10.00 m` 的结果。
3. 中间结果多留 1–2 位防止舍入累积，但**最终结果必须退回到输入允许的位数**。
4. 数量级估算只写 `~10^n` 或 `几×10^n`。写成 `3.74×10^n` 是把估算冒充成计算。
5. 常数取值的位数不构成精度上限——**精度由测量量决定**，不由你抄了几位 `π` 决定。
6. 不确定度不写成"大概差不多"。给不出不确定度就说给不出，标【缺失】。

## 3. 物理常数 / Physical constants

**不要把测量得到的常数写死在 skill 或输出里。** 写死的数值会随平差版本变化，
而且掩盖了"这是查来的"这个事实。规则是：**引用即注明来源与查阅日期**。

2019 年 SI 重新定义后，下面七个是**定义值，精确无误差**，可以直接用：

| 常数 | 值（精确） |
|---|---|
| 真空光速 `c` | 299 792 458 m·s⁻¹ |
| 普朗克常数 `h` | 6.626 070 15 × 10⁻³⁴ J·s |
| 元电荷 `e` | 1.602 176 634 × 10⁻¹⁹ C |
| 玻尔兹曼常数 `k_B` | 1.380 649 × 10⁻²³ J·K⁻¹ |
| 阿伏伽德罗常数 `N_A` | 6.022 140 76 × 10²³ mol⁻¹ |
| 铯 133 超精细跃迁频率 `Δν_Cs` | 9 192 631 770 Hz |
| 发光效率 `K_cd` | 683 lm·W⁻¹ |

由此 `R = N_A k_B` 也是精确值。**标准重力加速度 `g_n` = 9.806 65 m·s⁻² 是约定值，不是当地实测值**——
需要当地 `g` 时按纬度和海拔查表或实测，标【标准值】并写出处。

`G`、`ε₀`、`μ₀`、`m_e`、`α` 等仍是**测量值**：用时查 CODATA 最新平差，写上版本年份。
其中 `G` 是所有基本常数里相对不确定度最大的一个（约 10⁻⁵ 量级），
凡结论对 `G` 敏感的，必须把这一点写进不确定度讨论。

材料参数（`μ`、`σ`、`k`、`C_p`、`n`、密度）**强依赖温度、压强、成分与表面状态**。
引用时必须连同状态条件一起写：`水 20 °C, 1 atm: μ ≈ 1.00 × 10⁻³ Pa·s`。
只写"水的黏度"而不写温度，等于没写。

## 4. 学术诚信边界 / Academic integrity

`physics/` 下的 skill 是**拆解与检查工具，不是答题机**。统一边界：

- 不给出使用者应当自己完成的最终答案、完整推导或可直接提交的解答。
- 不虚构数据、实验结果、文献、常数值或"典型值"。查不到就标【缺失】。
- 不把使用者的催促当作某个解释已被确认。
- 使用者明确说明是自学、复盘或已交卷后的理解，可以把讲解做深；
  但**仍然不代写将以本人名义提交的内容**。
- 竞赛（IYPT、物理竞赛、科研项目）场景下，机制排序、参考系选择、假设清单
  属于参赛者本人的智力产出，本 skill 只提供结构和检查项。

## 5. 交接格式 / Handoff

skill 之间交接时只携带三段，不携带推理日志：

```markdown
## 已确认
<可供下游直接使用的条目，逐条带状态标签>

## 暂定
<【推断】与【估算】，各写依据和被推翻的条件>

## 未解决
<【待确认】与【缺失】，各写它挡住了哪一步>
```
