# 无量纲数与标度 / Dimensionless groups and scaling

一个无量纲数就是**两个机制的比**。把机制排序变成算比值，是开放问题里最可靠的一步。
这份表给定义、它在比什么、以及常用的经验门槛。

供 `physics-mechanism-decomposer` 主要使用，`competition-scenario-extractor` 与
`reference-frame-choice-guide` 按需引用。

## 1. 白金汉 π 定理 / Buckingham π

`n` 个有量纲的物理量、量纲矩阵的**秩**为 `k`，则可构造 `n − k` 个独立无量纲组。

三条常被弄错的地方：

1. **`k` 是量纲矩阵的秩，不是"出现了几个基本量纲"。** 若 `M` 只在 `ρ` 一个量里出现且总以 `ρ` 的同一幂次出现，实际秩会低于表面上的量纲数。做题时**把矩阵写出来求秩**，不要数字母。
2. **π 定理定不了无量纲系数。** 它给结构 `Π₁ = f(Π₂, Π₃, …)`，`f` 的形状要靠实验、渐近分析或求解方程得到。得到 `T ∝ √(L/g)` 之后那个 `2π` 不是量纲分析给的。
3. **漏掉一个相关量，结论就错。** 单摆周期用 `{T, L, g}` 得到 `T ∝ √(L/g)`，把振幅 `θ₀`（本身无量纲）算进去后正确形式是 `T = √(L/g)·f(θ₀)`——**无量纲的自变量不受 π 定理约束，必须靠物理判断补进去**。

## 2. 流体

| 数 | 定义 | 比的是 | 门槛与备注 |
|---|---|---|---|
| 雷诺 `Re` | `ρUL/μ = UL/ν` | 惯性 / 黏性 | 圆管过渡约 2300；绕流边界层在 `Re` 大时仍然是黏性主导区 |
| 弗劳德 `Fr` | `U/√(gL)` | 惯性 / 重力 | 另有 `Fr = U²/(gL)` 的定义，**引用时必须写明用的是哪一个** |
| 韦伯 `We` | `ρU²L/σ` | 惯性 / 表面张力 | 液滴破碎、喷雾 |
| 邦德（厄特沃什）`Bo`/`Eo` | `ρgL²/σ` | 重力 / 表面张力 | `Bo = 1` 定义毛细长度 `√(σ/ρg)`，水约 2.7 mm |
| 毛细 `Ca` | `μU/σ` | 黏性 / 表面张力 | 涂布、润湿动力学 |
| 奥内佐格 `Oh` | `μ/√(ρσL) = √We / Re` | 黏性 / √(惯性·表面张力) | 与速度无关，只由流体与尺度决定 |
| 马赫 `Ma` | `U/c_s` | 惯性 / 可压缩性 | `Ma ≲ 0.3` 时密度相对变化 `≈ Ma²/2 ≈ 4.5 %` |
| 克努森 `Kn` | `λ/L` | 分子平均自由程 / 尺度 | `≳ 0.01` 滑移，`≳ 1` 连续介质失效；`Kn ∝ Ma/Re` |
| 斯特劳哈尔 `St` | `fL/U` | 非定常 / 对流 | 圆柱脱涡 `Re` 约 300–2×10⁵（阻力危机之前）时 `St ≈ 0.2` |
| 斯托克斯数 `Stk` | `τ_p U/L`，`τ_p = ρ_p d²/(18μ)` | 颗粒惯性 / 跟随流体 | `Stk ≪ 1` 颗粒跟随流线；`≫ 1` 直线穿过 |

## 3. 传热与传质

| 数 | 定义 | 比的是 | 门槛与备注 |
|---|---|---|---|
| 普朗特 `Pr` | `ν/α = c_p μ/k` | 动量扩散 / 热扩散 | 空气 ≈ 0.71，水（20 °C）≈ 7，液态金属 `≪ 1` |
| 施密特 `Sc` | `ν/D` | 动量扩散 / 质扩散 | `Pr` 的传质对应物 |
| 刘易斯 `Le` | `α/D = Sc/Pr` | 热扩散 / 质扩散 | 湿空气过程 |
| 佩克莱 `Pe` | `UL/α`（热）或 `UL/D`（质） | 对流 / 扩散 | `Pe = Re·Pr` 或 `Re·Sc`；`Pe ≪ 1` 时扩散主导 |
| 努塞尔 `Nu` | `hL/k_fluid` | 总换热 / 纯导热 | **分母是流体导热系数** |
| 毕渥 `Bi` | `hL/k_solid` | 外部换热 / 内部导热 | **分母是固体导热系数**；`Bi ≲ 0.1` 才能用集总参数。`Nu` 与 `Bi` 形式相同、含义完全不同，是高频混淆点 |
| 傅里叶 `Fo` | `αt/L²` | 已进行的热扩散 / 尺度 | 无量纲时间；`Fo ~ 1` 时热已穿透 |
| 格拉晓夫 `Gr` | `gβΔT L³/ν²` | 浮力 / 黏性 | 自然对流 |
| 瑞利 `Ra` | `gβΔT L³/(να) = Gr·Pr` | 浮力驱动 / 耗散 | 两刚性平板间对流起始临界值约 1708 |
| 埃克特 `Ec` | `U²/(c_p ΔT)` | 动能 / 焓差 | 判断黏性耗散生热是否可忽略 |

## 5. 用量级比排序时的纪律

1. **只比同量纲的量。** 要比"哪个机制更重要"，先统一成同一个物理量——都化成力、都化成功率、或都化成能量。拿力去比能量是没有意义的。
2. **给指数，不给形容词。** 写 `阻力功/重力功 ~ 10⁻³`，不写"阻力比较小"。标度律要写成 `v_t ∝ d²` 而不是"随直径增大"。
3. **`1/10` 不是通用的可忽略门槛。** 判据取决于目标量：
   - 目标量是**和**（如总能量）：10 % 的项通常可忽略。
   - 目标量是**两个大项之差**（如净力、共振偏移、残差）：10 % 的项可能决定**符号**，绝不能忽略。
   - 目标量在**指数上**（如 `e^{−E/k_BT}`）：指数里 10 % 的偏差会放大成倍数。
4. **门槛值是经验分界。** `Re = 2300`、`Ma = 0.3`、`Bi = 0.1` 都是习惯划线，不是相变点。比值落在门槛一个量级以内时，**必须实算，不能引门槛下结论**。
5. **无量纲数相等 ≠ 物理相似。** 模型实验要成立，必须**所有相关**无量纲数同时匹配。只匹配 `Re` 而 `Fr` 不匹配的船模实验，波阻部分不相似——这正是缩比实验最常见的失败方式。

## 6. 自检

排完序做三项检查：

- 每个宣称"可忽略"的机制，都有一个写出数值的比值，并注明它是【题面】、【标准值】还是【估算】。
- 所有比值的分子分母量纲一致（用 `scripts/dimcheck.py` 跑一遍）。
- 主导机制给出的标度律，与已有的定性观察不矛盾（如"加大三倍后现象变强"要与指数对得上）。
