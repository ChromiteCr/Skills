# Modeling Validation Playbook

这份参考用于区分容易混在一起的检查。只在选模、假设、批判、代码或论文阶段需要判断验证充分性时读取。

## 1. 五类检查不是同义词

| 类别 | 回答的问题 | 典型做法 | 不能证明什么 |
|---|---|---|---|
| 校准 / fitting | 模型参数怎样由已有数据估计 | 训练、拟合、反演、参数估计优化 | 对新数据有效、机制正确 |
| 验证 / validation | 对未用于校准的数据或已知情形是否有效 | 留出集、时间外推、手算例、已知解 | 所有边界场景都稳健 |
| 灵敏度 / sensitivity | 输入或参数小变化如何影响输出 | 局部扰动、全局采样、情景扫描 | 输入本身的概率分布正确 |
| 不确定性 / uncertainty | 已知不确定来源如何传播到结果 | 区间、分布、置信 / 可信区间、误差传播 | 未建模偏差已经消失 |
| 稳健性 / robustness | 合理替代设定、异常情景或数据扰动下结论是否保留 | 模型替换、压力测试、删点、分布漂移 | 模型在作用域外仍成立 |

还要单独检查**验证（verification）**：代码是否按预定方程工作。代码算对了与模型描述现实正确是两层问题。

决策优化不属于校准：它在已给定模型与情景下选择行动。参数调优优化、逆向优化和运营决策优化要分别命名，
并分别记录哪些数据用于估计、选模、决策与最终压力测试。

## 2. 最低验证梯

从便宜到昂贵逐级执行；前一层失败时先修，不用更复杂检查掩盖：

1. **结构检查**：符号定义、维度、单位、参数范围、非负性、边界条件
2. **手算 / 小例**：可人工得到答案的微型输入
3. **极限情形**：零、无穷大、全相等、单对象、无约束等有明确预期的情况
4. **基线比较**：恒值、历史均值、朴素规则、线性松弛或其他任务合适的简单基线
5. **校准外验证**：未参与拟合的数据、未来时段、不同区域或独立情景
6. **灵敏度与不确定性**：针对会改变结论的输入、参数与假设
7. **稳健性 / 对抗情景**：缺失、异常、分布漂移、约束收紧、结构替换

不是每个项目都能完成第 5–7 层；缺失时应降低结论强度，而不是写“模型具有良好稳健性”。

## 3. 单位与量纲

- 加减项必须同维度；等式两侧必须同维度。
- 对数、指数和三角函数的输入通常应无量纲。
- 归一化后记录基准量，不能让“0.8”失去原量纲解释。
- 速率需要时间基准；密度需要分母口径；百分比要明确分子和分母。
- 数值单位转换放在单一入口并测试，避免模型内部到处乘 `1000`。

量纲一致是必要条件，不是模型正确性的充分条件。

## 4. 可辨识性 / Identifiability

先问：不同参数组合是否会产生无法区分的输出？若会，参数数值就不能被单独解释。

可用检查按模型选择：

- 结构秩、Jacobian / Fisher 信息矩阵的秩或条件数
- 参数相关性与协方差
- profile likelihood 或单参数扫描
- 多初值拟合是否得到不同参数但近似同损失
- 后验分布是否宽、强相关或受先验主导
- 参数扰动后可观测输出是否几乎不变

发现不可辨识时，选项包括：减少参数、重参数化、增加能区分参数的数据、只解释可辨识组合，或放弃参数解释。
“优化器收敛”不能替代可辨识性检查。

## 5. 数据分割与泄漏

- 预测问题按时间、个体、组别或空间结构分割，不能默认随机拆分。
- 归一化、特征选择、缺失值处理和超参数选择只在训练侧拟合。
- 同一对象的重复记录跨训练 / 验证集会造成泄漏。
- 优化方案用来调参的场景不能同时充当最终压力测试。
- 数据少到无法留出时，用交叉验证、重采样、已知性质与限制声明组合，不虚构独立验证。

比较多个候选或超参数时，候选比较本身会消耗验证信息。明确分开训练 / 校准、开发 / 选模与一次性最终评估；
小样本使用嵌套交叉验证，时间序列使用嵌套的 rolling-origin / walk-forward 设计。最终评估集在模型、特征、
阈值、指标和报告规则冻结前不得查看；看过就把它降为开发集并另找诚实的最终证据。

预测使用外生变量时，验证中只能使用预测时点实际可获得的信息。未来天气、价格或政策若需另行预测，必须用
历史时点可获得的预报、联合模型或明确情景传播其不确定性，不能拿实现后才知道的真实未来值。

## 6. 不确定性合同

每个区间、分布或情景范围都要写：

- **estimand / target**：参数、未来观测、均值、最优目标、决策 regret 或其他对象
- **source**：测量、过程 / aleatoric、参数、模型结构、输入情景、数值或优化不确定性
- **method and assumptions**：渐近、bootstrap、Bayesian、Monte Carlo、区间传播或情景分析，以及依赖结构
- **calibration**：频率覆盖、预测区间 coverage / sharpness、posterior predictive check，或为什么只能解释为情景范围
- **selection effect**：是否包含模型 / 特征 / 超参数选择带来的额外不确定性

参数置信 / 可信区间与预测区间不能互换；灵敏度扫描范围不能称为置信区间。时间、空间或群组相关数据的重采样
必须保留相应依赖。没有可校准概率解释时，使用“所测情景范围”，不要写“95% 置信”。

## 7. 因果识别门槛

出现“导致、影响、效应、干预后会”时，预测表现不够。至少登记：

- estimand、处理 / 暴露、结果、时间顺序和目标总体
- 随机设计、自然实验、准实验、DAG 或其他识别策略
- 混杂与选择机制、positivity / overlap、consistency、干扰 / spillover 假设
- 缺失、测量误差和 post-treatment 变量的处理
- 识别假设的可检验含义、安慰剂 / 负对照或对未测混杂的敏感性

任一关键项缺失时，只能报告关联或条件预测，不得把模型系数解释为因果效应。

## 8. 数值方法专项验收

- **ODE / PDE / 数值积分**：与已知解或高精度参考比；做网格 / 步长加密与观测阶检查；检查稳定性、刚性、
	事件定位、守恒 / 正性和非物理解，不能只看曲线平滑。
- **连续 / 整数优化**：分别检查 primal / dual 可行性、变量界、整数性、尺度、残差、最优性 gap、超时状态与
	可用证书；有 incumbent 但 gap 未闭合时只能称当前可行解或有界近似解。
- **MCMC / 随机采样**：多链、R-hat、有效样本量、自相关、Monte Carlo 标准误、warm-up 与后验检查；种子一致
	不是收敛证据。
- **随机仿真**：重复数、方差 / 误差目标、停止规则和随机数流；比较方案时使用合理的共同随机数或独立重复设计。

## 9. 结论强度

| 支持情况 | 允许的措辞 |
|---|---|
| 只在训练数据拟合良好 | “在该数据上拟合……” |
| 在明确留出集表现良好 | “在该留出范围内……” |
| 多场景与替代设定结论一致 | “在所测试的场景中保持……” |
| 机制与因果识别得到额外论证 | 才能讨论机制 / 因果，且写识别条件 |

“证明有效”“普遍适用”“具有强鲁棒性”需要与字面同等强度的证据；没有就降级。
