# LaTeX Conventions for Modeling Papers

这些约定服从赛事模板和仓库已有 class / package。模板冲突时保留模板，记录限制，不强行换技术栈。

## Source structure

- 一个逻辑章节一个 `\input{}` 文件只在论文规模值得时使用；短论文保持简单
- 导言区放 class、package、全局命令与元数据；正文不重复 `\usepackage`
- 重复符号、算子、单位格式和向量样式用语义命令，但不要把每个一次性表达都包装成宏
- 生成文件放明确目录；不手改自动生成表图后再丢失来源
- 相对路径、大小写和扩展名在目标编译环境中可复现

## Math and notation

- 符号首次出现时定义含义、单位和索引范围；同一符号不承担两个概念
- 行内数学用于短表达，关键关系使用编号环境；只给正文确实引用的式子编号
- 多行推导使用 `align` / `aligned` 等 amsmath 环境，不用 `eqnarray`
- 交叉引用使用 `\label` + `\eqref` / `\ref`，不写死“公式 (3)”
- 向量、矩阵、随机变量、集合、算子和转置样式全篇一致
- 文本说明使用 `\text{}`，多字符函数使用 `\operatorname{}` 或已定义算子
- 数值与单位之间保留不可断空格；若项目已有 `siunitx`，统一用其接口
- 不用手工 `\!`、`\quad` 堆出对齐；先选择正确环境和结构

任何可能改变运算优先级、上下标范围、求和界、导数变量或向量含义的“格式修复”都属于内容决策，必须停下来询问。

## Tables

- 表格回答一个比较任务；标题、单位、样本 / 场景与小数精度可解释
- 单位放列标题，不在每个单元重复
- 同列同精度，除非精度差异本身有统计依据
- 若模板允许，使用 `booktabs` 风格的少量水平线，不使用竖线和每格边框
- 数值列按小数点或量级对齐；极长表移附录或横置，而不是缩到不可读
- 空值区分“不适用、未测、缺失、零”，不能都写 `-`
- 每张表在正文被引用并解释，不把表格单独当论证

## Figures

- 优先 PDF 等矢量格式表达线图和示意；照片 / 栅格图使用足够分辨率
- 轴、单位、范围、基线、误差 / 区间、样本与场景完整
- 图注可独立说明图展示什么、数据范围和必要限定，不重复结论口号
- 颜色不是唯一编码；打印为灰度后仍能分辨
- 不拉伸、裁掉标签或用 `scale` 将文字缩到不可读；优先修图源尺寸
- 每张图由登记脚本 / 运行生成或标明外部来源与许可

## References

- 只保留团队实际读过并用于具体主张的方法或数据来源
- BibTeX / biblatex 元数据来自可核对来源；作者、标题、年份、DOI 不凭记忆补全
- 引文紧邻被支持的主张；一串来源不能模糊地支撑整段不同事实
- 不用手写 `[1]`；引用命令与 bibliography backend 遵循项目现有模板
- 编译日志中未定义引用、重复 label 与空 bibliography 必须归零

## Build and visual checks

1. 从清洁构建运行项目规定命令，记录 engine、版本和退出状态
2. 必要时完整跑 LaTeX -> bibliography -> LaTeX -> LaTeX 链，或使用已有构建工具
3. 处理错误、未定义引用、重复 label、缺字形、overfull / underfull box 和 package conflict
4. 检查 PDF 页数、空白页、目录、页眉页脚、浮动体顺序、公式断行、表格裁切和图中文字
5. 在目标提交尺寸查看，不只在编辑器放大状态检查
6. 对照内容冻结清单，确认数字、符号、方程、引用和结论未被格式化改写

`underfull` 不一定是错误；记录位置并目视判断。`overfull` 可能造成内容裁切，应逐项处理或说明模板限制。
