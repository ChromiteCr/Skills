# 地板 / The Quality Floor

不随抽牌改变的 27 条规则，每条能检查。抽牌决定"长什么样"，地板决定"好不好用、读不读得清、算不算数"。

每条：规则 → **检查** → 因 → **原站取值 / source value**（一个实例，不是默认）。"不要"只用于无障碍、正确、隐私。

标记：`[lint]` = `lint_floor.py` 自动查（令牌对比度浅深各一遍、必需令牌、CJK 回落、`prefers-reduced-motion`、焦点样式、无替代的 `outline:none`）；`[tones]` = `tones.py` / `EVK.tones` 算出并有测试；`[手工]` = 按"检查"在浏览器里做。lint 绿灯只代表带 `[lint]` 的条目过了。

---

## A. 颜色与对比 / Colour and contrast

### F01 正文与次级文字 `[lint]`
- 规则：`--text` 对 `--paper` ≥ 7:1；`--sub` 对 `--paper` 与 `--paper-2` 都 ≥ 4.5:1。
- 检查：浅深各量；`--text` 在 `--paper-2` 上也应 ≥ 4.5。
- 因：强光、单手，次级文字最先掉出可读范围。
- 原站取值：墨 `#14171D` 16.47；`--sub` `#5B6270` 5.63（paper-2 上 5.01）；深色 `#EEEAE1` 14.04。范围：text 7–17，sub 4.5–9。

### F02 强调色的"字版"与"反白字" `[lint]`
- 规则：每个强调色拆两个令牌：填充 `--a`、文字 `--a-text`；小字、链接、数字只用 `-text`。`--a-text`、`--b-text` 对 `--paper` ≥ 4.5；`--on-a`、`--on-b` 对各自填充 ≥ 4.5。爬升色同理拆开：`--climb` 只画图形（F03），凡是文字（步骤序号、"上楼"字样）一律用 `--climb-text`：对 `--paper` 与 `--paper-2` 都 ≥ 4.5，色相与 `--climb` 相差 ≤ 10°，浅深各一份；填充上要落纸色字时，用 `--climb-text` 当那块填充。
- 标题不暗于正文：`--a-text` 对 `--paper` 的对比度不低于 `--text` 的对比度减 0.5（浅深都算）；墨色系强调色在深色里走不到时，`--a-text` 直接等于 `--text`，强调留给 `--a` 的填充与规则线。lint 的 heading/body 检查：< 4.5 失败，< 正文对比度 × 0.8 警告。
- 填充里的字：填色面（主按钮、按下的分段 `aria-selected` / `aria-pressed`、填色标签）里的双语配对继承该面的字色。配方对纸面写的 `.evk-k { color: var(--a-text) }` 会让这些字落在同色填充上消失（墨压墨），所以 `base.css` 有一条 `.evk-btn .evk-k, .evk-seg > button .evk-k, .evk-tag .evk-k { color: inherit }`（"FILLS"）；配方不要再给这三处的 `.evk-k` / `.en` / `.cn` 写颜色（`craft-details.md` B09）。
- 检查：量；文字令牌还要在它落脚的面（paper-2、`--e-soft`、弹层底）上量；`grep -E "color:\s*var\(--(a|b|climb)\)"` 找误用；浅深各渲染一个主按钮、一个按下的分段（两种属性各一）、一个填色标签，字读得出来（lint 不查，`[手工]`）。
- 因：色带要饱满，字要够深。
- 原站取值：红填充 `#C8102E`，粉笔白字在其上 5.40；红字在 paper 5.40、paper-2 4.81；深色字版 `#FF7084`（6.34）。红在深蓝上仅 2.47，深蓝条上的红标签改 `#FF8A99`。爬升色原站已有字 / 图一对（字 `#B45309`、图 `#D97706`），但字版在 paper-2 上只有 4.11，套件补到 ≥ 4.5。

### F03 线、焦点、图形与画布文字 `[lint]`
- 规则：`--rule` 对 `--paper` ≥ 1.25:1，只画线、不当文字。`--focus` 对 `--paper` ≥ 3:1。`--climb`（上下楼）对 `--m-slab` ≥ 3:1，色相与 `--b` 差 ≥ 50°（方向的 `b` 有几个色相家族时，每一种配对都要过：`kit.py --validate` 按 ≥ 53° 查，留量化余量；`derive.md` §5）。地图的墨线 `--m-cap`（墙帽、环、针、图标描线）对 `--m-slab` ≥ 7:1（lint：< 4.5 失败，< 7 警告），墙面基色 `--m-wall` ≥ 3:1（lint 警告），浅深各一份；生成器沿 OKLCH 亮度走到这两个值（`map-craft.md` §5.7）。靠图形表意的东西（路线、选中环、图标）对其底 ≥ 3:1。地图的选中拆成两个令牌：`--m-select` 是选中的**边线**，对 `--m-slab` ≥ 3:1（lint 地板项）；`--m-select-fill` 是选中的**淡染**（`--m-room` 朝 `--m-select` 混 10–16 %），没有对比下限，但压在上面的标签仍 ≥ 4.5。引擎用 fill 填、用 select 描。画布标签、图上文字带与本地底同色的光晕或遮罩，对比以它为底量 ≥ 4.5。
- 检查：量，深色同样；地图缩到最大最小各截一张看标签；选中一间房截一张，淡染与边线两个通道都在。
- 因：线负责"分"，图形要被看见，字要被读；标签压在房间、墙、路线上，底色各异。
- 原站取值：石灰 `#D8D3C8` 在粉笔白上 1.37；焦点红 5.40；地图标签带 `--m-halo` 描边。原站 `--m-climb #D97706` 在地面 `#ECE8DF` 上约 2.6:1（推算），低于本条。原站只有一个选中令牌，是房间淡染 `#FBE3E7`（相当于 fill），没有边线；把这个淡染直接当 `--m-select`，要么整间房涂满强调色，要么边线 < 3:1，所以套件拆开。原站墙帽 `#13294B` / `#F7F5F0` 对楼板 11.9 / 12.2:1，过线；墙面 `#F4F1EA` / `#2C4A78` 对楼板只有 1.08 / 1.5:1（形体靠墙帽线），套件不照搬，墙面也要 ≥ 3:1。

### F04 实体色：一个输入，多个角色，走到 4.6 `[tones]`
- 规则：实体（学校、展商、展位）的色由一个输入色驱动，派生 `--e`（填充）、`--e-text`、`--e-on`、`--e-soft`、`--e-line`、`--e-dk`、`--e-soft-dk`。字版保持色相与彩度，朝墨色一端按 OKLCH 亮度 0.01 一步走（浅纸上变深，深纸上变亮），停在第一个 ≥ 4.6:1 处，L = 0.98 仍不够才落到墨色，所以深纸牌上各实体的色相仍可分（套件默认，`scripts/tones.py` 与 `EVK.tones` 结果一致；原站是朝墨色按 1% 混合，`--method mix` 可复现原站数值）；`--e-on` 在纸色与墨色里取对比更高者。一个项目只用一种算法；每个实体过测试：`--e-text`/纸、`--e-dk`/夜、`--e`/`--e-on` 都 ≥ 4.5。
- 检查：`python3 scripts/tones.py "#hex" --roll .evk/roll.json` 看全部角色（用这张牌的纸、墨、夜；不带 `--roll` 就按原站的浅纸 `#F7F5F0` 算，深底方向的结果是错的，脚本会提示；`--batch data/venue.json` 一次算全部实体）；项目里循环测试覆盖每个实体。
- 因：亮色直接做字读不出，整页压暗又丢身份；4.6 多出的 0.1 留给量化，"第一个够用"保住最多原色。
- 原站取值：52 色里 48 个本就 ≥ 4.6；Caltech `#FF6C0C`→字 `#B45111`（4.67；橙填充上用墨字 6.33）。淡底 = 10% 混入纸，线 = 45%，深色淡底 = 22% 混入夜。目标、步长、混合比例可换；"算出来并测试"不可换。

### F05 深色里的实体色 `[tones]` + `[手工]`
- 规则：深色字版 = 同色相提亮（套件默认 OKLCH 亮度步进；原站 HLS 提亮、饱和度封顶 s ≤ .62），已够亮的不动，对夜色 ≥ 4.6:1。辨识不能只靠对夜色 < 3:1 的填充；这种实体在深色里加边线（`--e-dk`）或徽章环。
- 检查：对每个实体量填充对夜色，< 3:1 的列出，逐个看深色截图。
- 因：很深的品牌色放深底会"消失"，只剩字悬在半空。
- 原站取值：UChicago `#370404` 对夜 `#0D1D36` 仅 1.05，字版提亮成 `#DA6060`；19 个蓝系提亮后近似同一中蓝。

### F06 深色是派生方案，不是反色 `[lint]` 部分
- 规则：
  1. 令牌名与浅色一致，声明两次：`@media (prefers-color-scheme: dark){:root:not([data-theme="light"]){…}}` 与 `:root[data-theme="dark"]{…}`；写 `color-scheme`。
  2. 地面不纯黑、字不纯白；至少三级抬升（地面 → 面板 → 弹层内的面），嵌套层与上层同色时在该容器里重定 `--paper-2`。
  3. 线用文字色的透明度；强调色字版重新提亮；阴影染品牌色。
  4. 读不了令牌的资源（data-URI 图标、`<select>` 箭头）有深色孪生；`theme-color` 浅深各一。
- 检查：[lint] 两块令牌齐全、F01–F03 在深色通过；其余在 375 px 深色下翻每页每弹层，找消失的选中行、输入框。
- 因：反色丢品牌、红变荧光、阴影消失。
- 原站取值：地面 `#0D1D36`、面板 `#13294B`、弹层内 `#1E3A66`（每级仅差约 1.2–1.5:1）；线 `rgba(247,245,240,.16)`。可换：纯黑 OLED + 1px 边、暖炭灰、有色暗底。

### F07 颜色不单独承载状态 `[手工]`
- 规则：当前、已读、选中、危险、爬升、步行，至少两个通道同时表达（形状、长度、粗细、标签、虚实线、位置），颜色只是其一。
- 检查：`filter:grayscale(1)` 截图，状态仍可分辨。
- 因：色觉差异；强光下色差先消失。
- 原站取值：章节线"当前"= 更长 + 实体色；爬升 = 琥珀 + 虚线 + "上楼到 3F"标签。

## B. 语言与字 / Language and type

### F08 双语层级：层级是规则，顺序不是 `[手工]`
- 规则：层级是规则，顺序跟 brief。先定一个 `lead` = `en | zh`（滚牌参数，`--keep lead=zh`；写在 `<html data-evk-lead>`），由 brief 与受众定，或按部件分工。**主语永远是配对里的第一个子元素**，生成器按 lead 调换写入顺序。样式分两层：**角色层**（字号、字重、颜色、顺序）只认位置，`.evk-k > :first-child` 为主、`:last-child:not(:first-child)` 为辅；**文字层**（字体族、大小写、字距、断行）只认语言，`.en` / `.cn` / `lang`。配方与页面不得把层级写在 `.en` / `.cn` 上。辅语在所有部件里处理一致：位置、弱色档、字体族、字距固定，不转大写。主语更响：名义字号 ≥ 辅语 1.1 倍（lead=zh 时中文行 1.1em，拉丁副行是 .86em 的小标签、`--sub` 色，仍 ≥ 11 px，F11）；小号全大写 + 加宽 + 加粗的标签按光学字号比。两种语言同时可见，brief 明说单语才用切换。专有名词放进另一种语言的句子时保持原字体。中文展示行自带 `lang="zh-CN"` 或 `.cn`，只写 `<html lang>` 不会换中文字体。
- 检查：列出双语部件的主辅字号比、颜色、字重；抽 5 个看辅语位置与弱色是否一致；把 `data-evk-lead` 改成另一值、按它调换配对顺序，层级仍成立，不改一行 CSS。
- 因：混合人群一眼找到自己的语言，一致的主辅让双行不打架。
- 原站取值：`lead=en`（英文主、中文辅）。标签 .74 / .66rem = 1.12；行标题 1.12 / .82 = 1.37；小号大写里中文名义上反而更大（数字条 .58 / .72）。中文 `--sub`、字重 500、字距 .06–.12em。

### F09 CJK 字体栈与 `lang` `[lint]`
- 规则：每个 `--f-*` 栈都含 CJK 系统字（无衬线：PingFang SC / Hiragino Sans GB / Noto Sans SC / Microsoft YaHei；衬线：Songti SC / Noto Serif SC / SimSun），最后是通用族。`<html lang>` 与内容一致，成段的另一种语言带自己的 `lang`。
- 检查：[lint] 每栈有 CJK 回落；`document.documentElement.lang` 非空。
- 因：Latin 字体没有汉字，浏览器随机挑一个，字形会跳；回落选同一流派。
- 原站取值：正文栈 `-apple-system, … Roboto, var(--f-cn)`；`<html lang="zh-CN">`；不下载 CJK 网页字体。

### F10 CJK 断行、空格、行高与行宽 `[手工]`
- 规则：`line-break: strict`；拉丁名称与短标签用 `word-break: keep-all`（只限 `.en` / `lang=en`），词组包进 `nowrap` 片段；中文名不用 keep-all（无空格的名字会留下单字孤行），加 `text-wrap: balance`。生成的 HTML 里两个汉字之间不留空白；汉字与拉丁、数字之间生成时补空格（`EVK.spaced`）。成段汉字行高 ≥ 1.7（长文 1.8–1.9），行宽用 `em` 且 ≤ 40em，不两端对齐。
- 检查：`grep -P "[\x{4e00}-\x{9fff}]\s+[\x{4e00}-\x{9fff}]"` 对构建产物应为空（拼出来的句子也算：搜索框例子、样张里的位置摘要）；375 px 读一段，行首无标点。
- 因：折错行像排版事故；模板换行变成的空格最常见。
- 原站取值：`body{line-height:1.7;line-break:strict}`；长文 1.02rem / 1.85、`max-width:40em`；构建时 `join_cjk()` 去空白。

### F11 最小字号与表单 `[手工]`
- 规则：成段文字与表单控件 ≥ 16px（输入框更小会让 iOS 聚焦时放大整页）；可点标签 ≥ 11px；< 11px 只用于别处已重复的冗余标注，且须加粗、加宽、字距 ≥ .1em、全大写，不用窄体。`text-size-adjust:100%`。
- 检查：遍历可见文本取 `getComputedStyle().fontSize`，< 16px 的元素类逐类说明。
- 因：小字号在窄体上最先失败。
- 原站取值：成段 1–1.02rem；最小 .54–.64rem（8.6–10.2px），全是加宽大写 + .14–.18em 且有中文行重复；是软肋。

## C. 触控与输入 / Touch and input

### F12 触控：目标、悬停门控、按压 `[手工]`
- 规则：可点的东西最短边 ≥ 44 CSS px（放不下的图标用 `::after` 扩大点击区；段落内行内链接除外），主要动作 ≥ 46、列表行 ≥ 56。所有 `:hover` 放进 `@media (hover:hover)`；`:active` 在触下那一帧生效、松开时缓出；换掉点按高亮就要保证自己的按压态在 iOS 上触发（加空的被动 `touchstart` 监听），`-webkit-tap-highlight-color:transparent` 配 `touch-action:manipulation`。全局 `a:hover` 不得把按钮字改成与按钮底同色；悬停也不靠降不透明度（`opacity .88` 会把 4.6:1 的按钮字拉到约 3.8:1），套件的悬停是下划线，`--hover-opacity` 只是想要淡出的方向自己开的旋钮。
- 检查：`[...document.querySelectorAll('a,button,summary,input')].filter(e=>e.offsetWidth&&Math.min(e.offsetWidth,e.offsetHeight)<44)` 逐个说明；`grep ":hover"` 每处在媒体查询内；真机点一次按钮和一行列表。
- 因：单手、走动、手指比光标粗；触屏没有悬停，粘住的悬停像没取消的选中；iOS 没监听器就没有 `:active`。
- 原站取值：按钮 46、行 60、格 56、输入 48、折叠 54；次按钮 38、导航按钮 42 低于线，是软肋。按钮 `scale(.97)` .1s ease-out；行底色按下 `transition:none`、松开 .15s。可换：涟漪、阴影塌陷、颜色反转。

### F13 焦点可见，含被裁切的形状 `[lint]`
- 规则：每个可交互元素有 `:focus-visible`；环粗 ≥ 2px、对相邻色 ≥ 3:1；`clip-path`、`overflow:hidden`、画布里的形状用 `inset box-shadow` 画环，环内再加一圈底色（免得红环落在红填充上消失）；不写无替代的 `outline:none`。
- 检查：[lint]；再 Tab 走完整页，每一站都看得见。
- 因：键盘用户全靠它；`clip-path` 裁掉外描边。
- 原站取值：全局 `outline:3px solid var(--accent);outline-offset:2px`；切角按钮 `inset 0 0 0 3px accent, inset 0 0 0 5px bg`。

## D. 动 / Motion

### F14 减弱动效、透明度、对比度 `[lint]`
- 规则：`@media (prefers-reduced-motion: reduce)` 块里：过渡与按压缩放关、弹簧直接落到目标（状态不丢、行程取消）、虚线与脉冲冻结、`scroll-behavior:auto`。`prefers-reduced-transparency` 下毛玻璃换实色。`prefers-contrast: more` 下 `--rule` 取文字色、`--sub` ≥ 9:1，深色也生效。
- 检查：[lint]；开 reduce 点一遍弹层与地图。
- 因：这是用户设置；"同样的状态、没有行程"是对的退让。
- 原站取值：reduce 列表不全，contrast 块在深色里不生效，是缺口。

### F15 只为状态而动 `[手工]`
- 规则：每个运动都是某个状态变化的可见后果：按压、展开、选中、开合、进度、路线。静止时无物循环。依次上浮、页面转场、环境视差要用就先说清服务哪条契约。至多一个"签名运动"（弹层或相机），其余反馈 ≤ 200 ms，只动 `transform`、`opacity`。
- 检查：`grep -E "infinite|@keyframes"` 逐条说明；页面停 5 秒无物在动（路线虚线除外）。
- 因：一个物理运动当主角、其余快速确认后静止，读成性格而非噪音。
- 原站取值：无一个 `cubic-bezier()`；时长 .1 / .15 / .2 / .25 / .5 s；无依次出现、计数器、骨架闪烁。

### F16 弹簧：可打断，从当前速度接手 `[手工]`
- 规则：手势驱动或可能被打断的东西（弹层、相机、拖拽）用物理弹簧：状态是（位置，速度）；换目标只改目标、不重置值；拖拽 1:1 跟手，越界用橡皮筋 `over·dim·c / (dim + c·over)`（c = .55）；松手按投影落点判断：`位置 + 速度 × 0.499` 与半高比；离开比进入快；手势开始时就触发其因果（相机拉远、取消高亮）；`dt` 夹到 50 ms；静止后不留 `transform`。
- 检查：快速开合弹层、中途抓住反向，物体跟手不跳；`EVK.Spring.to()` 不重置 `value`。
- 因：打断不显得故障；固定时长的缓动做不到。
- 原站取值：response .30–.35 s、阻尼比 1，仅"没拉够弹回"用 .8。本套件：`--spring-dur` 0.3–0.65 s、`--spring-bounce` 0–0.3，方向定"重而稳"或"轻而弹"，规则不变。

### F17 画布静止时不画 `[手工]`
- 规则：只在有东西在动时跑 `requestAnimationFrame`；物理返回"仍在动"，不动就停。字体加载、图片 `onload`、主题切换、`resize`、数据到达各踢一次重画。`devicePixelRatio` 取上限（≤ 3）；标签页隐藏不画。
- 检查：Performance 录 3 秒静止页面，帧数为 0（路线虚线除外）；切深色、转屏、字体晚加载，画面都对。
- 因：电池、发热、廉价感。
- 原站取值：`dt = min(.05, 经过时间)`；每个量有各自的静止阈值。

## E. 结构与稳健 / Structure and robustness

### F18 语义与无 JS 基线 `[手工]`
- 规则：
  1. 地图之外有同样信息的文本等价物（按楼层的名录），`<noscript>` 指向它；画布 `role="img"` + `tabindex="0"` + 说明操作方式与名录位置的 `aria-label`。
  2. 需要 JS 的控件先 `hidden`/`disabled`，脚本启用才显示；全局 `[hidden]{display:none!important}`。
  3. 状态用原生语义（`aria-pressed`、`aria-current`、`role="status"`、`<details>`、`<dl>`），只用做得到的角色。
  4. 路线每步一句进 `aria-live="polite"`；焦点只在原目标消失时才移动，关闭弹层回到触发它的按钮。
- 检查：关 JS 看首页、实体页、名录是否完整；键盘与读屏走一遍弹层。
- 因：现场网络差，脚本会晚到或失败。
- 原站取值：名录按楼层降序渲染成门牌卡片，既是无 JS 页面又是画布的等价文本。

### F19 极端内容与窄屏 `[手工]`
- 规则：320 px 宽、200% 缩放无横向页面滚动；最长与最短的真实实体名都渲染；用户长度的字符串加 `overflow-wrap:anywhere`；网格子项 `min-width:0`；图片写 `width`/`height`；底部固定元素加 `env(safe-area-inset-bottom)`；粘性栏页面的锚点设 `scroll-margin-top` ≥ 栏高 + 8；长页测 3 与 12 个章节、0 与 145 条来源；分段控件（楼层钮）放不下时在控件里横滑，不撑宽页面、不被 `overflow:hidden` 裁掉：6 个楼层钮加路线钮在 320 px 也点得到每一个。
- 检查：320×568 下 `document.scrollingElement.scrollWidth <= innerWidth`；换最长/最短数据各截一次；把楼层钮加到 7 个再看一次。
- 因：真实数据永远比模板宽。
- 原站取值：栏高 56–62，`scroll-margin-top` 70/76/80；校名 3–14 字符分 4 档字号。

### F20 缺席要设计，反馈不说谎 `[手工]`
- 规则：空结果、待定、未开放、出错、离线、无 JS 各有设计过的状态，写清"发生了什么 + 下一步试什么"，统一成一个部件。数量为 0 不印。动作按钮请求期间禁用，状态以服务器回应为准。不可撤销的动作，警告紧贴按钮。缺失的素材有同尺寸占位。
- 检查：列出数据来源，逐一制造"没有""慢""失败"并截图。
- 因：现场最常见的是空态与慢网。
- 原站取值：`.pending` = 浅底 + 4px 强调色左线 + 标题 + 说明；"没有找到匹配的学校。可以试试英文缩写，例如 MIT、UCLA。"

### F21 长页：任何时刻都知道自己在哪 `[手工]`
- 规则：实体长页满足阅读导航契约（`references/reading.md`）：常驻"当前章节"指示、一步跳到任一章节、已读/未读/当前不只靠颜色、进度在文末前就满、无 JS 有章节列表、锚点跳进折叠内容先展开再滚动。呈现可换，契约不可换。
- 检查：滚到三处各指出当前章节；关 JS 后章节列表可跳；点来源引用时折叠的 `<details>` 打开。
- 因：手机上的长文没有"页码"。
- 原站取值：栏左一列短线（当前一条拉长、实体色）+ 栏下 2px 进度线；阅读线在视口 28%。

### F22 路线必须有分步文字 `[手工]`
- 规则：地图上的每条路线都有分步文字（一步一句，含转向、距离、爬楼），可单独阅读与键盘操作，一句进实时区域。同一份数据既出线也出字；任何起点到终点都有结果，没路的组合在数据里报错。
- 检查：全部起点 × 终点跑 `plan()` 应都返回 steps（原站 13 × 52 穷举），并断言最长路线有上限。
- 因：地图给眼睛，文字给走路和读屏的人。
- 原站取值：每步英文标题 + 一句中文，"约 N 米"，"全览"可开关。

## F. 内容与伦理 / Content and ethics

### F23 样张、原型与演示用真实数据 `[手工]`
- 规则：样张里的名称、数字、房间号、日期用活动真实的；资料未到时用标明的虚构数据，不用 lorem ipsum、"Item 1"。未知字段设计成填空线（"日期待定 / Date to be announced"）。同时放入最长与最短的真实名称。
- 检查：`grep -ri "lorem\|item [0-9]\|占位\|xxx"` 为空；样张里同时有最短与最长名。
- 因：真实内容才暴露断行、溢出、挤压。
- 原站取值：所有样板用真实 52 校名；日期位是 3px 填空线。

### F24 不放个人信息 `[手工]`
- 规则：页面、数据、日志、注释里没有学生姓名、班级、小组、联系方式、可识别的人脸照片；受访者写"受访学长"。访问记录只存最少字段。写成对构建产物的正则测试。
- 检查：`grep -E "(报告人|组员|小组成员|指导老师)[：:]|2[0-3]\s*班|第\s*\d+\s*组"` 对 `dist/` 为空。
- 因：参与者多是未成年人，发布后删不掉。
- 原站取值：只公开大学名；个人经历段落上线前删除；访问日志 4 个字段。

### F25 第三方素材：授权与署名 `[手工]`
- 规则：照片、徽章、图标、字体、代码只用你能履行授权的。署名紧贴素材（"Photo: 作者 · 授权"）+ 机器可读的来源清单；缺署名等于构建失败。公开站不收 NC/ND。字体附授权文本。遵循所有者自己的署名政策。
- 检查：每个 `<img>` 的 `<figure>` 有含作者与授权的 `figcaption`；`SOURCES` 条目数 = 图片数。
- 因：授权与尊重。
- 原站取值：图注 .72rem "Photo: 作者 · 授权"；只收 CC0 / PD / CC BY / CC BY-SA。

### F26 数字有口径，场地是真的 `[手工]`
- 规则：每个醒目数字紧贴一个限定语位置（年份、"约"、来源、范围）；来源口径不同就写一章"口径说明"。楼层、房间、门、楼梯来自平面图或使用者确认的数据，不凭空画；示意图写"示意"。没在现场核实过的指路话术不发布。
- 检查：数字条每格都有 `note` 位置；`venue.json` 每个房间有 `doors`；示意图有"示意"字样。
- 因：大数字最易误导；指错路比不指路更糟。
- 原站取值：`note`："约""2028 届""截至 2024 年秋季""U.S. News 2027 版"；平面图按真实图纸重画。

### F27 运行时不依赖第三方 `[手工]`
- 规则：页面运行时不请求第三方域名（字体、脚本、统计、地图瓦片）；字体、脚本、图片随站托管，字体只裁出用到的字符与轴，预加载 ≤ 2 个，`font-display:swap`；数据放 `<script type="application/json">`（转义 `</`）。拿不到字体文件（不能下载或无授权）时，用 tokens 里的系统回落栈，`DESIGN.md` 写明"字体：系统回落"，页面不留指向字体 CDN 的 `<link>`（样张的联网字体只供预览）；做法见 `print-parity.md` §5。
- 检查：Network 面板只有本站域名；`file://` 打开可用。
- 因：场馆网络常屏蔽境外域名；第三方请求泄露访客。
- 原站取值：Latin 子集 WOFF2 共约 75 KB；无第三方资源；照片 WebP 720 / 1200 / 1440。
