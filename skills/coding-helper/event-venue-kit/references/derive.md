# 从活动的实物世界推导身份 / Deriving an identity from the event's physical world

这份文件讲的是 Varsity '28 怎么来的：不是它长什么样，而是**怎样从一场活动自己的东西里找到一个身份**。原站做了四个概念、同一份 brief、同一份数据、同一块板子，选一个，再做减法。各节先写原则，再给"原站取值"作为一个实例，并列出真正不同的备选；实例不是默认值。

配套文件：`randomness.md`（抽牌协议）、`library/directions.json`（方向池）、`floor.md`（地板规则）、`reference-direction/DESIGN.md`（原站完整规格）。

## 何时使用 / When to use

- **抽牌之前**：把活动盘点成 8–12 件实物并贴标签（§3、§4；没有照片和平面图见 §3.1），标签交给 `draw.py --tags`，盘点表里的实物是 `draw.py choose --reason` 的依据。
- **已有品牌或 brief**：照样盘点。冻结的轴用 `--keep`（品牌色 `palette=#主,#辅`；地图要求："能转 / 可旋转" = `projection=rotate`，"立体 / 看得出几层" = `projection=3d`；主语言 `lead=zh`），盘点回答"这张牌为什么放得进这个活动"。
- **抽到的牌不顺手**：先做 §6 的最差物件测试，分清是方向不对还是参数不对，再决定重抽（条件见 `randomness.md`）。
- **用户明说要原站的样子**：走 `--canon`，不需要本文。

## 方法一页纸 / The method on one page

1. **brief 写成通过 / 不通过的测试**（§1）→ 2. **盘五类实物加一项**，得 8–12 行盘点表（§2、§3）→ 3. **实物 → 标签 → 抽牌**，得三张牌（§4）→ 4. **在"意义机制"上分叉，数解释成本，跑最差物件测试**（§5、§6）→ 5. **选一个可拥有的装置，跨媒介复用**（§7）→ 6. **做减法，含逐个关掉没有依据的品类道具**（§8、§8.1）→ 7. **从落选的牌里偷规则，不偷图案**（§9）→ 8. **用系统呈现系统**（§10）。

写进项目 `DESIGN.md`：brief 测试、盘点表、三张牌、选择及理由、删除清单（含关掉的 `--prop-*`）。原站没记录为什么选 D（§12），这是缺口。

## 1. Brief 写成通过/不通过的测试 / Brief as pass–fail tests

原站 brief（`CollegeFair-Design/concepts/BRIEF.md`）里每条硬要求，都是一个候选方案**可以挂掉**的测试。四个概念因此能被评审，不靠口味争论。

| 类别 | 原站取值 | 怎么判 | 另一种写法 |
|---|---|---|---|
| 色彩主角 | 红 + 深蓝必须是视觉主角；可加中性色；点缀色至多一个 | 数面积占比、数色相 | 一墨两纸；近单色 + 信号色；色相由实体决定；写成"某机制的哪几个家族可以"（§5 色相家族） |
| 必含元素 | Logo 含 2028 / '28，含义是 Class of 2028 | 肉眼可查 | 必含日期、坐标、吉祥物 |
| 命名 | 英文名 SDSZ College Fair，**活动没有中文名**；中文只用于辅助信息，"2028届"可作届别 | 对成品文本跑正则（原站测试：页面外框不得匹配 `大学研究成果展\|大学展\|博览会`，且每页含 "SDSZ College Fair"） | 双语正式名；用代号作公开名 |
| 反参照 | 不得与 2023 届雷同：圆圈十字、牛皮纸做旧、铜版画、巴洛克角花、飘带标题、哈利波特 | 逐条对照草图 | 按调色板 / 字体类 / 隐喻 / 版式来排除 |
| 团队可用 | 字体只用免费可商用（Google Fonts、思源）；Logo 纯矢量 | 查许可；SVG 里不含 `<text>` | 允许付费字体，交付时转曲 |
| 媒介 | CMYK 印刷、入口 LED、单色橡皮印章、缩到 32 px 仍可辨认 | 每种媒介出一张试样 | 以该活动自己的最差物件为准（§6） |
| 审美门槛 | 以 Pentagram、Collins、Wolff Olins、Order、Experimental Jetset 的提案标准：一个强概念 → 一个可拥有的图形装置 → 克制而自信的执行；留白、比例、字距、网格要经得起放大检查 | 三级漏斗（有概念吗？有装置吗？克制吗？）加放大检查 | "小孩能凭记忆重画吗"；"不改动能过三种媒介吗"；"学生愿意印在外套上吗" |

**要点**

- 这份 brief 里的"不得"来自活动自己的现实：前一届、媒介限制、字体许可。它们比"希望"更能做设计，因为每一条都能挂掉候选。本 skill 只设地板（对比度、触控、隐私等），不替项目加禁令；项目的禁令写在项目的 DESIGN.md 里。
- 写 6–10 条，每条说明怎么判；能写成正则、能数面积、能在 32 px 下肉眼验证的最好。
- 用户没有给 brief：从盘点反推三条最硬的（媒介、命名、反参照）去问用户确认；确认不到就在 DESIGN.md 标"假设"，不要当成事实。
- brief 里白纸黑字的要求永远压过抽牌（`--keep`）；抽牌只决定没被钉住的轴。
- 别的写法各有代价：只写情绪词（无法证伪）；品牌原型加竞品集（容易复制竞品）；"必须能变成一件球衣、一张票、一块门牌"（以物件为准，原站最接近）；按用户旅程。

## 2. 五类实物输入 / The five real-world inputs

原站身份只引用观众已经看到的东西：年份、红墙、印章、名单。这让它读起来像"被发现的"，不是"被装饰的"。盘点就是找这些东西。

| # | 输入 | 原站取值（一个实例） | 它给了什么 |
|---|---|---|---|
| 1 | **名字里的名词** | "Class of 2028"。板上的洞见：美式校园里入学年份被穿在身上，外套袖臂的 class numerals、学院围巾的色条，年份本身就是身份 | 装置：倒角数字 '28；条纹取自围巾色条 |
| 2 | **建筑** | 走廊墙面有大面积学校红色色带；入口有横向 LED 拼接屏（约 3:1 ~ 16:9） | 概念 C 的"信号带"就是那条红带；LED 模板做成 3:1（2880 × 960，说明板上 5760 × 1920）；走廊 mock 的墙红 `#A8232F` 比品牌红更暗 |
| 3 | **仪式** | 集章：每个展位盖章收集 | 房间章 25 × 18 mm（可雕刻）、出口章、52 格名单式集章卡、Logo 的印章版 |
| 4 | **数据** | 52 所大学 / 10 个展区 / 3 层（`venue-data.json`） | 每块板和每个模板都用真名，没有 lorem；52、10、3 成为英雄统计（LED 上的 "03 / 10 / 52"） |
| 5 | **反参照 / 前一届** | 2023 届的照片：羊皮纸地图 + 飘带标题 + 巴洛克角花；红色 LED 上斜体衬线 "2023 College Fair" 加浅蓝箭头；红色走廊墙 | 既指出该避开什么（羊皮纸、铜版画），也指出什么是真的（红墙、LED、贴墙的纸质地图） |
| +1 | **观众手里的媒介**（原站未作主轴，列为备选） | 手机锁屏、胸牌、纸质地图、手环、签到表 | 决定第一个接触点是什么，决定要不要先做"手机里的那一张" |

**推导规则**：从最靠近观众身份的名词出发（原站：Class of 2028），其余四类提供约束和"物件清单"。出发点也可以换：以**仪式**为主，身份是一套文件系统（护照、邮票、卡片）；以**场地**为主，是导视优先的身份（概念 C）；以**数据**为主，是名册 / 网格身份（52 个实体就是 52 格）；以**媒介**为主，从胸牌或锁屏长出来；以**地方手艺**为主（剪纸、篆刻、招牌书法，原站没做过）。

**把反参照翻成几何层面的排除项**（原站做法）：一旦写成"别像上次"，草图仍会无意靠近；写成形状、纹理、材质才抓得住。

- B：避开普通正十字、"四分"和任何"容器 + 交叉"结构（301 由斜十字改成不含交叉的"风车"）；不用金色，远离霍格沃茨。
- C：没有圆形徽章，没有做旧纸张，没有插画；从"魔法地图·怀旧手绘"转向"现代主义导视·向前出发"。
- D：所有转角都切角、**从不用圆**；印泥颗粒只做轻微模拟，不做做旧斑驳；纸是暖粉笔白，但不做旧。
- 别的写法：按调色板、字体类、隐喻或版式来排除（如不用酒红、不用雕版体、不用魔法隐喻、不用居中装饰框）。

## 3. 盘点提示清单 / The inventory prompt list

对任何新活动逐题运行，产出一张 8–12 行的盘点表（模板在附录）。**约束类**答案写进 §1 的测试；**题材类**答案变成盘点行并贴标签（§4）。"原站答案"只是示范；问不到的写"未知"，不要编。

| Q | 问题 | 收集什么 | 原站答案（实例） | 类型 |
|---|---|---|---|---|
| Q1 | **名字里的名词**：全名、主办方叫法、观众自称里，哪个名词已经穿在身上、拿在手里或挂在嘴上？ | 每个名词的物理形态（袖章、色条、门牌、票）；有无歧义 | Class of 2028 → 年份即身份 | 题材 |
| Q2 | **建筑**：人在场地里会看见什么？ | 3–5 张照片；平面图；门牌真实尺寸与观看距离；屏幕比例；墙上已有的色带与现成导视 | 学校红墙带；LED 3:1 | 题材 |
| Q3 | **仪式与动作**：来的人反复做什么，用什么工具，留下什么证据？ | 动词清单（盖章、投票、撕票根、领手环）；工具的物理尺寸；必须延续的传统 | 集章；橡皮章 25 × 18 mm | 题材 |
| Q4 | **数据**：多少实体、房间、楼层？名字多长？几种文字？ | 真名清单（禁 lorem）；计数（成为英雄统计）；最长名字与缩写；编号方案（203·01） | 52 / 10 / 3；长名如 Wisconsin-Madison | 题材 |
| Q5 | **前一届与反参照**：上一届长什么样，哪些被爱，哪些要避开？ | 照片、logo、色板、字体、母题；3–6 条几何 / 纹理 / 材质层面的排除项；其中**真实存在**的东西 | 2023 羊皮纸；红墙与 LED 是真的 | 约束 |
| Q6 | **观众手里的媒介**：观众第一次碰到身份是在哪？ | 首个接触点；屏幕与网络（一个场馆的手机常共用一个出口 IP）；是否离线；要不要打印 | 手机、A4 告示、纸质集章卡 | 题材 |
| Q7 | **最差物件**：身份会被硬放上哪些最难看的载体？ | 尺寸、颜色数、观看距离：5 m 门牌、单色橡皮章、32 px 图标、3:1 LED、黑白复印、刺绣 | 门牌 5 m；橡皮章；32 px | 约束 → §6 |
| Q8 | **语言与命名**：主语言（定 `lead`：en 或 zh，拿不准就问）？唯一名称？哪些名称禁用？ | 规范名；禁用字符串（写成正则）；主 / 辅语言字号下限；域名与短域名 | 英文主中文辅，EN ≥ 1.1 × CN；无中文活动名 | 约束 |
| Q9 | **实体自带的颜色与标志** | 实体色表；标志格式与形状分布（圆章 / 盾 / 方）；授权类型；无标志时的占位 | 52 种校色、52 个校徽（23 公有领域、1 CC0、25 合理使用、3 需署名） | 题材 → `print-parity.md` §3 |
| Q10 | **动线与层**：从哪进、怎么上楼、在哪等？哪些是现场确认过的？ | 比例平面图；楼梯 / 电梯 / 出入口朝向；"已走过"与"未确认"分开记 | 设计稿的旧楼数据被真实平面图替换；未确认的找路提示不写 | 题材 → `map-craft.md` |
| Q11 | **时间、季节、材质** | 日期与时段；光线；工艺（CMYK、Riso、LED、丝网）；可用纸；预算 | 一日活动；CMYK + LED + 单色章 | 题材 / 约束 |
| Q12 | **声音与禁区**：主办方怎么说话？什么永远不显示？ | 6–8 句主办方原话；隐私红线；署名政策 | 平实、数字精确；不出现学生姓名 / 班级 / 分组；页面不加 AI 使用声明 | 约束 → `print-parity.md` §8 |

### 3.1 没有照片和平面图时 / Inventory without photos

使用者常常只给一段 brief。盘点要"能拍照的实物"，又说"问不到写未知、不要编"，两者不冲突，分开**事实**和**假设**：

1. **事实留"未知"**：名单、数字、日期、楼层与房间、门的位置、真实尺寸。不推断，不进页面；平面图向使用者要（没有就只画示意并标"示意"）。
2. **实物按活动类型推断，逐行标"假设"**：这类场地里通常有什么——科学节的实验室门牌、实验台、走廊折叠桌、安全标识、方格记录本；书市的书脊索书号、借书卡、书架端牌。每行写"依据"（brief 里的哪句话）。推的是**这个场地里会出现的东西**，不是品类的通用母题（SKILL.md 红旗：科学节别用元素周期表）。
3. **一次问完**：出牌前把假设行列成一条消息请使用者确认——"这 10 件是我按活动类型推的，请划掉没有的、补上真有的"。没回音就带着"假设"往下走，不阻塞抽牌。
4. **假设只决定外观，不进页面文字**：标签（§4）、`choose --reason`（点名的若是假设行，要说明）、方向借用的物件、留哪些品类道具（§8.1）可以来自假设行；页面上的名字、数字、楼层、路线只来自事实。`DESIGN.md` 的盘点表保留"状态"列和使用者的确认结果。
5. 拿到真照片或平面图后，把"假设"改成"已证实"或删掉；外观要调就 `draw.py adjust`，不要重抽。

## 4. 从盘点到抽牌：标签词表 / From inventory to the draw: the tag vocabulary

**规则**

1. 盘点表每行贴 1–3 个标签，只用下表的词。词表与 `library/directions.json` 各方向的 `fits` 共用；拿不准某个标签有没有方向承接，跑 `draw.py list` 看各方向的 `fits`，没人认的标签等于没给（`draw.py` 会提示"tag(s) … match no direction's `fits`"并列出已知标签）。
2. 数各标签出现的次数，取最多的 3–6 个传给 `draw.py --tags`。`draw.py` 的标签权重 = 0.5 + 1.5 × 命中数 / 给出数（不给标签则为 1），所以每多给一个不贴切的标签，命中比例就被稀释；标签只改权重，不决定结果。
3. 约束类实物（Q5、Q7、Q8、Q12）不贴标签，进测试。
4. `choose --reason` 必须点名盘点表里的一件实物，如"201 门口那条红墙带"，不是"更有活力"。

**怎么在新项目里做分叉**

- 用 `draw.py` 抽三张牌，这就是自动化的分叉：三张牌借用三套不同的现实系统，而不是三种 logo 形状。
- 手工分叉：先列 6 个机制，挑差别最大的三个，至少覆盖三个材料族（纸、金属、织物、光、玻璃……），不要三个都是"暖纸 + 墨"。原站没做但可以做的：图书馆目录、线路图、报纸、实验室 / 元素周期表、剧院票务、种子包 / 标本集（方向池里的对应 id 以 `directions.json` 为准）。
- **色相也是分叉的一部分（色相家族）**。方向的配色不是一个固定的色，而是这种机制的真实活动可能拥有的 2–4 个**色相家族**：`b`（强调）必有，`paper` / `a` 在机制允许时也有（图书卡印台：紫 | 红 | 绿；纹章釉色：gules | vert | purpure，azure 留给 `a`；展签墙：松绿 | 牛血红 | 普鲁士蓝；新闻纸：粉 | 灰绿；赛道：红褐 | 蓝 | 紫；蓝图修订笔：橙 | 红 | 荧光黄；孔版：三组纸 + 墨对；线路牌：黄 | 橙 | 绿。全表以 `draw.py list` 与 `directions.json` 的 `names` 为准）。`draw.py` 每次先抽家族（每个角色花一次随机数，只有一个家族也花），再在家族内取色相，所以同一个方向的两个项目不会都是同一个强调色，而且 `--keep` / `adjust` 不会让别的值跟着动。牌面表里的 `family` 列、每张牌的 "hue family" 行、`DESIGN.md` 和样张都写着抽到的家族名。`varsity`（原站）只有一个家族。
- **家族是候选，物件才是依据**。盘点里有已经定了色的东西——墙上的色带（Q2）、实体色表（Q9）、上一届的主色（Q5）、手边的印台或橡皮章——先把它翻成约束：品牌色抽牌前 `--keep palette=` 或 `b=#hex`；选定后才发现牌上的家族与物件不符，用 `draw.py adjust b=#hex --reason "…"`（记进 `adjusted`），不重抽。`choose --reason` 点名的物件若有颜色，对照牌上的家族名。
- 方向自己的 `idea` / `specimen_note` / `richness` 只点名**每个家族都成立**的颜色词（`kit.py --validate` 会查，并要求 `climb` 在每个家族配对里离 `b` ≥ 53°）；样张文字里没写颜色，颜色以牌上的家族和你的物件为准。写新方向或改家族：`palette.b.h` 写成 `[[lo, hi], …]`（2–4 段）；`climb` 用 `"follow": "b"` 跟着同序号的家族，`night` 跟 `paper` 或 `a`（家族数必须相同）；`names` 给每个家族起名（牌面上显示）；改完跑 `python3 scripts/kit.py --validate`。
- 每张牌用同一份真数据出样张再比较：`specimen.py --venue 你的 venue.json`（`--entity ID` 指定长页样本，默认取名字最长的那个）；只比名字，得到的是名字的平均印象。

## 6. 解释成本与最差物件测试 / Explanation cost and the worst-case-object test

**解释成本**：隐喻每多一个物件需要说一句"这张邀请函是登机牌"，就多一份成本。D 不需要映射表，因为它的"隐喻"是活动自己的名词，就印在门上的数字上。A 要翻译信封、邮戳、邮编；B 要翻译盾、盾头饰带、分区图形印章；C 要翻译 FIDS 屏、登机牌、护照章、登机口牌。

**测试流程**

1. 列出这个活动的最差物件（Q7）。场馆类活动的最小集合：5 m 外的门牌、双语标签、实体页头、地图上的实体标记、分隔线、统计行；再按活动补：单色印章、32 px 图标、3:1 的 LED、A 型立牌、胸牌、黑白复印件、手机深色模式。
2. 每张牌对每件物件写一行：怎么做、要不要解释。
3. 数"需要一句解释"的物件数，选少的那张（§12 推断原站的选择最看重这一条）。
4. 最丑的物件做不出来的方向，淘汰或换参数，不靠"主视觉好看"撑着。

**5 m 门牌测试：用测量代替口味**（原站 D 板）

- 数字高 64 mm，观看距离 5 m，对应视角 44′。
- 以每弧分 5 px 渲染，高斯模糊 σ = 最小可分辨角 / 2，模拟视力 0.5 和 0.2 两档。
- 数字对相似度 = 模糊后亮度图（裁到字形边界）的相关系数，越低越不易混。只测实际会出现的数字对。
- 原站结果（C1 → C1a，视力 0.5 / 0.2）：3 与 8 由 .68 / .81 降到 .39 / .36；4 与 1 由 .49 / .62 降到 .10 / .19；5 与 6 基本没变（.73 → .74，.84 → .81），房号里没有 6。
- 它帮原站找到真正的原因：外轮廓连在一起、反白小岛、闭合的内孔。没有记录说它在现实里走过 5 m，这是模拟。
- 备选：1:1 打印后退到 5 m 看；OCR 混淆矩阵；找陌生人测；眯眼看 8 px 缩略图。

## 7. 一个可拥有的装置，跨媒介复用 / One ownable device, reused across media

**原则**：一个概念 → 一个装置 → 克制的执行。装置要满足三点：小孩能凭记忆画个大概；单色、32 px 下还认得出；在 ≥ 5 种物件上是**同一个文件**，不是五次重画。

**原站取值：倒角数字**。同一套图形既是 logo，又是房号（门牌、桌牌、LED）、英雄统计（"03 / 10 / 52")和印章主体。

**构造：先画主角，再提参数，再程序化生成其余字母**

| 参数 | 原站取值（字高 100 单位） | 备选 / 区间（来自原站的不同版本） |
|---|---|---|
| 竖笔 / 横笔 | SV 18.0 / SH 14.5 | 任意，但整套字母共用 |
| 外凸角切口 / 内凹角切口 | CO 7.0 / CI 3.0；每个凸角切 `min(CO, 0.3 × 邻边)`，凹角只在两边都 ≥ 20 时切 | — |
| 外缘（深蓝） | 7.4（定稿）；早期构造 4.4–4.5 | 4.4 – 7.4 |
| 细线（纸白） | 3.0 | — |
| 数字间距 | 22 单位，每个数字是独立贴章 | 必须大于外缘，否则围出白色小岛 |
| 内孔开口 | 叠层后可见 ≥ 19 单位（8 的上孔 19.7 × 16.2） | 以 16 px 压力测试为准 |
| 撇号 | 一枚楔形，28 单位 = 28% 字高，顶端与数字齐平 | 次级字形不超过 ~30% |

- 外缘、细线是对字面并集做**斜接偏移**得到，不是描边。外缘再做 `buffer(+5).buffer(-5)` 填掉小缺口。
- 同一套字母画 CF、28、SDSZ COLLEGE FAIR、CLASS OF 2028；字母由数字衍生，所以字标属于数字这一家。词标可解字距对齐到精确宽度；每种用途一个变体（标志、徽章、竖版、横版、小号、印章、单色、反白）。
- 全部是 `<path>`，没有 `<text>`，所以能刻章、能激光切、能上 LED；印章与封签的 SVG 里直接写物理尺寸（`35mm × 44.33mm`）。

**把最贵的渲染配给功能与品牌重合的地方**

- 原站取值：三层缝线**只给 logo 和房号**，其余（楼层数字、统计、章、图标、箭头）都是实心平涂。
- 小尺寸有降级：≤ 48 px 用实心双色、无细线、无外缘、无词标；≥ 64 px 再用三层版。
- 每种底色该消失哪一层要写清：纸上全三层；深蓝上外缘并入底色，只剩面 + 细线；实心版用于楼层、统计、小尺寸；红底上原站板写"实心白"，而成品桌牌直接把三层数字放到红底上（红面隐入底色）——这是原站里文字与成品不一致的地方，选一种写进规格。
- 备选的"贵渲染"：偏移双色影、内描边高光、浮雕、半调、烫金。无论选哪个，限定在 1–2 处。

**一个容器形状，由物件短边的比例推出**

- 原站取值：45° 切角，约短边的 14%。实测：印章 250 × 180、切角 26（14.4%）；徽章宽 300、切角 36（12%）；封签 480 × 360、切角 48（13.3%）；区间 12% – 14.4%。
- 网页按钮 `--cut: 8px` 八边形；地图房间用双层 `clip-path`，外 10 px，内 **8.8 px**（= 10 − 2 × (2 − √2)，推算），让 2 px 轮廓在转角处仍是 2 px。
- 备选：直角、固定小圆角、胶囊、票根缺口、折角、齿孔边。

**一条签名分隔线，按物件缩放**

- 原站取值：班级条纹，深蓝 / 纸白 / 红 / 纸白 / 深蓝，印刷 32:10:16:10:32，网页 30:10:20:10:30（两处不一致，是原站的未修项），取自学院围巾的色条比例，平涂无纹理，只做分隔与边缘。
- 条纹总厚度占物件高度的比例（原站实测）：目录 1.3%、A3 地图 2.5%、立牌 2.5%、桌牌 3.2%、LED 4.2%、走廊牌 6.0%、邀请函正面 7.0%、信封 8.8%。区间 1.3% – 8.8%。
- 备选：两色细线对、三条袖口线、票根齿孔边、带数据刻度的线、按楼层变色的轨道。
- 红蓝并置会"振动"（红在深蓝上 2.47:1，推算），所以用纸白隔开。你的色板如果没有这个问题，分隔线可以不要这一层。

**用印刷件当网页的模板**：首页 = 入口 LED，实体页 = 桌牌，列表 = 门牌，地图 = 平面图模板。移植细节见 `print-parity.md`。

## 8. 删减即设计 / Deletion as design（C1 → C1a）

选定之后，评审的工作是减法，直到只剩装置和网格："The rest is paper."

**原站的七条修订意见**（每条都删掉一处"在模仿球队商店"的地方）：① 删除所有中文活动名；② 撇号从"帽 + 长刺（约 45% 字高）"改成一枚楔形，28 单位 = 28% 字高；③ 重画数字（3 = 两个碗；8 的上孔可见开口 5.4 → 19.7 × 16.2 单位；2 的上碗放大；2 与 8 之间原本纸白的缺口填深蓝，因为像破洞）；④ 新增 ≤ 48 px 的小号 logo；⑤ 做 5 m 门牌测试（§6）；⑥ 集章卡改成英文主行、双面、25 × 18 mm 房间章；⑦ 导视的燕尾旗箭头换成标准 90° 箭头，**删旗串、删 LED 上滚动的校名条**，说明板改纸白发丝线网格。同时气质"从球队周边收回到学院"，条纹"平涂，无纹理"，旗串、针织罗纹、滚动校名条全部删除。

**为什么会漂移**：强隐喻招来道具。校队 → 旗串、针织、字幕条，每件单看都合理，加起来成了周边商店。

**做法**

- 选定后专门跑一轮减法：列出每个"非文字的图形元素"，问它是装置、网格，还是在模仿隐喻的道具。
- 备选（原站没用）：给每个物件设预算，如"最多 3 个装置"；做**装置普查**（每个模板的非文字图形元素个数，目标 ≤ 4）。
- 原站成品的"不做清单"：无渐变、物件上无投影、无纹理、无照片、无插画、无圆角、无第三色、无旗串 / 飘带 / 针织、无滚动字幕；唯一的装饰是条纹和红色短尾线。这是**项目的**选择，写进项目的 DESIGN.md；另一种合理做法是留一个被许可的装饰族（纸纹，或一种手绘插图）。

### 8.1 方向自带的品类道具：盘点里有依据才留 / Category props: keep one only if the inventory supports it

方向借用的那套现实物件里，有两类东西。**机制**是它之所以成立的部分（孔版的套印、纹章的盾面分区、出发板的翻牌格）；**品类母题**是这一品类的人一眼认得的装饰（标本的叶形标签、孔版的网点、纹章的盾形、航空信的斜纹条、出发板的条码）。母题不是每个活动都有对应的物件：博物馆夜场借标本台纸的机制没问题，页面上到处是叶子就是"母题来自品类"（SKILL 红旗）。所以每个方向把自己的品类母题列成可开关的**道具**。

- **在哪**：`library/directions.json` 每个方向的 `props: [{name, var, off, what}]`（每个方向 2–4 项；`kit.py --validate` 列出全部，`draw.py` 的牌面每张牌一行）。配方里一律写成 `var(--prop-x, 开的值)` 来读，**从不自己声明**（tokens.css 先加载，配方里的声明会盖掉关闭值）；`off` 是一个裸 CSS 值：存在型写 `none`，尺度型写 `0`，其余写一个中性值（herbarium 的叶形标签 `--prop-leaf: 3px` = 方角小签）。
- **默认全开**：样张、`draw.py` 的牌面（每张牌打印一行 props）、`install.py` 写出的 `tokens.css` 都是开的，`tokens.css` 的 `:root` 末尾带着每一项**已写好的注释行**。`specimen.py --props off`（或样张上的 Props 钮、`?props=off`）看这张牌去掉全部母题的样子，先比再定。
- **逐项对盘点**：每一项问"盘点表里哪一行支撑它？"。有——事实行，或已向使用者确认的假设行（§3.1）——就留，把依据记进 `DESIGN.md`（"strips：盘点第 1 行，展签角上的馆藏登录号"）；没有就关。关一项只改一处：去掉 `evk/tokens.css` 末尾那一行的注释符号（`--prop-leaf: 3px;`），或在 `recipe.css` 之后加一条 `:root { --prop-leaf: 3px; }`；`install.py --update` 保留你已打开的行。关掉的写进 `DESIGN.md` 的 Deviations 表，写明依据与还原法。
- **关完还成立吗**：成立——少一件道具的牌通常更稳（§8 的减法）；关掉就塌了（出发板去掉翻牌格就不是出发板），说明机制与活动不合，是方向问题，回 §6 的最差物件测试，不要靠开关补。
- **只关道具，不关机制**：`--prop-*` 之外的东西（配色结构、字体、实体页头形式）仍是这张牌的身份；要改它们用 `draw.py adjust`，不要手改配方。
- 试跑里的例子：herbarium 抽给"博物馆夜场"，盘点里有展签角的馆藏登录号（支撑穿孔采集签 `strips`），没有植物（叶形标签 `leaf` 改成方角）——当时是手改配方 CSS，现在是一行 `--prop-leaf: 3px`。

落选方案是一个**规则零件箱**。以下迁移是从原站文件推断的（推断），不是原站写下的决定。

| 来源 | 落选方案里的规则 | D 里的落点 |

| B | 红与蓝之间隔一道纸白，宽 = 红块高的 1/14；红蓝直接相接一律禁止 | 三层数字的 3 单位纸白细线；条纹深蓝 / 纸白 / 红 / 纸白 / 深蓝。实测红在深蓝上 2.47:1（推算），纸白线是解法。此规则在 D 的模板里并不绝对：桌牌条纹的最后一道深蓝直接压在红带上 |

## 12. 选择理由与记录 / Choosing and recording the reason

**原站发生了什么**：评审排名 C > A > B > D，建成的是 D，没有任何文档记录为什么。以下是从文件推断的（推断）：只有 D 的同一个画出来的资产同时是 logo、门牌、统计数字、楼层数字和印章（B 的纹章笔、C 的翻牌砖都需要一层"翻译"）；它以最低成本通过 brief 里最难的媒介（单色可雕刻章、32 px、5 m 门牌）；语气是美式校园、学院、自信、年轻，观众就是一个真的会用 "Class of" 的年级（A 偏怀旧邮政，B 偏学术纹章，最接近被禁的霍格沃茨，C 偏企业交通）；零隐喻开销（§6）。

**教训**：评审的名次和主人的选择可以不同；观众自己的名词（所有权）压过借来隐喻的精致度。选的理由要写下来。

**做法**

- `draw.py choose N --reason "…"` 的理由必须点名盘点表里的一件实物。
- 在 DESIGN.md 记录：盘点表、三张牌、选哪张、理由、落选牌各一条值得偷的规则（§9）。
- 几张牌难分高下时，用打分表并公布分数（备选做法，原站没用）：媒介适配（最差物件通过率）、解释成本、可拥有程度、制作成本、团队会不会做，五项各 1–5 分，权重自定（建议前两项最高）；或把两个 logo 在真实门牌距离下打印出来让用户看。
