# 微细节目录 / Craft Details

"用了没人说得出名字，不用都觉得哪里不对"的那一层。来自 SDSZ College Fair 站（Varsity '28），按层归类。

怎么读：
- 每条三段：**原站**（= 原站取值 / source value，一个实例）→ **原则**（要带走的）→ **可换**（别的方向会怎么做，2–4 个真选项）。
- 带走原则，不带走数值。抽到的方向在 `DESIGN.md` 里给自己的值；每一层至少有两处与原站不同，且来自方向，不是随手改。
- 同一层只用一套惯例（切角按钮配胶囊搜索框会散）。
- 字号、窄屏、可点尺寸的下限以 `references/floor.md` 为准；原站的软肋标"软肋"，别当取值抄。
- 标 (套件补充) 的是原站没做、`base.css` 补上的；标 (推算) 的是按原站数值算出来的。只有"原站 + 原则"的条目是正确性，没有可换。

## 1. 颜色 / Colour

- **C01 纸不是白** 原站：页面 `#F7F5F0`，面板 `#ECE8DF`；纯白只在地图房间填充与印刷里。原则：纸取微暖或微冷的非纯白，再留一档更暗的做面板。可换：冷灰白 + 单一热强调；牛皮纸 + 奶油；有色底（淡蓝、淡绿）；深色优先，纸色作反相。
- **C02 三档文字** 原站：标题深蓝 13.32、正文墨 16.47、次级 5.63，靠色相 + 明度分层，不靠加粗。原则：正文、标题、次级是三个令牌。可换：标题与正文同墨、靠字重；标题用强调色、正文中性；只两档。
- **C03 链接** 原站：标题色字 + 2px 强调色下划线，`text-underline-offset:.22em`；hover 才变色，且在 `hover:hover` 里。原则：靠下划线颜色被找到，不靠蓝。可换：强调色字、hover 才出线；背景渐变荧光笔条（4px、30% 高）；虚线下划线 + 箭头。
- **C04 面的阶梯与阴影配额** 原站：纸 → 淡面 → 深面；卡片不抬升，平铺着色；只有两样东西浮起带阴影（弹层、浮出的目录），阴影染品牌色 `0 16px 44px rgba(19,41,75,.24)`。原则：先决定谁有资格浮起。可换：每卡 1px 描边、零阴影；三级纸堆叠阴影；硬偏移阴影（4px 4px 0）；只靠明度抬升（暗色）。
- **C05 强调色预算** 原站：红 = 这里 / 现在 / 去做（链接下划线、当前导航、序号、房号、焦点、主按钮、房号带、弹层帽、选中框）；深蓝 = 结构（标题、顶线、面板）。红字永远短（数字、一两个词）。原则：每个饱和色有一份语义清单，清单很短。可换：强调 = "新 / 未读"；两个强调（行动 + 状态）；强调只给图标。
- **C06 面积比例** 原站（设计板）：纸 46 / 深蓝 30 / 红 18。原则：纸占面积、墨占注意力，把比例画成一个条发布。可换：墨为主的夜间系统；红为主的活动海报；屏幕与印刷各一个比例。
- **C07 相撞配对公布** 原站：红对深蓝 2.47，两者亮度相近会震；之间隔粉笔白关键线 / 条纹留白；红字不放蓝底，深蓝条上的红标签另用 `#FF8A99`。原则：算出每个被允许的配对，公布禁用配对。可换：用邻近色相避免相撞；加一个中介色；靠形状而不是色分隔。
- **C08 第三色只给一个功能** 原站：琥珀 = 爬楼梯，字 `#B45309`、图 `#D97706`、深色 `#FBBF24`，字比图深（套件里字 = `--climb-text`，图 = `--climb`，floor F02 / F03）。原则：若允许一个多余的颜色，给最需要"第三种状态"的功能。可换：给"正在进行 / 你在这"；给警告；不用第三色，用线型（虚线）区分。
- **C09 极性反转靠重定令牌** 原站：访谈带容器上重定 9 个令牌，里面所有块自动反白；次要字用 `opacity:.82`，不再引入新灰。原则：组件只引用语义令牌，容器换令牌就换极性。可换：浅色反相（实体淡底 + 墨字，不用推导对比）；语录墙；左右分栏。
- **C10 班级条纹** 原站：`linear-gradient(navy 0 30%, chalk 0 40%, red 0 60%, chalk 0 70%, navy 0)`，3:1:2:1:3，硬停靠；用在欢迎块下、页脚 10px、无图实体页的头部、投票条帽 8px。深色里外侧蓝带与地面仅 1.16:1，读成"白-红-白"（推算）。原则：全站只给一个有边界的装饰母题，同时承担分隔 / 页脚 / 空状态。可换：重复图案带；波浪或扇贝边；3px 双线；齿孔线；无。

## 2. 字 / Type

- **T01 按功能分配声音** 原站：名字与数字 slab 600/700；标签加宽 sans 全大写；正文系统 sans；中文设备黑体；中文衬线只给报告章标题与引语。原则：字体按"它在说什么"分，不按页面分。可换：衬线 + 黑体两声（标签 = 正文的小型大写）；等宽出数字与房号；一个可变字族走光学字号；几何无衬线 + 人文体正文。
- **T02 字距随字号翻转** 原站：见 0.1。原则：大字收紧、小字全大写放开、中文标题略放开（+.04 到 +.08em）。可换：统一字距；只给全大写加字距；所有标题负字距。
- **T03 行高随字号翻转** 原站：桌牌 .86、数字 .8、标题 1.0、区块 1.15、正文 1.7、长中文 1.85。原则：越大越紧，中文成段要松。可换：全站 1.5；正文 1.6 / 中文 2.0。
- **T04 标签带里的微档** 原站：.54 到 .76rem 之间有十几个不同角色，大字只有少数几档且全用 `clamp()`。原则：每个角色一档，不套模数。可换：严格 1.25 模数 6 档；流体 `--step-n`（本套件令牌 `--step--1…--step-5`）；更大更少的标签（≥ 12px，句首大写）；全小写无字距。
- **T05 标题用 vw 夹值** 原站：中间值取 vw，使 4 字符的名字在 375 宽的列里占约 70%；上限 144px。原则：大字随视口增长到封顶，正文用 rem。可换：容器查询单位 `cqi`；断点分档；JS 收缩到合适。
- **T06 按名字长度分档** 原站：≤ 4 字符 19vw、≤ 7 为 14vw、≤ 12 为 10.5vw、更长 8.2vw（每档约 ×0.75），`overflow-wrap:anywhere` 兜底；52 个短名分布 12 / 13 / 21 / 6。原则：构建期按字符数分档，不依赖 JS，不抖动。可换：`ResizeObserver` 收缩；`text-wrap:balance` 配中号；压缩字宽轴；竖排。
- **T07 数据用对齐数字** 原站：`lining-nums tabular-nums` 用在数字条、章号、时间线、数字卡（slab 默认是老式数字，3 会掉到基线下）。原则：凡是被比较的数字都开。可换：正文老式、表格对齐；等宽数字面；仅 tabular。
- **T08 专有名词保持原字体** 原站：中文句里的英文活动名仍用 slab 600，`letter-spacing:0`。原则：品牌名走到哪都是品牌字体。可换：品牌名加下划线或换色；不特殊处理。
- **T09 标题由作者断行** 原站：`["Class of 2028,", "meet your colleges."]` 渲染为 `<br>`，不靠自动折行。原则：标题节奏是写出来的。可换：`text-wrap:balance`；关键词换色；一行跑马。
- **T10 居中大写的光学修正** 原站：居中的加字距大写行加 `margin-right:-.22em`（中文 −.12em），抵消末尾字距。原则：尾部字距会把行推偏。可换：用 `padding-left` 补偿；不居中。
- **T11 字体裁剪** 原站：Latin 子集，宽度轴钉在 125、字重 500–800，WOFF2 共约 75 KB；仅预加载两个；`font-display:swap`；回落同流派（slab → Rockwell → Georgia）。原则：只带用到的字符与轴。可换：整套可变字体 + `font-size-adjust`；纯系统字体；动态 CJK 子集；标题用 SVG。
- **T12 粗体 = 变色 + 变粗** 原站：`strong{color:var(--head)}`。原则：强调在松行距里要靠颜色，不只靠字重。可换：下划线高亮；只加粗。
- **T13 引用上标** 原站：`.cite{font-size:.62em;line-height:0;vertical-align:super}`，无下划线，用实体字色。原则：`line-height:0` 才不撑开行距。可换：方括号行内；边注；悬停卡。
- **T14 中文衬线保留给"阅读"** 原站：仅章标题（700, +.04em）与引语（700, 1.18rem/1.7）。原则：一个额外字体只服务一种内容语域，切换字体 = "现在在读，不在导航"。可换：拉丁斜体衬线引语；手写体；同一黑体放大加线；标签体全大写。

## 3. 双语对的尺寸 / Bilingual pair metrics

- **B01 四种姿势** 原站：①行内基线（`.k`：英文 .74rem/.2em + 中文 .66rem/.12em，`column-gap:.65em`，中文可折到下一行，`row-gap:2px`）；②上下叠（导航、数字条说明、行标题 + 副标）；③英文巨大 + 中文小（桌牌）；④英文小标签 + 中文大标题（章首）。原则：先定有限几种姿势，再规定谁灰谁黑谁大写。可换：全部行内；中文永远在上；英文只作 `<abbr>`；左右两栏。
- **B02 主辅比的实际数值** 原站（英文 / 中文）：标签 1.12、导航 1.13、按钮 1.06、区块标题 1.83、行 1.37、格 1.32、桌牌 1.21–1.33；小号大写反过来：数字条说明 .58 / .72、步骤 .66 / .9。原则：名字与标题严格 ≥ 1.1，小号加宽大写靠光学字号。可换：全站 1.0–1.15（中文主）；同尺寸并排。套件把这个比做成两个旋钮 `--k-1` / `--k-2`（em）：`lead=en` 主 1 / 副 .9，`lead=zh` 主 1.1 / 副 .86，副行不小于 11 px。
- **B03 辅语处理单** 原站：`--sub` 色、字重 500（与旁边 700 大写笔画相近）、字距 .06–.12em、不转大写、字体切到 CJK 黑体。原则：辅语永远同一套处理。可换：辅语斜体；辅语放在徽章里；辅语只在悬停出现。
- **B04 量词补全** 原站："03 | 层楼"、"10 | 个展区"、"52 | 所大学"；区块标题 "52 Universities 所大学" 是一句话切成两种语言。原则：数字 + 英文名词 + 中文量词。可换：每种语言各出一个完整短语。
- **B05 中文是回答，不是翻译** 原站："Directions 怎么走"、"View on Map 在楼层导览中查看"、"Vote 为这个展位投票"。原则：英文给东西起名，中文回答最可能的问题。可换：直译；只英文；只中文。
- **B06 内容区不双语** 原站：标签与名字双语，报告正文只有中文原文。原则：双语的是标签和名字，不是段落。可换：全站内容双语 + 语言切换；每节作者定语言。
- **B07 中文先行的例外** 原站：主题路线列表中文 1.08rem 700 在上，英文 .82rem 在下并降到 .8 不透明度。原则：内容语言决定谁先。可换：整站中文先行（= `lead=zh`，见 B09）。
- **B08 活动只有一个名字** 原站：活动名只有英文，测试断言中文名不出现在外壳里。原则：规范名写进 brief，再写成测试。可换：双语规范名；代号做公共称呼。
- **B09 两层：角色层与文字层**（套件补充，`base.css` §1、§5） 原站把"英文主"写死在 `.en`、`.cn` 上。原则：**层级**（字号、字重、颜色、顺序）按位置：`.evk-k > :first-child` 为主、`:last-child:not(:first-child)` 为辅；**排印**（字体族、大小写、字距、断行）按语言：`.cn`、`[lang|=zh]`、`[lang|=ja]` 把 `--f-display` / `--f-label` / `--f-text` 改指 CJK 栈，`--label-case: none`、`--label-track: .1em`、`--display-track: 0`、`--display-leading: 1.25`，并永远直立。配方只改写第一层的选择器，不把大小、字重、颜色写在 `.en` / `.cn` 上；填色面上（按钮、选中的分段）设 `--k-2-ink: currentColor`，副行才跟着面上的字色走。**填色面里的配对继承该面的字色**（套件补充）：配方给纸面写 `.evk-k { color: var(--a-text) }` 没问题，但主按钮、按下的分段（`aria-selected` 与 `aria-pressed` 都算）、填色标签里的 `.evk-k` / `.en` / `.cn` 必须吃该面的 `color`。`base.css` 的 "FILLS" 规则（`.evk-btn .evk-k, .evk-seg > button .evk-k, .evk-tag .evk-k { color: inherit }`）已经做了，十二个配方各有一行注释指向它；配方不要在这三处再写颜色，否则字落在同色填充上消失（lessons C12）。验收：浅深各渲染这三样，字色对填充 ≥ 4.5。中文展示行要自带 `lang="zh-CN"` 或 `.cn`：`<html lang>` 与 `html` / `body` 被排除在外，不会整页换字体。大字拉丁名用 `letter-spacing: var(--track-tight, -.02em)`、`line-height: var(--lead-tight, .9)`，这样中文行自动得到 0 字距和 1.15 行高（CJK 不用负字距）。可换：只在第一层用 `data-evk-lead` 属性选择器分支（不推荐，每个配方都要再写一遍）。
- **B10 `lead=zh` 的写法** 格子 = 标记、主行、副行、位置码，按位置读（中文名写第一位，`.name` / `.cn` / `.en` 只管排印）；标签与导航中文主 1.1em，拉丁副行是小标签；按钮里中文主、拉丁副（颜色随按钮字色）；章头：中文标题为主，拉丁眉标退成小标签（`reading.md` §4.2）；地图标签随 `VenueMap` 的 `lead`；目录面板由 `partNav` 按章头配对的顺序生成。验收：把 `data-evk-lead` 翻一次，配对顺序随之对调，没有一个选择器需要改。

## 4. 线与母题 / Rules and motifs

- **R01 开头粗、中间细** 原站：列表顶线 2px、行线 1px；弹层顶 6px；表头 2px、行 1px。原则：块的起点用重线，同级用轻线。可换：双线（3px 空 1px）做块起点；只用留白；虚线分次级。
- **R02 长条 + 短尾** 原站：滚动细线（2px，深蓝 + 末端 96px 红）、桌牌条（6px，深蓝 + 64px 红 / 实体页金）、地图页 4px + 96px、结果条。原则：一个"线带彩色尾巴"的母题在三个尺度重复。可换：起点圆点；渐隐尾；缺口箭头；两色虚线。
- **R03 方形记号与方头线帽** 原站：22×22 复选框（2px 框）、9×9 时间线节点、30×30 步骤方块、20×20 路线序号；`stroke-linecap="square"`，图标线宽 1.9–2.4。原则：终端形状选一次，线帽、记号、复选框全用。可换：圆点与圆帽；菱形；斜线；描边圈内数字。
- **R04 隐形左边线** 原站：每个网格首列的左内边距为 0，校徽 / 表格首列 / 数字条首格 / 行内文字都贴在 20px 页边。原则：页边是一条排版对齐线，色块和图片出血，文字回到这条线。可换：缩进一个字；全部内缩的卡片。
- **R05 左线粗细 = 重要性** 原站：引语 3px 全浓度实体色 + 衬线粗体；注记 2px 45% 浓度 + 小灰字；`.pending` 4px 强调色。原则：同一种"左线"用粗细与浓度分等级。可换：引语加巨大引号；注记配图标；注记放边栏。
- **R06 边框画的箭头，旋转后补偿** 原站：9×9 方，`border-width:0 2px 2px 0`，`rotate(45deg)`、`margin-top:-4px`，展开 `rotate(-135deg)`、`margin-top:4px`，.2s ease。原则：旋转中心会偏，同时改 margin。可换：加减号；旋转 SVG；"阅读更多"渐隐；标签页。
- **R07 表格只有横线** 原站：行线 1px，表头线 2px 实体色；首列不留左内边距；宽表 `min-width:620px`，首列 `sticky` 且背景 `var(--bg)`；容器 `tabindex=0 role=region`。原则：横线、表头更重、宽表滑动不缩字。可换：斑马纹；手机变堆叠小卡；固定表头；格内迷你条。
- **R08 品类道具可关（`--prop-*`）**（套件补充，`directions.json` 的 `props`） 原站：没有，母题（倒角数字、班级条纹）就是活动自己的名词。原则：方向借来的**品类母题**（叶形标签、网点、盾形、斜纹条、条码、格线……）不是每个活动都有依据，所以每个母题是一个自定义属性 `--prop-<名>`：配方一律 `var(--prop-x, 开的值)` 读、**从不声明**（`tokens.css` 先加载，配方里的声明会盖掉关闭值）；关闭值 `off` 是裸 CSS，存在型 `none`、尺度型 `0`、其余一个中性值（叶形标签关成 `3px` 方角），让元素退成中性而不是消失后留下错位；列进 `directions.json` 的 `props: [{name, var, off, what}]`，`kit.py --validate` 核对（配方读了没列的、列了没读的、自己声明了的，都报）。写新配方：先写读法，再把每一项设成 `off` 看版面塌不塌。验收：`specimen.py --props off` 看整张牌，再逐项 off，浅深各一。留哪些、依据是什么见 `derive.md` §8.1。可换：无，它是开关，不是风格。

## 5. 形状 / Shape

- **S01 切角只给可点的东西** 原站：按钮八边形 `--cut:8px`（`clip-path`），其余全部直角，只有校徽是圆。原则：给交互件一个独有轮廓，别处不用。可换：全胶囊按钮 + 方卡片；单角缺口；票据凹口；折角；齿孔边；4–6px 软圆角。
- **S02 切角 = 短边的比例** 原站（设计板）：切角取短边 14%；地图房间外 10px + 2px 内边距 + 内 8.8px，使轮廓处处 2px（8.8 = 10 − 2(2−√2)，推算）。原则：用比例定义，再算出内外偏移。可换：固定半径；椭圆端头；斜切一个角。
- **S03 重复丰富的渲染要配额** 原站：三层描边（红面 + 3u 粉笔白关键线 + 7.4u 深蓝边）只给标志和房号；其余扁平；≤ 48px 用单色小版。原则：把最贵的渲染留给"功能与品牌重合"的地方，并给小尺寸版本。可换：双色错位印刷；内描边高光；浮雕；半调；烫金。贴纸式点缀每页 ≤ 2 个，角度 ±2°。
- **S04 数字各自成章** 原站：房号每个数字独立（间距 22u），外缘不相连，计数孔 ≥ 19u；用 5 米模糊相关系数比较易混数字对（3-8 从 .68 降到 .39）。原则：数字先为远处可读设计，再谈品牌。可换：连字；等宽；斜体运动数字；放进牌子里。
- **S05 一个万能箭头** 原站：杆宽 = 高的 21%，90° 箭头头，旋转得到四向；红 = 去这里，深蓝 = 普通指向。原则：定义一次，旋转使用。可换：人字箭头；长尾；用条纹做箭头。
- **S06 不用渐变与模糊做内容** 原站：渐变只有条纹与滚动细线，模糊只有栏与提示。原则：装饰预算给一个品牌母题，颜色由内容提供。可换：纸纹；双色调照片；插画底；动态网格渐变。

## 6. 栏与滚动细线 / Bar and hairline-on-scroll

- **BR01 栏与页面同色，静止时无边** 原站：`position:sticky`，`--bar` = 纸 .9 透明度（暗 .88）+ `backdrop-filter:saturate(160%) blur(16px)`；高 56（36 + 2×10）。原则：栏颜色 = 地面颜色，内容滑过去才"存在"。可换：实色深色栏；向下滚动收起、向上滚动返回；透明叠在主图上再变实；常驻粗顶线。

- **BT08 分段控件放不下，就在自己里面横滑**（套件补充，`base.css` 的 `.evk-seg`） 原站：楼层钮三个，放得下。原则：`.evk-seg` 是 `inline-flex` + `max-width:100%` + `overflow-x:auto`，按钮 `white-space:nowrap`、高 ≥ `--hit`；六个楼层钮加一个路线钮在 320 px 也不撑宽页面（放它的网格列写 `minmax(0, 1fr)`，否则网格项按内容撑开）。配方给分段加圆角、描边、切角：圆角写 `border-radius`（横滑容器会随圆角裁切），描边用 `box-shadow: inset`，切角给**按钮**；**不要在 `.evk-seg` 上写 `overflow:hidden`**：它盖掉横滑，第 5、6 个钮被裁掉点不到。同类的小控件：`.evk-lines`（阅读导航钮）可点区 ≥ 44 × 44，配方改它的宽度时补 `min-width`。可换：下拉选楼层；竖向选层柱；楼层多时折成 `select`。

## 10. 实体页"桌牌" / Entity page table tent

- **E01 顺序** 原站：桌牌（名字）→ 主图或条纹 → 数字条 → 房号带 → "在哪"（文字 + 小地图）→ 报告 → 海报 → 翻页。原则：线上读到的先后 = 线下看到的先后。可换：证件卡（大头像 + 字段）；登机牌（目的地 + 票根）；书脊；档案抽屉标签。
- **E02 校徽是印章，名字在喊**（套件：名字字号由 `--name-min` / `--name-vw` / `--name-max` 三个旋钮和 `data-fit` 四档缩放定，配方不写 `font-size`，ux-contracts EP-2；名字之外的行是 `.evk-entity-sub` / `.evk-entity-line` / `.evk-entity-code`） 原站：校徽 52px（≥760 为 76）在右上角，名字 `.86` 行高的巨型 slab，色 = 实体字版色，其下一句 lede（34em，1.02rem/1.8）。可换：校徽大名字小；名字描边或偏移；名字后色块；名字竖排。
- **E03 名字下的签名条** 原站：6px 高、最宽 660px，实体填充色长条 + 64px 金色短尾；名字用字版色，条用填充色：同一色相的两个深度同屏。可换：条是校徽剪影；一条细线加一个方块；无条，靠字重对比；三段阶梯色条。
- **E04 主图** 原站：手机出血 4:3，桌面 16:9 且 `max-height:74vh`；`object-position:50% {focus_y}%` 逐图设；`srcset` + `sizes`；`width/height`；首图 eager，其余 lazy；占位底 = `--e-soft`；无照片时放一条条纹。可换：视差；双色调；校徽形状蒙版；轮播。
- **E05 数字条**（套件：`.evk-num` = `<b>` 数值 + 单位 `small` / `.unit` + 说明 `> span`，单位在数值里、说明是它的兄弟，不用 `.evk-num span` 一把抓） 原站：`dl`，数值在 DOM 里在标签后，`flex-direction:column-reverse` 显示成数值在上；手机 2 列（3 项时 3 列），≥760 `repeat(var(--n,4),1fr)`；数值 `clamp(1.55rem, 7.4vw, 2.5rem)` 实体字色、对齐数字；说明 .72rem 紧贴数值；首格无左线无左内边距。可换：一个超大主数字 + 三个小数字；横滑 chip；账本式；环形。
- **E06 房号带** 原站：整宽强调色块（手机出血），左边房号牌（高 `clamp(70px, 17vw, 128px)`），右边 "Room 203 · 2F" 与大号 booth 编号压在 3px 粉笔白下划线上；未定时换成"待公布"。可换：图钉卡；带齿孔的票根；贴在标题旁的小牌；底部粘性条。
- **E07 "在哪"** 原站：文字 30% + 小地图 70%（`.7fr / 1.3fr`，≥880），两个动作：怎么走、在地图上看。可换：整宽地图 + 浮动按钮；分步卡片；静态平面图。
- **E08 翻页** 原站：`1fr 1fr`，顶 2px，每格 `.k` + 名字 + 副标，按压 `.98`。可换：校徽 + 缩略图卡；无限滚动；主题路线推荐下一个。

## 11. 地图的 DOM 外壳 / The map's DOM chrome

- **M01 画布容器** 原站：`position:relative;overflow:hidden`，加载时底色用淡面（不闪白）；高度按 vh 夹值（整页 `clamp(440px, 74vh, 780px)`）；画布 `touch-action:pan-y`（竖划仍滚页面，横拖才旋转）、`cursor:grab / grabbing`、`tabindex=0 role=img`，`aria-label` 教怎么操作；聚焦内嵌 3px 环。可换：点一下才激活的遮罩；点开全屏；常驻 + / − / 旋转钮。
- **M02 一次性的手势提示** 原站：底部居中小药丸（`bottom:14px`，`padding:7px 13px`，栏的材质 + 14px 模糊，18px 拖动图标，"Drag to rotate 拖动旋转" .64rem/.14em），地图活起来才出现，首次拖动或 6 秒后淡出（.5s），不需要关闭；"Reset 复位"在右上，回到初始视角时 `hidden`。可换：手指动画演示；加载时自转 2 秒；"知道了"引导。
- **M03 楼层分段控件** 原站：2px 深蓝外框，按钮 `min-height:40`，`padding:0 14px`，右边线 2px，.72rem/.14em 全大写，选中 = 头色底 + 页面色字；"All 全部 · 1F 一层 · 2F 二层…"，每个 `aria-pressed`。可换：药丸 tab + 滑动滑块；地图旁的竖向楼层条；上下步进。
- **M04 提示条与名录卡** 原站：提示 = 面板色对（深蓝底粉笔白字），slab 600 .92rem + 中文 .72rem（.8 不透明度），`translate(-50%, -100%)` 在目标上方；名录卡 = 2px 框 + 房号牌（高 46）+ 编号列表，楼层从高到低，`repeat(auto-fill, minmax(300px, 1fr))`（≥760）。可换：白卡加阴影；引线标签；手风琴楼层。

## 12. 弹层 / Sheets

- **SH01 浮起的卡，不是贴边的板** 原站：`left/right/bottom:8px`，直角，顶 6px 强调色帽，`max-height:70vh`，底内边距加 `env(safe-area-inset-bottom)`，阴影染品牌色；≥880 变成右下角 400px 宽卡（right / bottom 24），抓手隐藏。可换：贴边 + 顶部圆角 + 暗幕；三档吸附（露头 / 半 / 满）；锚在被点房间上的气泡；常驻侧栏。
- **SH02 抓手区与滚动区分开** 原站：40×4 抓手，`margin:6px auto 10px`，不透明度 .5；只有抓手区 `touch-action:none;cursor:grab`，列表照常滚；忽略按钮 / 链接 / 选择框上的按下；`pointercancel` = 松手。可换：整张卡可拖（滚动到顶时）；仅 44px 抓手条。
- **SH03 伙伴而非模态** 原站：无暗幕、无焦点陷阱、地图保持可用，点另一个房间只换内容；一次只开一个弹层。可换：暗幕模态；锚定气泡；底部横幅。
- **SH04 离屏距离 = 高 + 24** 原站：离屏位置 = 弹层高 + 24px，阴影在静止时不探头；关闭从同一轴离开，比进入快。原则：进出同一条路径，退出更快。
- **SH05 模式与高度** 原站：规划态 `max-height:min(72vh,640px)`，行走态 `min(62vh,560px)`；矮手机（高 ≤ 720）只显示当前一步，并用 `:has()` 兜底（没有当前步骤时不隐藏任何一步）。套件改为：`(max-height: 900px)` 且窄屏起只显示当前步，行走态弹层 ≤ 54dvh（812 px 高的手机在 720 的门槛下只剩约 170 px 地图）；隐藏用 `visibility:hidden; height:0; overflow:hidden; margin:0; padding:0`，不用 `display:none`，后者会重置 CSS 计数器，每步都显示"1"。可换：全屏步进器；横滑步骤卡；常驻小横幅。
- **SH06 步骤行** 原站：20×20 方形序号（CSS 计数器），当前行 = 3px 左线 + 淡底 + 填充方块；爬楼步骤改爬升色（字比图深）；底部 Back | Overview | Next 三钮 `grid 1fr 1fr 1fr`，≥ 48px。可换：时间线节点；转向图标；仅加粗。
- **SH07 浮层共享一个签名** 原站：弹层顶 6px 强调色，目录面板顶 4px 实体色，`.pending` 左 4px：所有"浮起或提示"的东西都有一道色边。可换：圆角加软阴影；全屏菜单；侧滑抽屉。

## 13. 深色 / Dark mode

- **D01 品牌第二色当世界** 原站：地面 `#0D1D36`（比品牌深蓝再暗一档），品牌深蓝升为"抬升面"，文字暖白 `#EEEAE1`。原则：深色是品牌的反相，不是黑。可换：纯黑 OLED + 1px 边；暖炭灰；与品牌不同色相的有色暗底；"dim"模式（只降对比）。
- **D02 三级抬升与嵌套重定** 原站：`#0D1D36` → `#13294B` → `#1E3A66`；弹层与淡面同为 `#13294B` 时，在 `.sheet` 里重定 `--tint:#1E3A66`。可换：白色 alpha 叠层（.04 / .08 / .12）；边框代替填充；`color-mix(in oklab, bg, white 6%)`；毛玻璃层。
- **D03 填充红不变，字红提亮** 原站：见 floor F02。原则：每个强调色两个令牌，并在每个深色面上量字版。
- **D04 位图与 data-URI 的孪生** 原站：`<select>` 箭头 `%235B6270` ↔ `%23AEB6C6`；logo 贴纸通吃；SVG 数字深蓝与粉笔白互换、红不动。可换：`currentColor` SVG；CSS `mask-image`。
- **D05 两处声明** 原站：`@media (prefers-color-scheme: dark){:root:not([data-theme="light"]){…}}` + `:root[data-theme="dark"]{…}`；`color-scheme`；`theme-color` 两个。原站没有切换钮，`data-theme` 钩子在，要切换钮自己加。
- **D06 每个花哨效果有一行退路** 原站：`reduced-transparency`（栏与提示改实色）、`prefers-contrast: more`（`--rule` = 深蓝，`--sub` = `#3A404C` 9.55:1）各一小块。可换：`forced-colors` 系统色；用户可见的"减少效果"开关。

## 14. 密度 / Density

- **DN01 密度是设计目标** 原站：站立、单手、嘈杂的观众；手机首页缩短约 40%，靠布局（并排格、网格、三列数字、叠放按钮）而不是缩小可点件。可换：渐进展开；横向轮播；虚拟列表；底部 tab 外壳。
- **DN02 具体的减法** 原站：区块标题上边距 46 → 34，分组 36 → 22，地图 380–660 → 300–430，数字行三列，欢迎块塌成窄带，非当前路线步骤隐藏英文行。可换：折叠章节；摘要在先；卡片轮播。
- **DN03 间距节奏手调** 原站：无间距令牌；结构值落在 8 的倍数（56 / 64 / 88），簇内 8–28 随光学需要（`.field .val{padding-bottom:5px}`）。可换：4 / 8 点令牌 `--s-1…--s-8`；`clamp()` 流体间距；容器相对单位。
- **DN04 出血与边距线** 原站：父级 20px 边距，出血件 `margin:0 -20px` 并自带 `padding:… 20px`，≥760 把负边距归零。原则：色与图碰边，文字回到边距线。可换：CSS grid 命名出血线；`100vw`（小心滚动条）。

## 15. 断点 / Breakpoints

| 宽 | 原站在此改什么 |
|---|---|
| 手机基线 | 单列；20px 边距；出血；2 列校徽网格 |
| ≥ 640 | 提交按钮自适应宽（最小 260） |
| ≥ 700 | 3 列网格；报告卡 2 列；数字卡 `auto-fit` |
| ≥ 760 | 双栏列表；房号带去出血；照片不出血 + 16:9 / 21:9；校徽 76px；数字条一行；访谈带不出血 |
| ≤ 879 | 手机首页窄带、3 列数字、并排按钮、矮地图、弹层压缩 |
| ≥ 880 | 欢迎块 1 : 2.1；"在哪" .7fr : 1.3fr；弹层变角落卡 |
| ≥ 980 | 报告章 250px 粘性左栏 + 56 间距；小节导航变竖列 |
| ≥ 1000 / 1100 | 4 列网格 / 3 列报告卡 |
| 高 ≤ 720 且 ≤ 879（套件：高 ≤ 900） | 路线弹层只显示当前一步 |

原则：约 8 个宽度，每个对应一个具名部件的布局变化；移动优先；一个容器宽 1120。可换：容器查询到每个部件；只两个断点；`auto-fill` 无断点；桌面优先。

## 16. 文案即设计 / Copy as design

- **CP01 标签 1–2 个词，中文是回答** 见 B05。原则：按钮不超过两个英文词。可换：俏皮带 emoji；正式机构腔；图标代替文字；全是祈使动词（Find / Go / Vote）。
- **CP02 空与错的格式** 原站：说发生了什么 + 给一个例子或下一步："没有找到匹配的学校。可以试试英文缩写，例如 MIT、UCLA。"；"点赞和投票暂时无法使用，请稍后刷新页面。"；404 给出地址规则并列出入口。原则：不怪用户，给下一步。可换：插画 + CTA；骨架；行内提示。
- **CP03 不可撤销的话紧贴按钮** 原站："每台手机只能投一次，提交后不能修改。" 在提交按钮正下方。
- **CP04 待定也写出来** 原站："待定"代替空白；"To be announced / 展位位置将在活动前公布"；数量 0 什么都不印。
- **CP05 标题的语气** 原站：第二人称、逗号断行、句号收尾："Class of 2028, / meet your colleges."；中文是平实翻译，不是口号。可换：名词短语标签；提问；幽默；邀请函体。
- **CP06 语言里的空格** 原站：生成的每句中文在汉字与拉丁 / 数字间补空格（"走到 301 门口"）；模板里汉字间的空白在构建时去掉。**只要是拼出来的句子都过这一道**：路线句、搜索例子、样张与页面的位置摘要（"在二层东回廊"，不是"在二层 东回廊"），拉丁与汉字交界处恰好一个空格。可换：`text-autospace`；发丝空格。

## 17. 其余不被注意的 / Smaller still

一行一条，都是原站的做法；没有"可换"，因为它们是正确性。

- `img, svg{max-width:100%}`；`[hidden]{display:none!important}`。
- 空计数 `.likes:empty{display:none}`；`.vh` 给读屏用，1px 裁剪。
- `overflow-wrap:anywhere` 用在巨型名字、数字条的数字、来源条目（长 URL）；`min-width:0` 给所有网格子项。
- 图片写 `width/height`；占位底用实体淡色而不是灰；校徽缺失时留同尺寸的淡面圆，网格不位移。
- `li:target{background:var(--e-tint)}`：被引用的来源条目落地后高亮；`scroll-margin-top` 在每个锚点目标上。
- 打印隐藏栏、地图、按钮，背景强制白。
- 路线虚线：`[0.8w, 2.4w]` 随时间位移约 36px/s；爬升连接线虚线 `[6,6]` 约 25px/s；减弱动效时冻结。
- 选中文字、滚动条、光标颜色随令牌（套件补充，`base.css`）。
