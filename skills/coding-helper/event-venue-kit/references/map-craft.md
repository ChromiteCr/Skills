# 场地图手艺 / Venue Map Craft

> 给 `EVK.VenueMap`（`assets/engine/venue-map.js`）和任何要自己写场地图的人。原站是 2D canvas + 画家算法 + 手写 15 行透视，没有任何库。
> 本文把原站每个"让地图好看又好用"的决定拆成两半：**原理**（保留）和 **原站取值 / source value**（一个实例；范围与换法写在同一行）。
> 读法：先读 §0；再按 `--m-projection` 跳 §15，按 `--m-material` 跳 §14；做路线读 §10。
> 标注：`k` = 该点每米的屏幕像素；**(推算)** = 由原站常数算出、原站没写；**(本套件设计)** = 原站没有，为其他材质/标记/投影补的做法，数值是起点不是定论。

## 0 不变量与可选轴 / Invariants and choice axes

**不变量**（质量原则，不是风格；任何材质和投影下都保留）：

1. 一份米制共用平面；墙、门、竖井由集合运算从同一来源派生，构建期校验（§1）。
2. 功能进几何：能进的空心，不能进的实心（§1.3）。
3. 动效 = 从当前位置和速度出发的弹簧；手势把目标归零；松手带速度；限位用橡皮筋（§3）。
4. 静止不重绘；离屏不动；每个异步资源有重绘钩子（§12）。
5. 与页面谈手势：竖滑归页面，单指横滑转动（oblique 为平移，§15），双指才倾斜，ctrl+滚轮才缩放（§3.3）。
6. 标记是公告牌：`clamp(米数×k, min, max)`，总览封顶更低（§7.1）。
7. 场景内文字用晕边，不用盒子：先描边后填充，`lineJoin: round`（§7.6）。
8. 一个意义一种颜色；强调是梯度，细节渐隐不消失（§5.6、§8）。
9. 路线和楼层数字是独立的一遍，画在场景之后，永不被遮（§6.3、§10）。
10. 减弱动效 = 同一终态、无行程；每个动画调用都有瞬时路径（§3.6）。
11. 地图不是唯一入口：同一份数据必须有文本名录（`ux-contracts.md` Z）。
12. 命中区大于视觉；点按 = 位移 < 7 px 且 < 600 ms（§8.2）。

**可选轴**（令牌驱动，抽牌会变）：

| 令牌 | 取值 | 本文 |
|---|---|---|
| `--m-projection` | orbit / oblique / exploded / plan（brief 说"可旋转" = `--keep projection=rotate` = orbit 或 exploded；`3d` 还含 oblique） | §15 |
| `--m-material` | paper / line / clay / blueprint / riso | §14 |
| `--m-token` | badge / pin / plate / dot / flag / stamp | §7.2 |

| `--m-cap` `--m-wall` | 墙帽与墨线（对 `--m-slab` ≥ 7:1）/ 墙面基色（≥ 3:1）；浅深各一 | §5.1、§5.7 |

## 1 场景模型 / Scene model

### 1.1 一张共用平面
原站取值：单位米，x 向东、y 向南；三层**同一外轮廓** `[[0,0],[28.4,0],[28.4,18.0],[16.1,18.0],[16.1,34.5],[0,34.5]]`（28.4×34.5 m 的 L 形）；楼梯、电梯、小块盒子三层逐字节相同。
原理：共享的东西靠构造对齐——叠层后楼梯成垂直柱，眼睛读到一栋楼，竖井（§9）才能是直棱柱。换法：每层不同轮廓；单底图 + 每层蒙版；环形校园。

### 1.2 真实比例，只简化语义
原站坐标精度 0.05 m，保留测量的不规则（201–203 宽 7.05，301–303 宽 6.95）；到场的人认得出走廊。**没有平面图就问要**；实在没有只画示意，并标"示意图 / Schematic"。换法：2 m 网格"玩具积木"；种子过程生成；只保拓扑的示意图。

### 1.3 空心 = 能进，实心 = 不进
| 类型 | 画法 | 原站取值 |
|---|---|---|
| `rooms[]`（可进的展区） | 地面 `--m-room` + 低墙 + 门洞，内部露出标记 | 墙高 1.0 m |
| `blocks[]`（stairs / lift / wc / office / solid） | 实心挤出，无内部 | 高 1.15 m（墙高 ×1.15） |
| 走廊（无名字、无展位） | 不画，剩下的楼板就是走廊 | 本场地未用 `corridor` |
| `areas[]`（走廊、中庭地面、大厅：要命名、要放展位、要写进路线文案的无墙可走区） | 无墙无门，不产生墙；虚线（`corridor`）或点线（`open`）的地面补丁 + 名字，可点选、可聚焦，展位站在里面；路线文案说"沿…走到 / 穿过…走到"，不说门（`wayfinding-copy.md` §2）。环形回廊是**带洞的区**（`holes`，见下） | 本场地未用 |
| `blocks[]` 的 `void`（中庭、采光井：通往下层的开口） | 不是实体：板被切掉，一圈栏杆；放在上层，里面不得有房间、块、展位（§9.1） | 本场地未用 |

换法：不可进区做虚线轮廓 / 斜线；不画（负空间）；压低到 0.2 m。别用 `solid` 块冒充挑空：画出来是一张大桌子（lessons M16）。

**带洞的区：环形回廊**（`areas[].holes`，多边形或 `[x, y, w, h]` 的列表，洞必须落在外圈里）。二层绕着中庭一圈的回廊不是四条走廊，也不是一块"中间挖空的房间"：它是**一个**区，外圈是回廊外沿，洞是中庭那口井。
- 洞不属于这个区：展位归属、路线文案（"沿中庭回廊走到…"）、点按都把洞里的点排除；区的重叠检查也不算洞。引擎的栅格**不**因此挡路：洞本身只是普通地面，要说它是什么就**在同一坐标画一个块**——`void`（通往下层的口，§9.1）、实心块（柱芯、楼梯芯）或房间——否则洞就是一块可走的地。
- 地图把两圈轮廓都描出来（虚线 / 点线随 `kind`）；区的名字和 `label` 号牌放在**最宽的那一条带**里，不压在洞上。
- 不写 `at` 的展位沿环一圈摆开（顺时针，避开门和楼梯落点），不走网格；要定位置就写 `at`。
- 例（二层中庭回廊，洞与 `void` 同一多边形）：`{"id":"GALLERY","kind":"corridor","name":{"en":"atrium gallery","cn":"中庭回廊"},"poly":[[16,8.4],[26,8.4],[26,16.4],[16,16.4]],"holes":[[[17.8,10.6],[24,10.6],[24,14.4],[17.8,14.4]]]}`，同层 `blocks` 里 `{"kind":"void","id":"ATR","poly":[[17.8,10.6],[24,10.6],[24,14.4],[17.8,14.4]]}`；套件的 `assets/demo/venue.json` 就是这样画的。

### 1.4 墙是算出来的
1. 收集外轮廓和每个展区的横平竖直边，按 `("v",x)` / `("h",y)`（坐标 round 0.01）分桶，桶里存区间。
2. 同桶区间并集：两个房间共墙只剩一道。
3. 减去每个实心块自己的边（块已经画了那几面）。
4. 减去入口缺口（入口矩形的范围）。
5. 减去每个门：`at ± w/2`，默认 `DOOR_W` 1.2 m（原站报告厅门 1.7 m）。
6. 丢弃短于 0.15 m 的残段；坐标 round 2 位。
7. 只支持横平竖直；斜边在构建期报错。要斜墙：用多边形布尔（Clipper 一类），或把斜边做成"实心块"。

外法线：取边中点沿候选法线走 0.01 m（Python）/ 0.02 m（JS）做探针，探针在多边形内就翻转——与顶点绕向无关。

### 1.5 门牌站在门外
`sign = door[0] + 外法线 × 0.9 m`，z 1.7，只取第一个门；重心留给展位。换法：重心 + 引线；贴墙外面；铺在地上。

### 1.6 入口是数据
`entrance { at, name }` 在外墙开缺口 + 一个指向室内的大箭头（§6.4）+ 一个标签：三重冗余。箭头方向 = 最近外墙边的内法线。

### 1.7 竖井的配对
原站：相邻楼层楼梯中心距 < `STAIR_LINK` 2.5 m 自动配对（容忍每层楼梯盒略有差异）。套件：`blocks[].links` 同值显式连接（schema 规定）。两种都要能画出竖井。

### 1.8 展位的自动摆放
优先级：显式 `at`（原站叫 `xy`）> 房间 / 区的 `slots` > 网格；开放区里的网格同样内缩，实体写 `at` + `floor` 就能直接站在无区的地面上。网格：外接框内缩 `m = min(1.0, w/4, h/4)`；`cols = layout.cols || max(1, min(n, round(√(n·w/h))))`；`rows = ceil(n/cols)`；第 i 个中心 `(x0+(i%cols+0.5)·w/cols, y0+(i÷cols+0.5)·h/rows)`。`MIN_GAP` 0.8 m 构建期断言。换法：泊松圆盘；沿墙一圈；六角堆叠。

### 1.9 构建期校验（数据错 = 视觉错）
门不在墙上、大堂在房间里、楼梯 `doors` 不在楼梯边上、斜墙、重复 id（房间与区共用一个 id 空间）、两展位近于 0.8 m、实体指向不存在的房间或区、区与房间重叠、挑空在最低层或里面放了东西——全部让构建失败（引擎把它们收进 `EVK.wayfind.create(venue).warnings`，要求为空；其中会藏起实体的——房间或区的 id 不存在——另在 `.errors` 里，同时也在 `warnings` 里）。门有三种常见的错，都给出带坐标的警告：门画在两间房**共用的墙**上（`door 101@[x,y] opens into 104`：门外 0.4 m 是另一间房，这间房从此进不去，表现为几百条"no route"）；门离房间边界超过 0.3 m（门被忽略，不到 0.3 m 就吸到墙上）；门朝着实心块、挑空或楼外。再加**全穷举寻路测试**：每个起点 × 每个实体都出路线，跨层必有楼梯，最长路线低于上界（原站 38 m，断言 < 60 m，楼 28×35 m）。空间有限就测穷尽（`ux-contracts.md` D）。

### 1.10 高度词汇与贴地层级
| 量 | 原站取值（m） | 范围 / 换法 |
|---|---|---|
| 墙高 `WALL_H` | 1.0 | 0.3–1.4；令牌 `--m-wall-h` |
| 墙厚 `WALL_T` | 0.22 | 0.08–0.4（`--m-wall-t`）；帽的屏幕宽 = 厚×k（此楼 1.2–2.4 px） |
| 块高 `BLOCK_H` | 1.15 | 墙高 ×1–2.2，块略高于墙才压得住邻墙 |
| 板厚 `SLAB` | 0.45 | 0.1–0.9 |
| 针高 `PIN_H` | 2.1 | 1–3（`--m-pin-h`）；人的高度台阶 1.2 / 1.7 / 2.1 |
| 贴地层 z | 走廊 .005 · 房间 / 区 .01 · 选中边线 .012 · 入口箭头 .02 · 路线 .08 · 起点/落点环 .1 · 入口/起点标签 .3 · "上到 3F" .4 · 块图标 1.2 · 房号牌 1.7 | 毫米级台阶防串层，写成表放进代码注释 |

**墙高要低于遮挡极限**：墙后被遮住的地面深度 = `墙高 / tan(俯仰)`（推算）。1.0 m 墙：16° → 3.5 m，30° → 1.73 m，50° → 0.84 m，84° → 0.11 m。最低俯仰越低，墙越矮，或让近墙淡出。

## 2 投影与相机 / Projection and camera

### 2.1 十五行透视
```js
// 相机：yaw 绕竖轴，pitch 绕横轴，朝 (tx,ty,tz) 看；L = 相机距离
x1 = dx*cy - dy*sy;  y1 = dx*sy + dy*cy          // dx,dy,dz = 点 - 看点
Y  = -y1*sp + dz*cp;  D = y1*cp + dz*sp           // D 越大越近
k  = L / (L - D) * s                              // 该点每米像素（一等公民）
return [ox + x1*k, oy - Y*k, D, k]                // 屏幕 x, y, 深度, k
```
`D` 用于排序，`k` 用于给所有直立物定尺寸（"有界公告牌"的来源）；`s = fitS × zoom`。

### 2.2 透视强度按场景尺寸定，不按视场角
`L = persp × stackR`（`--m-persp`，原站 7，范围 3–40），`stackR = hypot(半径, ((顶层−底层)·层距 + 墙高)/2)`。此楼 stackR 31.7 → L 222 m；包围球最近 / 最远处放大 ×1.167 / ×0.875（推算 7/6、7/8）。

| L / R | 近 / 远 | 观感 |
|---|---|---|
| 3 | ×1.50 / ×0.75 | 戏剧化广角 |
| 5 | ×1.25 / ×0.83 | 强透视模型 |
| **7（原站）** | ×1.17 / ×0.88 | 桌上建筑模型，平行墙近乎平行 |
| 10 | ×1.11 / ×0.91 | 偏长焦 |
| ≥ 40 | ≈ ×1 | 近乎正交；`k` 处处相等，标记尺寸仍用 clamp |

太强像玩具，没有则像图解；5–10 是"模型感"。

### 2.3 预设视角：语义化，随屏幕比例变
| 状态 | 俯仰 | 偏航 | 备注 |
|---|---|---|---|
| 总览（叠层） | **30°** | **32°**（`YAW0`，从东南看，各层房间都露出） | 令牌 `--m-pitch` `--m-yaw` 就是这一行 |
| 单层 | 50° | 宽屏 32°；`W ≤ 0.9H`（竖屏）14°（`YAW_TALL`，近正南，铺满宽度） | |
| 聚焦房间 | 58° | 同单层 | 取景 share 0.62 |
| "近景"（实体页小图） | 50° | 同单层 | 取景集 = 房间四角各外扩 3.5 m |
| 路线 | 并排 46° / 单层 52° / 叠放 32° | 并排 18° / 单层竖屏 14° / 叠放 32° | |
| 硬限 | 16°–84° | | 缩放 0.75–4.5；橡皮筋可短暂越过，但俯仰封在 4°–89.5°（§3.4） |

原理：问题越局部俯仰越陡（叠层要低角度分层看，房间要陡角度看内容）；偏航永不取 0/45/90，三个可见面明暗不等才读作立体。
**用令牌表示其他状态（本套件设计，由 30/50/58/46/52/32 反推）**：单层 = `--m-pitch`+20°，房间 +28°，路线并排 +16°、单层 +22°、叠放 +2°；竖屏偏航 = `--m-yaw`×0.44，并排 ×0.56（plan 整体 ×0.5）；最后夹到硬限。
换法：真等轴 35.264° / 45°；始终俯视；总览缓慢自转。
长条楼（脚印长宽比 > 1.6）在竖屏上，上面的偏航会被再夹一道，见 §2.8。

### 2.4 自动取景
在便宜的正交空间里取景，再除一个固定余量吸收透视：
`fitS = min((W − 左边距 − 右边距) · share / (2·mx), H · share / (2·my)) / 1.06`
`mx = max|x1|`，`my = max|Y|`，遍历相关平面点与相关高度。**把最高的装饰（针头）算进取景集**，才不会裁到标记。

| share | 用在 | 原站取值 |
|---|---|---|
| 总览 / 单层 / 近景 / 路线总览 | 0.9 | 范围 0.8–0.94 |
| 聚焦房间 | 0.62 | 0.5–0.7 |
| 路线单步 | 0.82 | 0.7–0.9 |

余量 = `1 + 0.42/persp`（persp 7 → 1.06，吸收近处 ≤17% 的放大）。分辨率变化时 `fitS.set()` 不做动画（手机转屏只重新取景，不播放缩放）。每米像素（推算）：390×405 画布 5.63；1120×780 → 10.83；单层 7.8–18.1。

### 2.5 安全区：把 UI 遮挡变成相机参数
`setPad({top,right,bottom,left})`。原站三个弹簧：`gut` 左（楼层数字，只在总览）、`pad` 右（侧卡）、`lift` 竖直（底部弹层）。
`ox = (W + left − right)/2`，`oy = H/2 − lift`，`lift = (bottom − top)/2`；取景宽用 `W − left − right`。

**遮挡形状决定补偿方式**：条带（底部弹层）→ 平移（`lift`，不改比例）；侧栏 → 重新取景（`pad` 改 `fitS`）。变化 < 2 px 忽略；`pad ≤ W/2`。响应 0.45–0.5 s，弹层一起"滑开"。弹层的几何取**落定后**的，不取滑动中的（`ux-contracts.md` X）。

### 2.6 枢轴与转向
枢轴 = 可见集合的中心：叠层 `tz = ((顶−底)·22 + 墙高)/2 = 22.5 m`，单层 0。偏航目标 `yaw + wrap(目标 − yaw)`，`wrap(a)=a−τ·round(a/τ)`，永远走短路。**用户转过的偏航在换模式时保留**（`turned`），只重置俯仰 / 缩放 / 看点；Reset 清除。路线步骤切换会清 `turned`。

### 2.7 明暗由相机算，不烘焙
`facing(nx,ny) = [nx·sy + ny·cy, nx·cy − ny·sy]` = [朝向观者, 朝向屏幕右]。第一项 ≤ 0.01（板边）/ 0.005（墙块）剔除背面；第二项 `s ∈ [-1,1]` 调亮度。光固定在视图空间，楼转动时被照亮的面在变——立体感的主要来源。

### 2.8 长条楼：竖屏上让长边横过屏幕（本套件设计）
一栋 50 × 20 m 的楼，偏航 −32° 时长边斜着往远处走：在 375 px 的手机上每一层只有一只手掌宽（实测四层 exploded 在 343 px 画布上每层 122–150 px）。抽牌时 `yaw` 在方向的包络里取，不知道你的楼多长，所以由**引擎在运行时**夹，`draw.py` 照旧抽、不改牌。
- **何时**：全部楼层脚印的包络沿 x 的长度 ≥ `longAspect`（1.6，范围 1.4–2）× 沿 y 的长度；画布是竖的（高 > 宽）；投影会在平面里转（orbit、exploded、plan；oblique 的偏航是倾斜，长边本来就横着，不夹）。横屏、方楼、沿 y 的长条楼（竖屏上它本来就顺着画布）都不动。
- **夹成多少**：静止偏航的绝对值，取使**一层脚印的投影宽**仍 ≥ 可用宽 × `longShare`（0.8，范围 0.7–0.88）的最大整数度，且不超过令牌自己的偏航；可用宽 = 画布宽减楼层数字槽。按"整叠楼层在取景缩放下"算一次，再套到所有静止视角（一层、路线）。偏航 0 也够不到 80% 就取能得到的最好的一档。
- **只夹静止姿态**：拖动、双指、键盘照旧自由转；被夹的是各个静止视角（总览、一层、路线）的起点偏航。
- **何时重算**：resize、转屏、令牌变化；按整度取值，拖动窗口不会每个像素重排一次。
- 实测（50 × 20 m、4 层、exploded，343 px 画布）：每层脚印宽 122–150 → 205–248 px，偏航夹到 5°；转横屏回到令牌值。想让每层更大，用 `plan`（平铺，§15.4）或把 `--m-yaw` 调小（`draw.py adjust yaw=…`）；想关掉，`new EVK.VenueMap(canvas, venue, { tuning: { longAspect: 99 } })`；两个数 `longAspect`、`longShare` 都在 `opts.tuning` 里。
- 验收：长条楼的牌在 343–375 px 竖屏下看总览与一层；转横屏再看一次（ux-contracts MP-17）。

## 3 运动 / Motion

### 3.1 弹簧：用 response（秒）和阻尼比定义
`k=(τ/response)²`，`c = 4π·ζ/response`，半隐式欧拉 `v += (−k(x−to) − c·v)·h; x += v·h`；`n = max(1, ceil(dt/0.004))` 子步；`|x−to| < ε 且 |v| < 8ε` 时落定。`dt = min(0.05, Δt)`；循环休眠时 `last = 0`，醒来第一帧用 1/60。
**令牌换算**：`response = 原站 response × --spring-dur / 0.45`（0.45 s = 原站 0.4–0.55 s 带的中点，即默认；各量保持原站比例，"淡出快于移动、偏航最慢"不变），`ζ = 1 − --spring-bounce`：

| 量 | 原站 response (s) | ε | 单位 |
|---|---|---|---|
| yaw | 0.55 | 0.0004 | rad |
| pitch · zoom | 0.45 | 0.0004 · 0.0005 | rad · — |
| fitS · tx ty tz | 0.5 | 0.0005 · 0.002 | — · m |
| lift · pad · gut（引擎：四向 inset） | 0.45 · 0.45 · 0.5 | 0.1 | px |
| 楼层 z / ox / oy | 0.55 | 0.003 | m |
| 楼层 alpha | 0.4 | 0.003 | — |
| 开场偏航 | ×2（1.1 s），1400 ms 后恢复 | | |

原站全部 ζ = 1；99% 落定（推算）：response 0.4 → 0.42 s，0.5 → 0.53 s，0.55 → 0.58 s。引擎所有弹簧共用一个 ζ，过冲峰值（推算）：bounce 0.1 → 0.15%；0.2 → 1.5%；0.3 → 4.6%；0.35 → 6.8%；alpha 绘制时夹到 0–1；想更稳可让 pitch / zoom / fit 固定 ζ = 1（建议）。
节奏范围：沉稳 dur 0.5–0.65 / bounce 0；轻快 0.35–0.45 / 0.2–0.3。

### 3.2 手势映射（原站取值）
| 手势 | 映射 | 数值 |
|---|---|---|
| 单指 / 鼠标横拖 | 转盘：`yaw = yaw0 − dx·TURN` | `TURN` 0.0078 rad/px = 0.447°/px（100 px = 44.7°）（推算） |
| 鼠标竖拖 | `pitch = rubber(pitch0 + dy·TILT)` | `TILT` 0.0055 rad/px = 0.315°/px；**触屏单指不倾斜**，竖滑留给页面 |
| 双指 | 缩放 `zoom0·d/d0`、扭转 `yaw0 + wrap(Δ角)`、中点竖移 = 倾斜 | 三个自由度同时 |
| 触控板捏合 | ctrl+滚轮 `zoom *= exp(−deltaY·0.01)`（非被动监听）；Safari `gesturechange` | 有指针按下时忽略 gesture 事件 |
| 键盘 | ←→ ±20° 偏航，↑↓ ±8° 俯仰，`+`/`=` ×1.25，`-` ×0.8；引擎另有 `[` `]` 切换实体、`Esc` 取消选择、`0`/`Home` 复位 | 写目标；减弱动效时 `set()` |

画布 `touch-action: pan-y`、`cursor: grab / grabbing`、透明 tap 高亮、`user-select: none`；焦点环用 `inset box-shadow`（`overflow:hidden` 会裁外描边）。换法：弧球；点按钮跳预设角；两指才转。
以上是 orbit；exploded 同一套手势。oblique 的单指拖动是平移、扭转禁用，plan 只在纸面内转（§15）。

### 3.3 与页面谈判（不变量 5 的做法）
- `setPointerCapture` 放 try/catch；`pointercancel` 当松手；非主键忽略。
- 指针数量变化时**重新锚定手势**（`start()`：fling=0，yaw/pitch/zoom `hold()`，重记原点），双指抬起一指不会跳。
- 手指按下 = 接住一切飞行中的东西：`hold()` 把 `to` 设为 `x`、`v` 设为 0。

### 3.4 松手惯性与橡皮筋
- 速度窗口：最近 ≤ 6 个样本，丢掉 > 90 ms 之前的；`span = max(12, 末−首 ms)`；`v = dx/span·1000` px/s。末样本距今 > **80 ms** 视为手指已停，`v = 0`。
- 触发：单指、`|v| > 60 px/s`、非减弱动效：`fling = clamp(−v·TURN, ±9 rad/s)`。
- 衰减：每毫秒 ×0.9955（= `e^{−4.51t}`，时间常数 222 ms，半衰期 154 ms，推算）；`|fling| < 0.02 rad/s` 停。滑行总量 = `v/4.51`：3 rad/s → 38°，5 → 64°，9（上限）→ 114°（推算）。
- 橡皮筋 `band(over, dim) = over·dim·0.55 / (dim + 0.55·over)`，渐近线 = `dim`。俯仰 `dim` 0.5 rad（渐近 28.6°），缩放 `dim` 1。例（推算）：俯仰多拉 0.25 rad → 显示 0.108；缩放多拉 0.5 → 0.216。松手 `to = clamp(x)`，弹簧从手指离开处拉回。
- **橡皮筋是显示值，也要有底**：俯仰越过限位时显示值夹在 `pitchFloor` 4° 与 `pitchCeil` 89.5° 之间。俯仰 ≤ 0 时贴地椭圆的半径 `r·sin(pitch)` 为负，`arc()` / `ellipse()` 抛 IndexSizeError，每帧一次，帧循环停掉，相机卡在负俯仰（试跑里鼠标往上拖就能触发）。所以每个半径再过 `max(r, 0.2)`。验收：四个方向猛拖到头，控制台为空。
换法：无惯性（CAD 式）；吸附最近基向；线性摩擦；硬限位 / 环绕 / 对数缩放。

### 3.5 开场、模式切换、Reset
- **开场**（一次）：只偏移**当前值**，目标不动，所以与任何打断可组合：偏航 −40°（response 1.1 s）；第 i 层 `z −= 6 + 4i` m 且 alpha 0。动效减弱或 `intro:false` 跳过。它同时是"可以转动"的提示。
- **模式切换移动楼层，不只是相机**：总览 `z = (level−min)·22`，alpha 1；选一层时该层 z = 0、alpha 1，其余 `z = (level − sel)·26`（比 22 远）且 alpha 0。alpha 比 z 快（0.4 vs 0.55 s），淡出先完成。
- **Reset 只在离家时出现**：`|yaw−家| < 3°`、`|pitch−家| < 2°`、`|zoom−1| < 0.04`、无 fling 才算在家。

### 3.6 减弱动效
原站只在加载时读一次 `matchMedia`；引擎每次现读并订阅 `change`。路径：无开场；`place`/`go` 用 `set`；无 fling、无脉冲；路线虚线静止（`lineDashOffset = 0`）、循环不再为流动常开；键盘写 `set`。

## 4 布局 / Layouts

### 4.1 叠层的层距：让各层脚印在屏幕上刚好相接
一般式：`gap = 深度 · tan(俯仰) + 墙高 + 空气/cos(俯仰)`，深度 = 脚印沿视线方向的跨度 `max(x·sinψ + y·cosψ) − min(…)`。
原站总览：深度 37.8 m（推算），俯仰 30° → 21.8 + 1.0 = 22.8 m，取 **22**（略小于刚好相接，约 0.7 m 重叠 = 一道墙高；上层近缘只会盖到下层远墙，不会盖到房间）。
套件引擎：`gap = (深度·sin p + gapAir)/cos p + 墙高 + 板厚`，`gapAir` 0.8 m（刚好分开）；exploded ×1.55；选一层时其余层滑走 ×1.2（原站 26/22）。路线叠放：原站 28.15 m（推算），引擎空气取 3 m。
范围：紧叠 4 m（半透明切片）；**爆炸**加大空气 6–14 m（§15.3）。

### 4.2 单层 / 聚焦
其余层 alpha 0 并沿各自方向滑走（`GAP_AWAY` 26 m）。聚焦房间：看点 = 房间重心，取景集 = 房间多边形，`share 0.62`，`zs = [0, PIN_H]`。近景：取景集 = 房间四角各向四个对角外扩 3.5 m（"这间和周围"，不是缩略图）。

### 4.3 路线布局
`layout = 用到的层 < 2 ? single : W > 1.15·H ? side : stack`（页面与相机共用 1.15）。
- **side（宽屏）**：两层都 z=0；第二层沿屏幕右轴 `(cos18°, −sin18°)` 平移 `该轴上楼宽 + 7 m`（此楼 44.67 m，推算）；起点层在先。
- **stack（竖屏）**：按楼层序 `rank × 层距`；**single**：只那一层。
- 路线外的层 alpha 0，停靠位 `−17`（低于最低）/ `8.5`（中间）/ `34`（高于最高）——隐形的东西也朝合理方向进出。
- 转屏只在 side ↔ stack 类别翻转时重排（250 ms 去抖）。

### 4.4 逐步取景
walk 步：框住该段折线，外扩 3.5 m，`share 0.82`，另一层降到 alpha **0.12**；arrive 步：框住目标房间多边形；stairs 步与总览：框住两层，`share 0.9`。

| 房间 | 1.000 | 0.351 | 1.22 : 1 / 1.17 : 1 |

### 5.3 基面 = 页面
画布背景 `--m-ground` 与楼板同色：没有卡片边，只有墙、白房间、板边、标记，像桌上的模型。深色里楼板比页面亮半阶（1.09 : 1）仍能看出板。换法：带暗角的框；暗舞台亮模型；后退的网格地平面。

### 5.4 明暗 = 基色 × 光照系数
`填色 = 基色 × f`，`f = a − b·s`，`s = facing()[1]`（+1 = 面朝屏幕右 = 更暗）。**每种材料自己的跨度**：

| 面 | a | b | 跨度 2b | 浅色实例（左 / 中 / 右） |
|---|---|---|---|---|
| 板边 | 0.92 | 0.20 | 0.40 | #152E54 / #112645 / #0E1E36 |
| 墙面 | 0.93 | 0.13 | 0.26 | #FFFFF8 / #E3E0DA / #C3C1BB |
| 块面 | 0.86 | 0.16 | 0.32 | #DCD7CC / #BAB5AC / #97948C |
| 块顶 | 1.04 | — | — | #E1DBD0 |
| 走廊砖 | 0.97 | — | — | |

形体越需要，跨度越大（板边最大，墙最小）。`--m-light`：
- `left`（原站）：`s` 原样。
- `right`：`f = a + b·s`。
- `top`（本套件设计）：`t = facing()[0]`，`s = clamp(0.55 − 1.1·t, −1, 1)`，面越朝观者越亮。
换法：每材料三色手挑；沿面渐变；角落遮蔽线；不着色。

### 5.5 深色 = 墨色反转，不是换皮
墙帽从深变浅（仍是对比最高的角色）；墙面比房间、楼板都亮；房间比楼板亮；强调色**重调**（红 #C8102E → #FF4D63，琥珀 → #FBBF24）；晕边变页面色。深色里"墨"仍须 ≥ 7 : 1。

### 5.6 颜色配给与选中
红 = 你 / 目的 / 路线 / 入口箭头；琥珀 = 竖向；石色 = 实心；粉笔 = 晕边。第二强调色只在出现新意义时才加。**选中的房间先换地面淡染（`--m-select-fill`），再加一圈内缩的边线（`--m-select`）**：边线画在墙内侧 `墙厚/2 + 0.22 m`（画在墙线上会被近处的墙盖掉），比路线细、闭合成环，不会被当成墙或路线；淡染没有对比下限，状态靠边线这个第二通道（floor F07）。原站只换色不描边；套件两者都做。换法：只淡染（把淡染加深到 ≥ 3:1）；同色靠线型区分；沿路线渐变；按类别的环色；取自实体色。

### 5.7 从方向配色得出地图令牌（本套件设计）
`ground = --paper`；`slab = ground`；`room = slab` 抬 ΔL +0.05…+0.07（深色 +0.04）；`block = slab` 压 ΔL −0.05…−0.07（深色抬 +0.07）；`route = --b`；`climb = --climb`（色相离 `--b` ≥ 50°，对楼板 ≥ 3 : 1，lint 检查）；`select = route`（选中边线，路线色已过楼板 3:1；lint 当地板项查）；`select-fill = mix(room, route, 10–16%)`（淡染；`--m-text` 压在上面须 ≥ 4.5，不够就取 10 %）；`route-halo = ground`；`text = --text`。dark 同步重算，不是取反。

**`cap` 与 `wall` 是两个有下限的读得出来的角色**（floor F03）：
- `cap` = 墙帽与墨线，也是针、环、站序圆、图标描线：由 `--a`（各材质有自己的起点）沿 OKLCH 亮度走到对 `--m-slab` ≥ **7 : 1**，色相与彩度不动。
- `wall` = 墙面基色：由楼板朝墨端（深色里朝亮端）混出一档，走到对 `--m-slab` ≥ **3 : 1**。原站的"`wall = room` 压 −0.01…−0.03"不再用：它对楼板只有约 1.1:1，缩小后墙成一片白，形体全靠墙帽线；套件让墙面自己读得出。`--m-wall` 是乘光照系数（约 0.80…1.06，§5.4）之前的基色。
- 浅色与深色各走一遍，目标值取 7.05 / 3.05，十六进制取整后仍过线。`lint_floor.py`：`cap` < 4.5 失败，< 7 警告，`wall` < 3 警告；旧 roll 加载时自动补走。

## 6 几何绘制与顺序 / Geometry and painter order

### 6.1 板与墙
- 板：外轮廓挤出 SLAB，**只画朝向观者的边**（`facing[0] > 0.01`），再画顶。
- 墙：细盒，**切成 ≤ 2.4 m 的段**，两端各外延 `WALL_T/2`。每段 2 长面（±法线）、首尾段加端面、1 个顶四边形。切段是因为画家算法按中心深度排序，20 m 长的细盒排不对；外延填补转角缺口（此楼三层共 179 段，推算）。
- 面按平均深度远→近全画完，再按深度远→近画全部顶：墙帽的墨线永远压在邻面上。
- 帽 = 真实几何（0.22 m），线宽随缩放 / 透视自然变化。换法：屏幕空间恒宽描边；深面浅帽；玻璃墙（alpha 0.2）。

### 6.2 块、房间、走廊
块：面 `--m-block × (0.86 − 0.16s)`，顶 ×1.04（顶比面亮 = 最便宜的"实心"线索），与墙进同一排序表。房间与区：贴地多边形，z=0.01，选中填 `--m-select-fill`、再描内缩的 `--m-select` 边线（z=0.012）；同时把投影后的多边形存进命中表。

### 6.3 一帧的画家契约
清屏（`dpr` 变换）→ 楼层按动画 z 升序：板边 → 板顶 → 走廊砖 → 房间 → 入口箭头（按 `detail()` 淡）→ 墙与块的面（远→近）→ 墙与块的顶（远→近）→ **直立物**（图标、房号牌 `d−0.5`、入口标签、标记 `d + (目标 ? 50 : 0)`）按深度排序 → 该层的竖井（§9）→ 全部楼层之后：路线叠层（§10）→ 楼层数字。

### 6.4 入口箭头
平面箭头：杆长 `L=3.4`、半宽 `W=1.0`，头半宽 `H=1.7`、头长 1.9，尾端在入口重心外 3.4 m，z 0.02，填 `--m-route`；**画在墙之前**，两侧墙压住它，像从洞里伸出。标签在室内 3.2 m、z 0.3，路线中隐藏。换法：脉动门光；地面欢迎垫；走进来的人形。

## 7 直立物 / Billboards

### 7.1 尺寸 = clamp(米数 × k, min, max)，总览封顶更低
| 物 | 规则（原站取值） | 总览封顶 |
|---|---|---|
| 标记直径 | `clamp(2.1k, 16, 46)` | ≤ 22；目标 `max(1.3d, 26)` |
| 图标板 | `clamp(min(0.62·块短边, 1.7)·k, 11, 26)` | ≤ 15 |
| 房号牌高 | `clamp(1.5k, 13, 34)` | ≤ 16 |
| 标签字号 | `clamp(0.5k, 9, 12)` px | |
| 路线线宽 | `clamp(0.36·均k, 3, 9)` | |
| 起点环半径 | `clamp(0.55k, 7, 14)` | |
| 落点环半径 | `clamp(0.5k, 6, 12)` | |
| 楼层数字高 | `clamp(H/24, 15, 26)` | |
| 站序圆半径 | `max(7.5, 0.42r)` | |

原理：随缩放 / 透视生长，像贴在世界上，但有下限（读得清、点得中）和上限（不盖住别人）。总览封顶启发式（推算）：`≤ 0.8 × 最近邻间距(px)`。范围：下限 14–18、上限 40–56；换法：固定屏幕尺寸的针；纯世界尺度；点→图标→卡片的细节层级。

### 7.2 标记渲染器（`--m-token`）
共同约定：**锚点** `base = P(at,0)`、**头点** `head = P(at,pinH)`、**命中圆**（可视半径 + 6，记入当帧命中表）、**深度键**（头深 + 选中 50）、**占位**（无图画实体色盘 + 字母 / 序号，黑白字按亮度自选）、**站序圆**（右上 `(+0.78r, −0.78r)`）、**三档透明**（§8）。`d` = 直径，`r = d/2`。

**badge（原站）**：①地面阴影：base 处椭圆 `max(2,0.42r) × max(1,0.42r·sin(pitch))`，墨 18%；②茎 base → 盘底，宽 1.25（选中 2，`--m-route`）；③盘阴影 `(cx,cy+1)` 半径 `r+0.5`，墨 22%；④图像盘，`cy = head.y − 0.15r`；⑤环半径 `r−0.6`（选中 `r−1.25`），宽 1.2（选中 2.5），**描在图像边内侧**——吃掉 PNG 抗锯齿边，把 52 种图案统一成一个家族；⑥选中脉冲（§7.4）。
其余五种（本套件设计，引擎里的数值，是起点）：
- **pin**：水滴，头半径 `0.46d`，尖指向 base（陡视角时尖保持在头下 ≥ 1.7r），实体色填 + 墨描 1.1，头内 `0.5r` 白盘放图像或字母；无茎。
- **plate**：号牌，高 `0.82d`、宽 `max(1.55h, h+8)`，站在茎上；顶部一条实体色带（高 `max(3, 0.26h)`），展位号 `700 0.46h`；轮廓走 `--radius` / `--chamfer`。
- **dot**：无茎，**贴地**椭圆 `0.5d × max(0.5d·sin p, 0.28·0.5d)`，实体色 + 页面色描边，中心浅点；命中半径 ≥ 8。
- **flag**：杆高 `max(base−head, 1.1d)`，燕尾旗 `0.95d × 0.62d`，旗内字母；命中 `max(0.55w, 10)`。
- **stamp**：边长 `1.02d`，每边 `n = max(4, round(s/(3.3·hole)))` 个半径 `max(1.4, 0.055s)` 的齿孔（`evenodd`），内框 1 px，按 id 哈希取固定倾角（±3°，**不要每帧随机**），有茎。

### 7.3 图案归一化（badge / pin / stamp 里放第三方图案时）
原站构建期管线：128×128 PNG；4× 超采样 + LANCZOS；圆章占盘径 92%；其他形状最长边 `0.74`（`·aspect^0.25`，上限 0.83）、高盾下移 2% 做视觉居中、最远不过半径 90%；不透明圆源按圆裁；盘面恒为 `#FFFFFF`。**不要靠 `object-fit: contain`**——参差。换法：字母方块；单色剪影着实体色；圆角方块。套件不带任何第三方标志。

### 7.4 目标强调：有限的注意力
目标：放大、换强调色、画在最上、脉冲三下。脉冲：圆环半径 `r + 3 + 16t`，线宽 2，alpha `0.55(1−t)`，周期 **1500 ms × 3 次**；起点延后 **500 ms**（初次加载 900 ms）等相机落定、图像解码。**颜色用 `--m-route`，别像原站那样写死 rgb(200,16,46)**（深色里会不一致）。动效减弱：不脉冲。换法：持续呼吸；弹跳针；地面涟漪；只换色。

### 7.5 图标与房号牌
块图标（只给 stairs / lift / wc）：48 单位网格，框 2.5、字形 3.4、`miter` 连接，`Path2D` 按字符串缓存，描边宽按网格单位计、随尺寸等比增粗；放在块中心、z=块高+0.05。原站框是切角八边形 `M1.25 8.25L8.25 1.25L39.75 1.25L46.75 8.25L46.75 39.75L39.75 46.75L8.25 46.75L1.25 39.75Z`（切角 7，来自品牌的"切"）；**引擎按 `--chamfer` / `--radius` 换成切角 / 圆角 / 方框**，字形不变。
房号牌：站在门外 0.9 m、z 1.7，底边对齐锚点；高 `clamp(1.5k, 13, 34)`。引擎画成同形状语言的牌：宽 `max(1.1h, 字宽+0.6h)`，填 plate 色 .97，描 1.1（选中 2.2 + `--m-route`），偏移 (0.6, 1.2) 的墨影 16%，数字 `700 0.62h`。原站是设计师的三层描边号牌图（宽 = 高 × 宽高比），加载前退回晕边文字。

### 7.6 标签、晕边、剔除
- **晕边**：`lineJoin=round`，先 `strokeText`（`--m-route-halo`，宽 3.5 ≈ 0.3×字号）再 `fillText`；顺序反或 miter 会让 W、M、N 长刺。
- **双语栈**：主行在上、更大、`800` 权重，副行较小、`600` 权重，在 `+字号+2`；拉丁行用 `--m-label-case`、`--f-label`，中文行用 `--f-cjk`，不大写、不用伪粗拉丁字体。哪行是主行由 **`lead`** 决定：`VenueMap` 选项 `lead: "en" | "zh"`，缺省读 `<html data-evk-lead>` 并随它变化（`setLead()` 可钉住；旧名 `lang` 仍可用）；提示框和 aria 同序。
- **字体就绪**：画布文字不随 webfont 到达重排，`document.fonts.load(…).then(kick)`。
- **剔除**（原站标签少没做；引擎做了最小版）：次要标签（房间名、块名）按优先级贪心放置，与已放置矩形相交就不画；**标记、房号牌、图标、入口 / 起点 / 落点标签从不剔除**。可加强（建议）：显隐 alpha 向目标插值（≈ 80 ms）、决定至少保持 250 ms，转动时不闪。
- **实体名**：选中、悬停或 `k ≥ 13` 时在标记下方出短名，与近邻标记冲突则让位。
- **提示框**（仅鼠标）：`.evk-map-tip`，贴命中圆上缘 6 px，主名 + 副名；触屏不做粘滞提示。

## 8 状态与梯度 / States and ladders

### 8.1 梯度（原站取值）
| 状态 | 标记 | 房号牌 / 图标 / 入口箭头 | 其他 |
|---|---|---|---|
| 无选择 | 1 | 1 | |
| 有目标 | 目标 1 · 主题路线的站 **0.72** · 其余 **0.26** | 1 | |
| 路线总览 | 同上 | **0.5**（路线起终房和用到的楼梯仍 1） | |
| 路线单步 | 站 **0.4** · 其余 **0.1** | **0.16** | 另一层 **0.12**；非当前段线 0.38；非当前连接线 0.45 |

`--m-dim`（0–1）= "其余" 一档的 alpha（原站 0.26，范围 0.18–0.32）；其余档按比例：站 ≈ 2.8×，步骤态 ≈ 0.4×。

### 8.2 点选
自顶向下：标记（半径 + 6）> 房间 > 楼层。从当帧投影后的形状反查（`hits` 每帧重建，点选与像素一致）；点按 = 移动 ≤ `TAP_SLOP` 7 px 且 < 600 ms。16 px 的标记点选圆 28 px；密集总览可小于 44 px，但选中后的行动控件（弹层行）≥ 44 px。`locked`（显示路线时）禁用点选和悬停。换法：离屏颜色拾取缓冲；24 px 内最近标记吸附。

## 9 竖井 / Stair shafts
下层楼梯盒到上层板底之间的一根幽灵棱柱（`drawLink`）：盒内缩 `0.35 m`；从 `lower.z + BLOCK_H` 到 `upper.z − SLAB`，短于 0.5 m 或任一层 alpha < 0.02 不画（用两层 alpha 的小者）。面向相机的侧面填 `--m-wall`，**alpha ×0.07**；四条竖棱虚线 `[4,4]`、宽 1.2，三条 alpha **0.6**、离观者最远的一条 **0.22**（深度感，避免线框笼子）。画在下层之后，上层盖住它的顶（此楼高 20.4 m，推算）。**exploded**：井退化为虚中线（`[2,5]`、宽 1.8、alpha .55，电梯用 `--m-climb`）+ 上下两个落点外框；平铺布局不画井。
范围：面 0.04–0.1。换法：发光管、流动点、电梯厢精灵。

### 9.1 挑空 / Voids
竖井的反面：不是楼梯穿过板，而是板上开了口（`blocks[]` 的 `kind: "void"`）。
- **板被切掉**：口远侧的边缘画板的切面（朝向观者的那几面）；一圈栏杆 = 薄墨板，高 `clamp(墙高×0.8, 0.45, 1.05)` m，切成 ≤ 1.6 m 的段，立柱只显示为段端的线。栏杆两面可见，每段都画。
- **叠层（stacked）**：口是一口往下看的井——远侧井壁、更暗的井底、正下方展位的实体色点，全部裁在口内；井深 = `shaft`（3.2，范围 2–5）×`--m-wall-h`，夹到 1.2–5 m：墙是风格化的半高，要乘这个系数才像一层楼。下层通过口露出来，所以叠层视图里它是透的。
- **单层、plan、并排**：下面没有东西可看，口里画建筑师的 X（虚线对角线），底衬一层约 7 % 的淡墨，让这个口读成"落下去"而不是一块空地。
- 数据：挑空属于上层，下层不用画；不可走，路由当实心；里面不得放房间、块、展位（构建期报错）。绕着挑空的回廊是一个带洞的区（§1.3），洞与 `void` 用同一组坐标。

## 10 路线叠层 / Route overlay
- **独立一遍**：所有楼层画完后，每段线用**该层的 alpha**，再连接线，再各层的直立牌（起点环 `d+40`、落点环 `d+35`、"上到 3F" `d+30`）按深度排。上层永远盖不住路线（原站 C3d1 修过的 bug）。
- **线**：点在 z 0.08；线宽 `w = clamp(0.36·均k, 3, 9)`；`round` 连接 / 端头；先 `--m-route-halo` 宽 `w+4`，再 `--m-route` 宽 `w`；当前步再叠白虚线 `[0.8w, 2.4w]`、宽 `max(1.5, 0.42w)`、`--m-dash`，`lineDashOffset = −(now − t0)/28`（≈ 36 px/s，朝目的地）；非当前段 alpha ×0.38 且无虚线。方向靠运动，不画箭头。
- **起点环**：地面椭圆 `1.7r × 1.7r·sin(pitch)` 填 route 16%；上浮的内环（圆心上移 `0.2r`，半径 `0.75r`）填 halo、描 `--m-route`，宽 `max(2.5, 0.4r)`；"Start / 起点" 在 `+0.6r`。
- **落点环**：椭圆 `1.4r × 1.4r·sin(pitch)`，halo 填，`--m-climb` 描 `max(2.5, 0.35r)`。
- **连接线**：落点 → 上层到达点；虚线 `[6,6]`，halo 7 + climb 3.5，`−(now−t0)/40`（25 px/s）；叠放 = 直线；并排 = 二次曲线弧，抬升 `min(0.35d, 0.3H)`；alpha `a·(当前 ? 1 : 0.45)`。标签"Up to 3F / 上楼到 3F"（"Down to …"；电梯 "Lift up to …" / "乘电梯上 …"）在入口、z 0.4、`--m-climb`；`plan.hops` 可有多段。
- 原理：路线 = 外轮廓 + 本体 + 运动纹理，晕边让它在任何底上都读得出。路线存在且未减弱动效时保持 rAF。换法：箭头链、移动小人、彗星尾、渐变、"画上去"的揭示。

## 11 楼层数字 / Floor numerals
总览与路线总览才出。引擎：`--f-num` 文字 + 晕边 4；原站：设计师的路径数据 `d` + viewBox 以 `fill(Path2D, "evenodd")` 画（`evenodd` 让 2、3 的孔开口）。高 `clamp(H/24, 15, 26)`；x = 8 px，y = 该层最左轮廓点的投影 y，随楼层 / 相机移动；并排或平铺时居中于各层之上。取景留左槽 `gut = 数字宽 + 14`。换法：竖直选层柱；印在板边；3D 挤出字。

## 12 渲染循环与性能 / Render loop and performance
- **按需渲染**：`kick()` 至多排一个 rAF；`tick()` 步进所有弹簧 + fling，画一次；仅当 `moving || pulsing || (route && !reduce)` 且 `visible` 才再排。所有改变状态的入口（指针、setter、图片 onload、resize、主题变化、字体就绪）都 `kick()`。
- **离屏不动**：`IntersectionObserver` 设 `visible`，回到可见 `kick()`。
- **DPR**：`dpr = min(devicePixelRatio, 3)`；画布像素 `round(w·dpr)`；每帧 `setTransform(dpr,0,0,dpr,0,0)`；尺寸与 dpr 都没变就跳过。
- **异步重绘钩子**：图片（`decoding="async"` + `onload` 队列）、字体、主题。只预载当前可见楼层的标记图。
- **小技巧**：`Path2D` 缓存；命中表每帧重建；墙段预计算；先剔背面；alpha < 0.01 的层跳过。此楼满叠约 450–600 个四边形 / 帧（推算），无需缓存。
- 材质额外开销见 §14（clay 阴影、riso 多一遍）。换法：连续低帧环境动画；OffscreenCanvas。

## 13 画布周围的 DOM / DOM chrome
- 容器 `.evk-map`：`position:relative; overflow:hidden; background: var(--m-ground)`；`canvas{display:block;width:100%;height:100%}`。**高度用 vh 夹取**：原站完整 `clamp(440px, 74vh, 780px)`、首页 `clamp(380px, 64vh, 660px)`、小图 `clamp(320px, 52vh, 480px)`；套件基线 `clamp(360px, 62vh, 720px)`；手机出血、≥ 760 px 收回。
- 画布 `role="img"` + `tabindex="0"` + 一句 aria-label（说明它是什么、怎么操作、文字名录在哪，句式见 `wayfinding-copy.md`）。
- **提示条** `.evk-map-hint`：底边 14 px 居中，lead 语言在前（例"Drag to rotate 拖动旋转"，lead=zh 时"拖动旋转 Drag to rotate"；oblique 的牌写"Drag to pan 拖动平移"，§15.2），`pointer-events:none`；地图 `is-live` 前不可见；首次按下或 **6000 ms** 后淡出（`opacity .5s`）；`prefers-reduced-transparency` 改不透明。
- **Reset** `.evk-map-reset`：右上，离家才出现（§3.5）；**提示框** `.evk-map-tip`：§7.6。
- 打印：画布 `display:none`（文本名录负责印刷）。

## 14 材质 / Materials（`--m-material`）

每种材质回答：板、墙、块、房间、标记、路线怎么画；哪些手艺原样保留。**都保持 §0 不变量、§6.3 顺序、§8 梯度。**

### 14.1 paper（原站家族）
绘图台上的纸模型：面窄带、墨帽、一个强调（§5 即是它）。ground = slab；room 亮于 slab、block 暗于 slab；cap 深墨。变化余地：纸色（冷灰 / 牛皮 / 淡彩）、墨色（黑 / 靛 / 棕）、强调色任意。**与原站最像**：`orbit + paper + badge`（配红色强调）同取时相似度最高——三项里至多留一项。

### 14.2 line（线稿）
建筑墨线图，无色块。
- **消隐**：面仍要画——用底色（`--m-ground`）填、墨描（画家算法下的消隐线；不填，远处的线会透出来）。
- 块顶铺 45° 斜线表示实心（间距 5 px，范围 4–9；墨 38%、宽 0.7）；选中房间用 `--m-select-fill` 淡填，再描 `--m-select` 边线。
- 线重：基准 0.7–1.1 px（板顶 1.1、板边 0.9、墙面 0.8、块 1、房间 0.7）× `clamp(k/9, 0.7, 1.6)`；墙帽仍是真实几何。可选（建议）背光面线重 ×1.3。
- 标记只剩环 + 图像，dot 空心，stamp 的齿孔就是线；入口箭头改描边 + 22% 填；路线仍是粗线 + 底色晕边。
- 陷阱：叠层淡出时填充遮罩要同步淡出；用黑白检查对比度（它常被打印）。

### 14.3 clay（黏土）
哑光实体、柔和环境光，几乎无墨线。
- 令牌：room / slab / block / wall 同一色相，ΔL 0.03–0.06，对比交给路线和标记；引擎里房间 = `mix(slab, room, 0.35)`，面与帽同色 0.7 px 描边。
- 光照跨度远大于 paper：板边 `0.74 − 0.26s`、墙 `0.90 − 0.30s`、块 `0.88 − 0.30s`、顶 ×1.07（paper 跨度 0.40 / 0.26 / 0.32）。
- **接触阴影**：墙帽 / 块底面沿屏幕右平移 0.45 m（`--m-light: right` 反向，`top` 不偏移），两遍叠加（描边宽 `0.9k·0.8` 与 `0.45k·0.8`，墨 alpha .05 / .06）得软边；`filter: blur` 太贵。标记影加大（半径 0.7r）。
- 阴影画在该层墙块之前；四边形翻倍（总览 ~1000）仍可按需渲染；阴影不盖路线。

### 14.4 blueprint（蓝图）
深底浅线。
- 引擎自取：`--m-cap` 与 `--m-ground` 中较暗者为底、较亮者为线；浅色主题则把墨色混 70% 到近黑蓝作底、线太暗时混 78% 白（令牌不必先给深色；想自己控制就直接设 `--m-ground` 深、`--m-cap` 浅）。route 用暖色（橙 / 荧光黄绿），对深底 ≥ 4.5 : 1；climb 与 route 色相差 ≥ 50°。
- 面 = 底色混线色：板顶 5%、房间 11%、墙面 7%、块面 14%、块顶 20%；描边线色 85% / 50%；块顶加斜线。
- **地面网格**（裁在板内）：1 m 细线（alpha .07，宽 .6，`k ≥ 7` 才画）+ 5 m 粗线（alpha .16，宽 .7）；`k < 4` 不画；最底层、不参与命中。
- 尺寸标注（本套件设计，引擎未内置）：沿外轮廓最长两边画尺寸线（两端 tick + 居中 `12.4 m`，`--f-label` 9–10 px），轴线编号圈放网格边缘——该方向的分隔线母题延伸进地图。
- 光照弱，层级靠线重和不透明度。陷阱：深底上亮晕边成亮块，**晕边色 = 底**；`shadowBlur` 每帧太贵，用双线描边模拟发光。

### 14.5 riso（孔版 / 套色印刷）
两三种专色平涂叠印，轻微错位。
- 令牌：ground = 纸白；墨色对纸 ≥ 3 : 1，叠印色 = `multiply` 的结果（先算好对比度）。
- 引擎：整层 `globalCompositeOperation = "multiply"` 画在纸色上；**填充偏移 (+1.2, +0.8) px、墨线（墙帽等）反向偏移 (−1, −0.6) px**（范围 1–2 px）。偏移只改多边形坐标，**不动命中表**；文字、路线、标记在合成之后画。要三版以上就每版一张离屏画布再合成。
- 明暗**两阶离散**（`s > 0.35` ×0.8，`> −0.35` ×0.9，其余 ×1）；板边 = 纸色混 62% 墨。想要网点 / 纸纹（建议）：`createPattern` 点距 3–4 px、2–4% 颗粒（128 px 平铺，不要每帧生成）。
- 陷阱：错位 > 2 px 文字发虚；深色里 `multiply` 过暗，换 `screen` 或另备深纸色；图案按 DPR 取整，否则摩尔纹；路线在叠印区的对比单独查。

## 15 投影 / Projections（`--m-projection`）

`pitch` / `yaw` 取 `--m-pitch` / `--m-yaw`，其余模式按 §2.3 偏移。

**哪个投影会转（brief 里的"可旋转"和"3D"不是一回事）**

| 投影 | 单指横拖 | `--keep projection=rotate` | `--keep projection=3d` |
|---|---|---|---|
| orbit | 转（偏航自由） | 可 | 可 |
| exploded | 转（同 orbit 的手势） | 可 | 可 |
| oblique | 平移，偏航锁定、扭转禁用 | 不可 | 可 |
| plan | 俯视，只在纸面内转 | 不可 | 不可 |

brief 写"能转 / 可旋转 / 绕着看"就冻结 `rotate`；只写"立体 / 看得出几层"才用 `3d`（那就可能抽到 oblique）。`rotate` 取该方向自己列的 orbit / exploded，没有就用 exploded 并记进 `adjusted`；`directions.json` 每个方向至少列一个会转的投影，`kit.py --validate` 检查。已经抽到 oblique 才发现要转：`draw.py adjust projection=orbit`（或 exploded），再 `install.py --update`，不重抽（lessons I14）。

### 15.1 orbit（原站）
偏航自由，单指转盘，惯性、橡皮筋、双指三自由度（§3），叠层总览 + 转入开场。适合"一栋楼，各层都要看"。范围：俯仰 30–40°，起始偏航 20–45°，L/R 5–10。

### 15.2 oblique（斜投影）
- 相机：**平行投影**（`k` 恒等）；屏幕右 = 平面 x，屏幕上 = (0, −sin p, cos p)，竖直轴向一侧倾斜 `shx = clamp(−tan(yaw)·cos(pitch)·0.9, ±1.2)`——`--m-yaw` 在此是**倾斜角**而非旋转；平面不转，房间保持矩形，墙向一侧倒。
- 手势：**拖动 = 平移**：`tx −= Δx/k`，`ty −= Δy/(k·sin p)`（触屏只平移 x，竖滑归页面）；松手带速度；双指缩放 + 平移，扭转禁用；方向键每次平移 60 px。
- 面法线恒定，明暗固定；开场不转偏航，只升层；Reset 容差再加平移 < 0.8 m。
- 代价：没有"绕到后面看"；楼层多时借 exploded 的间距或选层。适合插画感、几乎平的场地。提示条和 `aria-label` 不要写"拖动旋转"（起步页按卡的投影选词：oblique 取 `map_hint_pan`、`map_drag_pan`、`map_what_pan`，自己手写的页面照此办）。

### 15.3 exploded（爆炸分层）
- 手势与 orbit 相同（偏航自由、惯性、橡皮筋），所以 brief 要"可旋转"时它和 orbit 一样合格；差别在层距，不在手势。
- 层距 = 相接值 ×1.55（范围 1.3–2.0），路线叠放 ×1.2；可再沿屏幕右轴给每层 `ox` 错 2–6 m。
- **连接是主角**：竖井画成虚中线 + 落点外框（§9）；选层 = 把一层抽出来，其余滑走淡出（也可留 alpha 0.12 保持结构感）。
- 取景含所有层与空气；俯仰 24–32° 让层间可分；`gut` 留左槽放楼层数字；空气大时 `share` 降到 0.84。
- 排序陷阱：仍按 z 升序画整层（上层板边会盖下层标记）。

### 15.4 plan（平面）
- 引擎：俯仰 84°（聚焦房间 87°），限位 80–89°，偏航 = 令牌 ×0.5，仍可自由转；`--m-pitch` 不起作用。
- **一切随 `sin(pitch)` 自然退化**：贴地椭圆变圆；针长 `pinH·cos(pitch)` 在 84° 仅 0.22 m，**标记不要茎**；墙只剩帽（`--m-wall-h` 0.3–0.6，或按线画）。
- 楼层叠不了：总览 / 路线按宽高比**平铺**（竖屏一列、宽屏一行，间隔 6 m，路线 7 m），楼层数字居中于各层之上；井不画；点选半径可 +4 px。
- 适合展位密集、要读房号、与打印同源。代价：没有透视就没有层次——用帽线重、尺寸标注（blueprint）或块面阴影（clay）补。

## 16 验收 / Acceptance
- 375 px 宽，浅 / 深色各看：总览、单层、聚焦房间、跨层路线、逐步取景。
- 动：拖动 1:1；松手惯性；能抓住滑行中的楼；过限位有阻力并弹回；双指缩放 / 扭转 / 倾斜同时；键盘。
- 静：停下后无 rAF；滚出视口 / 切走标签无 rAF；减弱动效下虚线静止、无脉冲、无开场。
- 画：墙角无缺口；帽线压在所有面上；路线不被上层盖；晕边 W/M/N 无刺；标记图像加载前后不跳。
- 状：三档透明；单步另一层 12%；`locked` 时点按无效；Reset 仅离家出现；选中的房间有淡染 + 边线，开放区也能选。
- 色：浅 / 深色里 `--m-cap` 对 `--m-slab` ≥ 7 : 1、`--m-wall` ≥ 3 : 1（`lint_floor.py` 已查）。
- 手势：`rotate` 的牌（orbit / exploded）拖动能绕到后面；oblique 的牌拖动是平移，提示条与 aria 不写"旋转"。
- 长：长宽比 > 1.6 的楼在竖屏 375 px 下，每层脚印接近占满可用宽，转横屏回到原偏航（§2.8）；带洞的回廊两圈轮廓都在，点洞里不选中回廊，展位沿环排开（§1.3）。
- 极：四个方向猛拖到头，控制台为空（§3.4）；`focusRoom(null)` 回到聚焦前的视图；lead 翻一次，标签主次随之对调；有挑空的场地，叠层看得见井，单层看得见 X。
- `--m-projection` / `--m-material` / `--m-token` 与原站相同的数目 ≤ 1，写进项目 `DESIGN.md`。
