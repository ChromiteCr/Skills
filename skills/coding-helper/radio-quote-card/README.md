# radio-quote-card

赛车队无线电字幕那种格式的语录卡。给名字、内容、主色，出一张 800×1000 的单文件 HTML。

## 文件

```
radio-quote-card/
├── SKILL.md                  技能本体
├── README.md                 这份
├── templates/radio-card.html 模板，{{NAME}} {{QUOTE}} 待填
└── examples/example-card.html 填好的成品，浏览器直接打开
```

## 三个输入

```
名字：MORELLI
内容：Why did I have to let him by? Let's talk after the race
主色：#e8112d
图标：（可选，不给就不放）
```

## 改哪里

| 想改 | 改哪 |
|---|---|
| 主色 | `:root` 里的 `--accent`，一处 |
| 名字 | `.name` 里的文字 |
| 内容 | `.quote` 里的文字 |
| 语录字号 | `.quote` 的 `font-size`，按字符数选档位 |
| 语录换行宽度 | `.quote` 的 `max-width`，默认 86%。留一条左边距是刻意的，占满整宽版式就散了 |
| 加图标 | 打开 `.logo` 的 CSS 和 `<img class="logo">` 两处注释，它在第二行 RADIO 左边 |

**这四处不要改**，改了就不是这个格式了：

1. 名字和 RADIO 上下两行，RADIO 大一号（138px vs 116px）
2. 标题和语录都右对齐
3. 语录 `max-width: 86%`，左边大片留空
4. 近黑双层底色，上浅下深，中间一道可见分界

## 语录字号档位

| 字符数 | font-size |
|---|---|
| ≤ 60 | 66px |
| 61–100 | 56px |
| 101–140 | 46px |
| >140 | 太长了，先删 |

## 波形

按「语录 + 名字」做种子生成，同一句话每次渲染都是同一条。不要换成 `Math.random()`，
否则同一张卡截两次波形不一样。

148 根、1px 间隔、中间高两头低。这几个数是对着参考图调的，改大噪声就会从电平表变成随机柱状图。

## 边界

图标位只放使用者自己提供的图。这个技能不生成任何车队或厂商的徽标。

内容如果是真实引语，要能说出出处；是玩梗就说清楚是玩梗。这个格式看起来很像官方转播字幕，
拿它给真人配一句他没说过的话，效果等同伪造发言。

## 示例说明

`examples/` 里的 MORELLI 是虚构人名，那句话是编来演示格式的，不对应任何真实的人。
