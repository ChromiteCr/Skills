# launch-summary-panel

把散落的产品资料收成一张 16:9 的 bento 总结面板。发布会 summary slide 那种信息密度。

## 文件

```
launch-summary-panel/
├── SKILL.md                      技能本体：触发场景、两阶段流程、事实校验、视觉原则、禁止事项
├── README.md                     这份
├── templates/
│   ├── panel-brief.md            阶段一的策划稿模板
│   └── panel.html                阶段二的面板模板，{{...}} 待填
└── examples/
    ├── example-brief.md          填好的策划稿（虚构产品 Halcyon 7）
    └── example-panel.html        由它生成的面板，可直接打开看效果
```

先看 `examples/example-panel.html`，浏览器直接打开就行，不需要起服务。

## 两步走

**第一步产出 `panel-brief.md`**：定位、核心卖点、支撑卖点、数字锚点、信息分组、
每条的出处或【未确认】、版式建议、舍弃项与原因。写完停下等确认。

**第二步产出 `panel.html`**：单文件、内联 CSS、1600×900、light/dark 双主题、
不引任何外部资源。

中间那次确认不能省。跳过它等于把"哪条卖点该上、哪个数字有出处"的判断藏进 HTML，
使用者只能全盘接受或者推倒重来。

## 面板结构

```
┌─────────────────────────────────────────────┐
│ 品类   产品名                      一句话定位 │
├──────────────┬──────────────┬───────────────┤
│              │              │               │
│              │  最大卖点     │   大卡 1      │
│    HERO      │  (116px 数字) │               │
│              ├───────┬──────┴───────────────┤
│              │ 大卡2 │      大卡 3          │
├────┬────┬────┴──┬────┴───┬────────┬─────────┤
│小卡│小卡│  小卡  │  小卡  │  小卡  │  小卡   │
├────┴────┴───────┴────────┴────────┴─────────┤
│ 资料来源                     未确认项说明     │
└─────────────────────────────────────────────┘
```

层级靠字号拉开：最大卖点 116px、大卡数字 52px、小卡 22px。三档挨着就等于没有层级。

## 主题与截图

默认 light。舞台外面有两个按钮，一个切 dark，一个在"适配窗口"和"原始尺寸"之间切。
按钮在 1600×900 的舞台外，截图舞台区域不会把它们带进去。

要原始像素的图就先点"原始尺寸"，再截舞台那一块。

## 换 hero 图

模板里 `.hero-ph` 是占位块。替换成：

```html
<section class="card he">
  <img src="your-image.jpg" class="hero-img" alt="">
</section>
```

再加一条样式：

```css
.hero-img { width: 100%; height: 100%; object-fit: cover; border-radius: inherit; }
```

图必须是你有权使用的。这个技能不提供也不生成任何厂商的产品图。

## 换主色

只动 `--accent` 一处，light 和 dark 各一个值。其余灰阶是配套的，单独改会花。

## 示例数据说明

`examples/` 里的 Halcyon 7 是虚构产品，所有数字都是示例值，不对应任何真实设备。
拿它看格式，不要照抄数字。
