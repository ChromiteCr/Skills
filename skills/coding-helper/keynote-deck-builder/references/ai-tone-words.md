# AI 腔词表

SKILL.md「片上文字的硬性写作规则」第 8 条的全文。那里只放判断办法和自查命令，这里放完整词表、替换写法和来源。
`ai-tone-words.txt` 是同一份词表的 grep 版，一行一个；两边增删要同步。

## 怎么判断：删词测试

把这个词删掉，或者换成一句大白话，句子少了具体信息吗？

- **没少**，就是 AI 腔，改。「打造一款产品」和「做一款产品」说的是同一件事；「讲隐私边界」删掉「边界」，
  听众还是不知道那条线在哪。
- **少了**，就是术语或本义，照用。物理课的「边界条件」、热力学的「熵」、生物课的「生态系统」、
  排版的「对齐」、习题的「答案」都是这种。

改的方向只有一个：**换成能被检验的具体东西**，一个数、一个动作、一个时刻、一个取舍，
也就是 SKILL.md「没有数字时，能当垫子的只有四样」那一节。只删不补，句子常常就空了；
空了说明这一句本来就没有内容，该和使用者确认这一拍到底要讲什么。

## 为什么片上尤其要紧

一张片只有十几个字，一个 AI 腔词就占了十分之一。长文里一个「赋能」读者一扫而过，
投影上的「赋能」会被整个会场盯着看好几秒，而且这类词最常见的位置正是标题和收束句。
讲者备注和讲义也要查：备注会被念出来，讲义会被逐字读。

## 词表

### 一、这两年最容易一眼认出的抽象名词

| 词 | AI 常见用法 | 换成 |
|---|---|---|
| 边界 | 隐私边界、能力边界、「边界在哪」 | 说出那条线本身：「不录音频」「只存在本机」「超过 20 分钟就不准」 |
| 张力 | 「形成张力」「充满张力」 | 说出是哪两样东西在拉扯：「又要轻，又要撑一整天」 |
| 底色 | 「温暖的底色」「产品的底色」 | 删；要讲成分就直说成分 |
| 叙事（比喻义） | 品牌叙事、宏大叙事、「新的叙事」 | 「说法」「讲法」；真要讲故事就把那个故事写出来 |
| 质感 | 「更有质感」 | 写材质或手感：「铝壳」「磨砂」「握着不滑」 |
| 温度（比喻义） | 「有温度的产品」 | 写出那件体贴的事本身 |
| 维度 | 「多维度」「从三个维度看」 | 「方面」，或者直接列出是哪几样 |
| 锚点、锚定（比喻义） | 「数字锚点」「锚定用户心智」 | 写那个数字本身；「让人记住」 |
| 切口、楔子 | 「找到切口」「作为楔子」 | 「从哪入手」「先做哪一件」 |
| 答案（比喻义） | 「这就是我们的答案」「时间给出了答案」 | 直接写结果 |
| 无限可能、XX 的力量 | 「探索无限可能」「专注的力量」 | 写它具体能做的那一件事 |
| 本质上、真正的、关键在于 | 「本质上是……」「真正的问题是……」 | 删掉，直接说那件事 |

### 二、汇报腔与互联网黑话

与 `writing-rules` 规则十一 D 组、SKILL.md 硬性规则第 6 条同一类，这里补全：

> 痛点、闭环、根因、口径、赋能、抓手、心智、一句话总结、底层逻辑、颗粒度、链路、沉淀、打通、
> 落地（比喻义）、赛道、护城河、破局、底座、飞轮、认知升级、长期主义、降维打击、弯道超车

换成：直接说做了什么、改了什么、多了什么。「打通了数据链路」→「手机和手表的记录合成一条」。

### 三、宣传腔

发布会片子最容易沾上。前七个沿用 SKILL.md「拍不出来」一节：

> 革命性、颠覆、重新定义、魔法般、无与伦比、极致、这改变了一切、
> 重塑、无缝、一站式、全方位、前所未有、开启新篇章、未来已来、打造、赋予、彰显、见证、旅程、解锁、点燃

换成：能被检验的东西。「无缝衔接」→「合上盖子，手机上接着写」；「极致轻薄」→「11.3 毫米，24 克」。

### 四、伪深刻意象

模型写「有文采」的中文时爱往上面堆宇宙和物理名词：

> 量子纠缠、熵增、解构、祛魅、光谱（比喻义）、涟漪、回响、注脚、年轮、褶皱、星辰大海

换成：删。物理课讲量子、热力学讲熵是本义，照用。

### 五、连接词与套话

片上本来放不下，多出在讲者备注和讲义里：

> 值得注意的是、不难发现、换句话说、这意味着、说白了、归根结底、总而言之、综上所述、让我们、不妨

换成：删掉，直接说那件事。「让我们」另外违反 SKILL.md 句式第 8 条（片上不用「我们」）。

### 句式

句式层面的 AI 腔已有专门的规则，这里只列指向：「不是 A，是 B」见硬性规则第 2 条，强行升华见第 3 条，
三点排比见「与 `writing-rules` 的关系」。「首先……其次……最后」在片上不会出现，讲义里也别用。

## 自查命令

在本 skill 目录下跑，把产出文件的路径换进去（没有讲义就去掉那一个）：

```bash
grep -nFf references/ai-tone-words.txt deck-outline.md deck.html handout.md
grep -nE '不是[^，。；]{1,20}[，,]\s*(而)?是' deck-outline.md deck.html handout.md
```

每条命中都过一遍删词测试，本义就留。`deck.html` 里命中在样式或脚本注释中的，是模板自己的说明，不算。

## 词表会过时

- 这类词一旦被大家认出，模型和写手都会换新词，**表面词表会不断失效**（硅星人Pro，2026-08-31）。
  每年把这份表过一遍；在自己的片子里又看到新的高频空词，加进 `ai-tone-words.txt`，并在上面的表里补一行。
- 词表只管表层。更深的 AI 痕迹在结构上：主题解释过度、结尾硬收成升华、每一处都求完整。
  这些由 SKILL.md 的其他规则管：一片一个概念、写完即止、杜绝强行升华。只换词不改结构，片子照样一眼 AI。
- 只列禁词效果有限：只告诉模型不要什么、不给它看要什么，它会换一批同样空的词（宝玉，2026-02-14）。
  所以上面每个词都配了「换成」，SKILL.md 里也有「能当垫子的四样」。
