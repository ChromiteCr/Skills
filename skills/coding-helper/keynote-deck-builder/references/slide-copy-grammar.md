# 片上文字的句式 / The grammar of slide copy

从 SKILL.md 原样移出（0.7.1）。每次都要守的十三条仍写在 SKILL.md「片上文字的句式」，这里是全文：
例句、取证，以及与 `writing-rules` 的关系。读取条件也写在 SKILL.md 那一节。
文中说的「上面」「场合一节」「反发布会腔那一节」都指 SKILL.md 里的对应小节。

### 片上文字的句式

上面管的是**写什么**，这一节管**用什么句式写**。实跑一次之后补的：产出的文案在长度和
具体性上都合格，语气却是讲解和提问，不是片上文字。

**片上是陈述，不是讲解，更不是提问。** 片子锚定注意力，解释留给嘴（A 档）。

#### 先分清：官网文案不是片上文字

这一节的第一版是从苹果官网标题推出来的，**那是个错的取材面**。两者处境不同：

| | 官网文案 | 片上文字 |
|---|---|---|
| 读者 | 自己停下来看，可以反复读 | 三秒扫一眼，旁边有人在讲 |
| 陌生化 | 是卖点，让人停住 | 是成本，抢走理解时间 |
| 能承受 | 拗口、生造、语序古怪 | 一眼读不懂就是失败 |

所以官网那套手法**不能整套搬上片**。下面第 2、3 条（名词短语、省动词）是两边通用的，
第 6 条（对仗）要克制，而「苹果式中文」那一整套要避开。

**1. 不用问句。** 苹果官网中英文页面的标题里都没有问句（A 档），发布会片上也没有——
2007 年那场，片上是「A widescreen iPod with touch controls」，Jobs 嘴上说的是
「Does it do email? Yeah, it does.」**问句在嘴里。**

最容易犯的是把文档小标题直接搬上片：

```
禁：它凭什么知道该建议什么   改：建议的来处
禁：它怎么用这些信号         改：（这一节根本不需要分隔片，删掉）
禁：图表讲什么               改：三年采用率
禁：它不做什么               改：取舍
```

反问式重构（「你的下一台电脑，何必是电脑」）确实存在，但占比极低且很难写好（B 档），
**默认不用**。

**课堂与讲堂的例外只有一个：提问片。** 它和上面那些问句的区别在于**真有人要回答**：
讲的人停下来，听众想、举手或写下来，答案随后揭晓（检查题当场，预测题讲完那一段）。判据是：

```
是提问片：  摆长变成 4 倍，周期变成几倍？      （下面有选项，随后揭晓）
不是：      周期和什么有关                      （这是章节标题，改成名词「周期」）
不是：      为什么会这样？                      （没有人要回答，这是讲的人自问自答，留给嘴）
```

**2. 名词短语优先。** 中文文案约八成是名词性结构，英文片上标题约 65%（A 档）。
先想能不能写成名词短语，写不成再退到短陈述句。

**课堂与讲堂的证据片例外**：标题写一句主张，说出这张片的结论（依据见「场合」一节）。
主张句仍然是陈述，不是问句，末尾仍然不加句号：

```
名词短语（发布会）：  周期与摆长
主张句（课堂）：      摆长变成四倍，周期只变成两倍
```

判断用哪种只问一句：**这张片是在给一个东西命名，还是在证明一件事？** 命名用名词，证明用主张。

**3. 能省动词就省，或把动词后移。**

```
弱：电池可以用一整天        强：一整天的续航
弱：高能效的 A15 芯片       强：A15 芯片的高能效
```

**4. 两层结构：名词标签 + 一句短陈述。** 这是苹果中文页的固定模式（A 档）：

```
轻松上手 / 从其他智能手机换成 iPhone，很简单
经久耐用 / iPhone 的价值，时间可证
环保     / 设计，为地球设想
```

模板里「时刻」片型的 `.lead` 加正文正是这个结构，其余片型也可以照用。

**5. 中文标题末尾不加句号**（A 档）。要停顿用逗号或断行。
英文可以用句号分隔并列的名词短语（「MacBook Air. The world's thinnest notebook.」），
**中文不要照搬这条**。

**6. 对仗能自然成就用，凑不出来就别凑。**

自然成的样子（A 档）：

```
身量小，能量大
事事拿手，轻松入手
```

**凑出来的样子**，也就是被嘲笑的那种：

```
开发者的大事，大快所有人心的大好事
```

三个「大」重复不产生递进只产生冗余，成语「大快人心」被硬塞进「所有」，读起来拗口。
**判断方法：把对仗拆掉，意思有没有损失。** 没有损失，说明对仗只是装饰，删掉。

**7. 章节分隔用单个名词。** 隐私、环保、创新、iOS（A 档）。
写不出一个名词就说明这一节的主题还没想清楚，或者这张分隔片根本不需要。

**8. 人称：中文可以用「你」，不要用「我们」。**
中文页有「数据怎么安置，全听你的」；英文片上则连 you 都不用，走产品视角（B 档）。
**这条中英相反，产出中文时按中文的来。**

**9. 讲机制时片上少写字。** 苹果讲机制靠动画和演示，片上只留一个名字当标注（B 档）。
所以「信号汇入」那一类片，标题给名词，输入输出给短标签，**把原理留给嘴讲**。

**10. 口语有线。** 判据：一个不每天上网的读者能不能不靠语境看懂？
「摆在那儿了」「搞定」「贼快」这类要么方言要么随便，不要。平台梗与过时网络语同样不要。

**11. 避开「苹果式中文」。** 这个词在中文语境里是批评性的，指苹果翻译腔那种句式。
它的五种手法里，**只有第三条可以用**：

| 手法 | 片上能不能用 |
|---|---|
| 碎句子、缺主语 | **不能**。片上没有上下文补主语，读者会卡住 |
| 硬凑排比与顶真 | **不能**。见第 6 条 |
| **名词前置**（「A15 芯片的高能效」）| **可以**。不增加理解成本，见第 3 条 |
| 随便拆解成语、生造四字词 | **不能**。「大快所有人心」就是拆坏的 |
| 英文语序直译 | **不能**。见第 12 条 |

**12. 警惕直译英文句式。** 「比大更大」翻车有三个原因（A 档）：同一个字重复不产生递进
只产生冗余；撞上廉价广告的语感；「比…还…」是书面古语，与现代产品主张冲突。
改成「岂止于大」才成立。**英文原句的结构不一定在中文里成立，要重写不要直译。**

**13. 课堂与讲堂里用学科通行的术语，不自造新词。** 发布会给功能起名（一个短而好记的名字，方便之后反复指称），
这个做法在课堂上要反过来用：**概念已经有名字的，就用那个名字**，听众课后要拿它去查、去读别的材料；
只有你自己的方法、你自己的发现还没有名字时，才起一个，起了就全场一致。
同一个概念全场同一种颜色，公式里、图上、字里都一样，这也是信号原则的用法。

### 与 `writing-rules` 的关系：三点式

`writing-rules` 规则三是「打破三点式惯性」。这个 skill 早先的版本写的是「展开用三点」，
那确实和它冲突——**但那是我把证据读窄了**，不是两条规则真的对立。

拆开看研究说了什么：

| 说法 | 档 | 它支撑什么 |
|---|---|---|
| 工作记忆约容纳三个块 | A | 一个**上限**：并列的点超过三四个会过载 |
| 「三是最优数，分段和段内分点都用三」 | B | Gallo 作为演讲教练的**处方**。容量上限推不出「必须凑够三个」 |

本 skill 只采纳上限。所以正确的说法是：**至多三点，点数由内容定。**
两点很常见，一点也行——只有一件事值得说的时候，硬拆成三件反而稀释它。

这样一来两边并不冲突：`writing-rules` 反对的是**总是产出三个**这种惯性，
本 skill 给的是**不要超过三个**这个上限。一个反对下限，一个规定上限。

回顾片四条封顶、推演四行封顶，是同一个上限在课堂上的写法：工作记忆约三到四个块，不是凑数的指标。

仍然要注意的是**视觉层面的三**：每张片都摆三个并列格子、三条并排短语、三个图标配三行字，
即使叙事上只有两点，看起来也会落进同一种惯性。bento 三格、规格三列、取舍三条不要连着用。

### 不适用的几条

写在这里是为了以后不被人"补全"：

| writing-rules 的规则 | 为什么不适用 |
|---|---|
| 六 长短句交替、不用嵌套从句 | 片上没有段落，最长的说明小字也就 24 字 |
| 十二 语气温和、Z 世代幽默 | 片上文字不是对话，目标是具体不是亲切 |
| 十五 检索优先英文来源 | 与排版无关 |
| 四 删句首冗余连接词 | 片上本来就不该有"因此""然而"开头的句子，这条自动满足 |

`writing-rules` 规则十二禁「演讲腔」，看起来和这个 skill 打架，其实不打架：
它禁的是**把演讲腔当文风用在散文里**，而本 skill 的「反发布会腔」一节禁的是同一样东西
在片子上的形态。两者同向。
