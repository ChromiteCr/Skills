### 十二类课堂片型

课堂与讲堂的十二类：

- **路线**：两到四站，每站一个名词。开场给全貌，每个章节分隔处复制一张，当前站最亮、没讲的灰、讲过的更暗；只是几个字，不做成胶囊按钮。
  这就是这套风格里目录页的位置：不是编号列表，是一条会前进的路
- **提问**：真要听众作答的题，二到四个选项排成几栏，每栏上面一条细线，不做成带底色的按钮。
  问号只给这一类和引导问句（标题是一问，下一张片立刻用一句结论回答它，一节课一两处，见 slide-copy-grammar 第 1 条）。
  **概念题本片揭晓；预测题本片不揭晓，讲完那一段后复制一张同样的题再揭晓**（示例 lecture-deck 里「回到预测题」那张）。
  只靠后面的主张片说出答案不算揭晓：听众要对着自己押的选项核对。先不揭晓，是因为课前小测不给反馈也有效
  （Soderstrom 与 Bjork 2023）；先揭晓了，听讲时就没有要核对的东西
- **满版图**：拍的是一个地方、一个现象、一个时刻，照片出血铺满，字只放在底部压暗区
- **半幅图**：图出血占右半，左半一句短结论，每行 8 字，**两行封顶**。字不压图，最稳
- **主张与证据**：左上一行结论，19 字封顶，争取 12 字内，句末不加句号。下面是为这句结论重画的图、图表、公式或照片，
  图上只有一处重点（强调色，或画在图上的箭头、框）；左下角是出处。细则见下面「学术片怎么少字」
- **概念**：学科通行的术语，有符号就把符号放在术语旁边。定义由讲的人说、写进讲义，片上不垫一行定义（0.9.0）
- **公式**：一张片一个式子，讲到哪一项哪一项换色。各项的名字前面的概念片交代过，不在式子下面再列一排
- **推演**：一次出一行，讲过的调暗，右栏写这一步的依据，**一行 8 字内**、写名字（「牛顿第二定律」「sin θ ≈ θ」）。
  代入、化简这类步也写依据：「代入已知量」「两位有效数字」「开方取正值」可以，「计算」「结果」「解出 t」不行，它们没说凭什么。**四行封顶**
- **代码**：只放要讲的几行，**十二行封顶**，讲到哪行亮哪行
- **误解**：「常见误解」标签先亮，误解本身用次要色，改正在本片揭晓并给误解划线
- **回顾**：课堂的回顾，左列提示词（4 字），旁边放前面那张关键图的缩略图，右列要点逐条揭晓，每条是一个短语（8 字内）。
  整节课没有图（全靠实物演示）时，缩略图换成那一步的关键符号或式子，或者干脆不放。
  先给提示让人自己想，再揭晓。**三条封顶**。
  学术报告的收尾做成「贡献」：两三条，每条一行（12 字内），一次出齐，问答时一直停着（Winston）
- **参考文献**：进讲义；讲到别人的结论时，在那张片的出处行写「作者 年份」。
  非要上片，就放在最后一张之后当备用页，**六条封顶**，多了只放讲义

### 学术片怎么少字

0.10.0 新加。适用于课堂与讲堂，学术报告也算；发布会不变，答辩的结果页可以借用。
SKILL.md「场合」里那几行是摘要，这里是细则。取证在 stage-style-research 第 12b 节，档次照那里标。

**证据片、结果片只有一句整话，就是标题**（提问片的题干、误解片的原话与正确说法各有自己的写法）。其余只能是：贴在图上的两到六个字的标签、数字前后的限定词与单位、
出处行、「未确认」标记（A：MIT Comm Lab 生物工程系，理想情况下全页唯一的完整句就是标题）。

1. **证据片、结果片的标题是一句短结论**：一行，19 字封顶，争取 12 字内，句末不加句号。
   结论写进标题，是斯坦福、MIT 几份指南的共同要求（A：Kayvon p.48–49；MIT Comm Lab 的 BE、NSE、MechE；ENGR 103 p.4；CWSEI 汇编）。
   证据要说准：
   - Garner 与 Alley 2013 的 d = 0.81 是整套做法的效果：结论标题、每张都有相关图、每页 21.2 词对 41.5 词、
     11 张里 8 张讲到才出现，论文自己写明五条多媒体原则同时用上（A）。不能只记在标题上
   - 同一团队 2012 年复验时，对照组也用了同样设计的图，结论标题组只剩不显著的正向趋势（B，只写在 references 里，不上示例片）
   - 没有研究直接比较过长短不同的主张标题（C）。「两行」是 Alley 体系的上限，不是目标（A）；
     斯坦福、MIT 真实页面上的主张标题是 3–13 个英文词（A）。「一行」是本 skill 为了少字定的
2. **正文是为这句结论重画的图。**
   - 删掉无关的系列、面板、图例项、网格线和多余数值（A：Kayvon p.52；MIT CEE；一致性原则 23/23、中位 d = 0.86）
   - 曲线和部件旁直接贴标签，不用图例（A：ENGR 103 p.12–13；空间邻近原则 22/22、中位 d = 1.10）
3. **重点只有一处。** 强调色只给关键元素，其余调灰；要指的地方在图上画箭头或框，不用激光笔
   （A：MIT Comm Lab 的 NSE 与 BE；CS149 第 50、56 页；Winston 约 29:43–31:38）
4. **讲到才出现。** 图的各部分随讲解出现；文字不逐行飞入，推导除外
   （A：MIT Comm Lab BE 的分步揭示；Garner 与 Alley 的 11 张里有 8 张这样做）
5. **讲每张结果图的顺序写进讲者备注**：要回答什么问题 → 横纵轴 → 看哪里 → 高亮是什么意思（A：Kayvon p.44–47）
6. **不证明什么的片不写结论。** 概念片只有术语和符号；公式片只有式子；分节一个词；纯图片片可以没有标题
7. **两项自查**：
   - 只读标题：证据片的标题连起来读，是一段摘要（A：Kayvon p.54）
   - 把缩略图铺开，看哪张字多：字多的就拆或删（A：Winston 约 31:52）。参照示例里最密的一张，约 30 字
     （中文一字算一个，拉丁字母、数字两个算一个，讲者备注不算），超了先拆或删；这是参照，不是配额

**一张片一层字的依据换了**（0.10.0）：先引一致性原则与信号原则，再加 Yue、Bjork 与 Bjork 2013：
屏上一句稍作改写的短句比逐字照搬旁白好（d = 0.95），迁移也比不放字好（d ≈ 0.6）（A）。
冗余原则在 Mayer 2021 的汇总里只剩 8/12、中位 d = 0.10，只作旁证。全文在 slide-copy-grammar 第 4 条。

**不采纳的做法**（理由在 stage-style-research 第 12b 节）：

- Winston「证据片也删标题」。它和 Kayvon、MIT Comm Lab、Garner 与 Alley 都冲突；删标题只用于纯图片片、分节片、提问片
- 苹果式「证据页只放一个词或一张图，没有判断句」。Yue 2013 显示一句短结论比不放字好；Durand 也要求关键观点上片
- 把冗余原则当减字的主要依据
- 把 d = 0.81 记在句子标题这一项上
- 把每页 21.2 词当指标，或者定任何每页字数配额
- 每页放机构标识（ENGR 103 这样建议）
- 用 Winston 学生没发表的小实验当数字依据
- 默认用问句标题：Alley 2006 里问句改成句子后，有的题升、有的题降

**字号备查**：斯坦福 OCP、ENGR 103 与 Durand 的字号下限是 24 磅，约合本模板 1920×1080 画布上的 48px；
本 skill 的 40px 约合 20 磅。本轮不改 40px 下限，只记在这里备查。

### 课堂路线的依据

0.10.0 从 SKILL.md 原「叙事拍点」一节移来，改写成三条课堂路线各自的理由。
路线本身在 SKILL.md「叙事路线」的路线表里，照搬、改一条或自己拼都行；出处与档次见 stage-style-research 第 4b、12 节。

#### 先猜后讲

路线 → 现象 → 预测题 → 名字 → 机制 → 例题 → 回到预测题 → 误解 → 概念题 → 回顾。
这样排，是因为每一拍都对着一条学习研究：

- **现象先于名字**：先让人需要这个概念，再给它名字。这是「叙事路线」原则 1 在课堂上的样子：开头交代听众为什么要听。
  先让学生自己试、再讲解，元分析里总体有正效应（Sinha 与 Kapur 2021，g = 0.36，A）；
  但只在给对比案例、或者讲解从学生自己的方案讲起时才有效（Loibl、Roll 与 Rummel 2017，A）。
  所以讲名字和机制时，从听众刚才押的答案讲起
- **预测题在讲解之前**：先让听众押一个答案，讲解时他们在找自己押对没有。
  预测题本片不揭晓，讲完那一段复制一张同样的题再揭晓（回到预测题）；只靠后面的主张片说出答案不算揭晓。
  这一拍的效果有限，要说准：课前小测在真实课堂里有效（Soderstrom 与 Bjork 2023，A），
  在长的真实讲课录像里正向但有限（Toftness 等 2018，A）；先预测再看演示，正确解释率 30%，只看演示 24%（Crouch 等 2004，B）；
  IES 实践指南（Pashler 等 2007）把「用前测题引入新课」评为低证据。所以预测题是一个选项，不保证有效
- **名字先于机制**：先把几个关键部件的名字和作用交代清楚，再讲它们怎么配合。
  Mayer 等（2002）的三个实验里，先学部件名称与状态的一组，迁移测验全部胜出（A）
- **例题分步出**，每一步写清凭什么成立：好的例题用标注或分段把概念结构显出来（Atkinson 等 2000，A）。
  推演片的右栏写依据，就是这个做法
- **误解放在正确说法旁边**，不单独占一张大字片：指出误解、标明它不对、再给正确解释，
  三段一起比只讲正确解释有效（Tippett 2010 综述，A）
- **检查与回顾**：检查用概念题，人人作答（原则 7）。主动学习的元分析里，考试成绩高出 0.47 个标准差，
  传统讲授的挂科风险约是主动学习的 1.5 倍（Freeman 等 2014，225 项研究，A）。
  回顾先给提示让人自己想，再揭晓：做一次提取比重读有效（Adesope 等 2017，A）；IES 2007 也把「用测验让学生重温」评为强证据

**什么时候换路线**：低年级和通用技能，先讲后练占优（Sinha 与 Kapur 2021，A），改走「回顾—小步—例题」。
先猜后讲适合有一定基础、目标是概念理解的听众。

#### 同伴教学循环

路线 → 〔短讲 → 概念题独立作答 → 讨论 → 再答 → 讲解〕× 2–3 → 回顾。

**为什么有用**：每个人先独立押一个答案，再和邻座讨论，讨论完再答一次，讲的人最后讲解。
Crouch 与 Mazur（2001）的数据里，首轮正确率约 35–70% 时，讨论后的提升最明显（方法 A；该校的成绩数据 B）。
MIT 8.02 的 TEAL 把短讲、桌面实验、可视化、PRS 概念题和小组练习混在一节课里（结构 A）；
Dori 与 Belcher（2005）报告学习增益约为对照的 2 倍，但那是准实验（B）。

**什么时候选**：概念多、误解多，听众能当场投票或举手。题目出在大约一半人会、一半人不会的地方。
35–70% 是观察到的区间，不是硬门槛。

#### 回顾—小步—例题

提取式回顾 → 路线 → 小步讲 → 例题与练习交替 → 换情境再做一题 → 小结 → 下次预告。

**为什么有用**：IES 实践指南（Pashler 等 2007）把例题与练习交替评为中等证据，
用测验让学生重温、深度解释性提问评为强证据；Rosenshine 2012 的十条原则也是这个方向（B）。
斯坦福 CS106B 2022 冬第 7 讲就是这个顺序：提纲 → 提取式小测 → 逐步例题 → 换情境例题 → 今日小结 → 课后任务 → 下次预告
（A，指这份课件本身）。

**什么时候选**：技能型、程序型内容，新手多。例题对新手有效，对熟手优势消失，甚至反过来
（专长逆转，Kalyuga 等 2003，A）。所以听众越熟，例题越少；全是熟手时，换先猜后讲或同伴教学循环。

**三条都不是固定序列。** 把 5E 或 Gagné 九事件当固定序列用，证据弱（B）。
真实课件（CS231n、CS106B、MIT 8.02）都是开头回顾、中途提问，结尾怎么收各不一样（A，指这几份课件）。

### 课堂与讲堂另加的五条

1. **别人的结论与图，出处跟在同一张片上。** 左下角写「作者 年份」，全文放讲义。
   理由与数字的注脚一样：放大了，出处就要跟紧。两种情况不用逐张写：
   讲一篇论文（论文讲读）时，标题卡的出处行写一次「论文讲读 · 作者 年份」，后面出自这篇的结果片不再逐张写，
   引到别的文献照常在那张片上写；教科书里的定律、原理只写名字（「牛顿第二定律」），
   引到某项实验的结论才写出处（「两种质量相等」那一步写「Touboul 等 2022」）
2. **符号第一次出现的那张片上就说清它是什么、单位是什么。** 嘴上说，讲义写全；不要让听众等到三张片以后
3. **简化要标出来。** 「忽略空气阻力」「小角度下」这类条件写在用到它的那张片上，
   和数字的限定条件一样不能丢：写进式子（`≈`、「θ ≪ 1」，只放符号或短语，连括号 8 字内）、主张句或出处行，不另垫一行小字。
   **简化可以，简化成错的不行**
4. **分清「原文说的」和「我的理解」。** 讲别人的论文时，主张句写的是原文的结论还是你的解读，
   要在片上或讲义里看得出来
5. **公式与推演要能复核。** 每一步写清凭什么成立；有推导就在讲义里给全，
   片上省掉的步骤不能是错的步骤
