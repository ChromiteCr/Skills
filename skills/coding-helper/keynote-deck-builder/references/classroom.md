# 课堂与讲堂 / Classroom and lecture

从 SKILL.md 原样移出（0.7.1）的两块：逐片清单里十二类课堂片型的做法，事实校验里课堂与讲堂另加的五条。
读取条件写在 SKILL.md「逐片清单」：场合是课堂或讲堂，或者别的场合要用其中某一类时才读。

### 十二类课堂片型

课堂与讲堂的十二类：

- **路线**：两到四站，每站一个名词。开场给全貌，每个章节分隔处复制一张，当前站最亮、没讲的灰、讲过的更暗；只是几个字，不做成胶囊按钮。
  这就是这套风格里目录页的位置：不是编号列表，是一条会前进的路
- **提问**：真要听众作答的题，二到四个选项排成几栏，每栏上面一条细线，不做成带底色的按钮。
  问号只给这一类和引导问句（标题是一问，下一张片立刻用一句结论回答它，一节课一两处，见 slide-copy-grammar 第 1 条）。
  **概念题本片揭晓；预测题本片不揭晓，讲完那一段后复制一张同样的题再揭晓**（示例 lecture-deck 第 13 张）。
  只靠后面的主张片说出答案不算揭晓：听众要对着自己押的选项核对。先不揭晓是因为课前小测不给反馈也有效
  （Soderstrom 与 Bjork 2023），先揭晓反而把悬念用掉了
- **满版图**：拍的是一个地方、一个现象、一个时刻，照片出血铺满，字只放在底部压暗区
- **半幅图**：图出血占右半，左半放一句主张。字不压图，最稳
- **主张与证据**：左上一句完整的结论，下面是图、图表、公式或照片，左下角是出处
- **概念**：学科通行的术语，有符号就把符号放在术语旁边。定义由讲的人说、写进讲义，片上不垫一行定义（0.9.0）
- **公式**：一张片一个式子，讲到哪一项哪一项换色。各项的名字前面的概念片交代过，不在式子下面再列一排
- **推演**：一次出一行，讲过的调暗，右栏写这一步的依据，一行 11 字内、写名字（「牛顿第二定律」「sin θ ≈ θ」）。
  代入、化简这类步也写依据：「代入已知量」「两位有效数字」「开方取正值」可以，「计算」「结果」「解出 t」不行，它们没说凭什么。**四行封顶**
- **代码**：只放要讲的几行，**十二行封顶**，讲到哪行亮哪行
- **误解**：「常见误解」标签先亮，误解本身用次要色，改正在本片揭晓并给误解划线
- **回顾**：左列提示词，右列要点逐条揭晓。**四条封顶**
- **参考文献**：只在学术场合、只在最后，**六条封顶**，多了放讲义

### 课堂与讲堂另加的五条

1. **别人的结论与图，出处跟在同一张片上。** 左下角写「作者 年份」，全文放讲义或最后的参考文献片。
   理由与数字的注脚一样：放大了，出处就要跟紧
2. **符号第一次出现的那张片上就说清它是什么、单位是什么。** 嘴上说，讲义写全；不要让听众等到三张片以后
3. **简化要标出来。** 「忽略空气阻力」「小角度下」这类条件写在用到它的那张片上，
   和数字的限定条件一样不能丢：写进式子（`≈`、「θ ≪ 1」，只放符号或短语，连括号 8 字内）、主张句或出处行，不另垫一行小字。
   **简化可以，简化成错的不行**
4. **分清「原文说的」和「我的理解」。** 讲别人的论文时，主张句写的是原文的结论还是你的解读，
   要在片上或讲义里看得出来
5. **公式与推演要能复核。** 每一步写清凭什么成立；有推导就在讲义里给全，
   片上省掉的步骤不能是错的步骤
