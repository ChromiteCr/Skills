# 当这不是发布会 / Beyond launches

从 SKILL.md 原样移出（0.7.1）。读取条件写在 SKILL.md「当这不是发布会」：场合是答辩、课程汇报、路演或立项评审时才读。
文中说的「上面」「叙事拍点」都指 SKILL.md 里的对应小节。

### 当这不是发布会

答辩、课程汇报、路演、立项评审都能用这套视觉，但**拍点要改，而且有些片不能删**。

| 场合 | 拍点怎么改 |
|---|---|
| 答辩 / 课程汇报 | 「价格与可得」换成「这一阶段做到了什么」，收束前加分工。评委看的是工程量，三处攻关各给一张双列对比比笼统说"性能提升"有用 |
| 路演 | 「展开」后面加市场与商业模式，数字那一拍分成产品指标与经营指标两段 |
| 立项评审 | 「揭示」之后先给可行性，再展开 |

课堂与讲堂不在这张表里，它们的主线见上面「叙事拍点」。

**课程或评分表要求的页面不能自作主张删掉。** 目录页改用「路线」片型就有了位置；分工页用「双栏人物」；
工具使用说明页在这套风格里仍然没有位置，但它可能是评分项。处理办法是**问，不是删**：
在大纲的舍弃项里单独列出来，写清楚"这几页按这套风格去掉了，如果评分表要求必须有，我加回来"。

**要看密度的场合要提醒使用者。** 这套风格靠删信息取胜，而答辩评委有时候恰恰要看你到底做了多少。
可行的办法是把原始材料当讲义发，这份当投影用。**这一句要主动说，不要等使用者发现片子太空。**
