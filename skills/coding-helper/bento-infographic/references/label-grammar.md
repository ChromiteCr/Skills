# 标签怎么写 / Label grammar

一格一个功能，标签是这个功能的名字，不是说明。苹果的总结片上没有说明句，也没有页头、页脚和分组小标签（`apple-measurements.md`）。长度、行数、孤字、汉字与字母之间的空格，`validate_spec` 和自检会拦；句式、用词、有没有夸大，靠这份文件和 AI 腔词表。说明句放进交付说明，不上图。

## 通用

- 名词短语，不加句末标点；不写说明句和问句，不用动词开头的口号。
- 换行写成 `label` 里的 `\n`。每行是一个不折行的 span，浏览器不会替你折行，中英文一样；写了几行就画几行，自检 `label_lines` 会对照。
- 数字连单位当画面：用 `stat` 的 `value` 和 `unit`，别塞进标签的句子里。中文的量词（个、份、项）不当单位：放进标签开头，从数字接着读（`"62"` / `个技能`）；缩小挂在数字旁会读成两种字号（第 10 轮评审）。测量单位（小时、码值）照常用 `unit`。图标格这类没有大数字的格，可以在标签第二行带数量（"物理\n17 个技能"），数量要有 `facts`。
- 最高级（"最长""首款""最薄"）只给最重要的一两格。苹果约 80 个标签里只有 5 次（Biggest-ever、Thinnest iPhone ever 这类）。
- 没有出处又非放不可的数字（`"unverified": true`），标签里要写"未确认"，如"技能（未确认）"，英文写 unverified；标签里不写，`validate_spec` 会拒绝。

## 英文

- 句首大写，其余小写；专有名词和缩写照原样（HTML、pptx）。
- 1–7 个词，多数 2–4 个；最多 3 行。按空格切词，连字符的词算一个。样图里 7 个词的只有一条，样图 6 的 48MP Fusion Main camera with variable aperture。
- 常见句式是"功能 in 应用"，如 Send Later in Messages。本库的写法：Animated export in keynote-deck-builder。
- 不以句号、逗号收尾。

## 中文

- 两行相加 ≤ 12 字，每行 ≤ 11 字，最多 2 行。按折算数：汉字和全角标点算 1，拉丁字母和数字算 0.55，空格 0.3，其他半角符号 0.35。两行的标签合计也只有 12，每行大约 6 字。
- 一行不能只剩一个字：含汉字、折算不到 2 的行报 `一行只剩一个字（孤字）`。
- 换行手写，断在词组或逗号处。
- 名字里的空格用不换行空格（U+00A0），如 `"iPhone\u00a018\u00a0Pro\u00a0Max"`。渲染器原样保留；校验按空格算 0.3，数英文词数时仍当 4 个词。
- 汉字和拉丁字母、数字之间留一个空格："续航 36 小时""AI 使用"。全角标点两边不加空格："n = 12，室温"。前一条由 `cjk_spacing` 查，后一条要自己守。
- 字重 600、字距 0，和英文页一样；行高放松到 1.3（英文 1.18）。

## 研究模式：样本数与条件

research 的 `stat` 可写 `n` 和 `condition`，画在标签下面一行，字号也是 u。

- 格式：中文 `n = 5，室温`，英文 `n = 5, room temperature`。只写了一个就只画一个。
- `label` 这时只能是一行；多出的这行，中文折算 ≤ 11 字，英文 ≤ 7 词，超了报 `样本数与条件那一行太长`。
- `n` 是正整数。`condition` 写数字成立的前提，用短的名词短语，如"室温""p99"；不写结论，更不裸写"与理论吻合"。
- 统计量写进标签，不写进条件行："肤色色相最大漂移"比"肤色色相漂移 / 最大，护栏 6°"好。限值（护栏、上下限）放进 `facts` 和交付说明，不上图（第 10 轮评审：逗号连着限值的半句话不像苹果的标签）。
- 有达不到标准的，照实写："LUT 回读达标的风格 5/6"，不要只挑达标的那几个数。
- 没有不确定度的数，写 `exact` 或 `"n": 1`，见 `bento-json.md`。

## 中文：好例子与坏例子

| 好（都来自本库的样例） | 好在哪里 |
|---|---|
| `电影感调色` | 功能名，5 字，名词短语 |
| `照片跨页排版` | 写功能，不写分类：比"摄影"具体 |
| `物理\n17 个技能` | 手写断行；数字和汉字之间有空格 |
| `带动画导出` | 配在 `word` 格 `pptx` 下面，只写特点，名词短语 |
| `自检\n54/55 项通过` | 两行，数量带出处；"54/55"与"项"之间有空格 |
| `"value": "429", "label": "条测试用例"` | 量词放进标签开头，读成"429 条测试用例"；数字单独当画面 |

| 坏 | 问题 | 改成 |
|---|---|---|
| `每个数字都能指回材料，并附上出处。` | 说明句，带句号，17 字，超过 12 字 | `数字都标出处` |
| `一站式生成发布会总结图` | 宣传腔（词表里有"一站式"），动词开头 | `发布会总结图` |
| `写作规则十五\n条` | 第二行只剩一个字 | `写作规则\n15 条` |
| `物理17个技能` | 汉字和数字紧挨，没有空格，也没断行 | `物理\n17 个技能` |
| `n = 12 ，室温` | 全角逗号前多了一个空格；校验查不到这条 | `n = 12，室温` |
| `学习规划` | 分类名，读起来像菜单，不像一个功能 | `截止日倒排计划` |

## 英文：好例子与坏例子

| 好（本库自己的功能） | 好在哪里 |
|---|---|
| `Cinematic color grade` | 3 个词，名词短语，句首大写 |
| `Nine canvas ratios` | 数量写在词里，不加句号 |
| `Built-in self-check` | 2 个词，一行 |
| `Animated export in keynote-deck-builder` | "功能 in 应用"句式 |
| `Numbers traced to sources` | 4 个词，没有动词 |

| 坏 | 问题 | 改成 |
|---|---|---|
| `Every number points back to its source.` | 整句话，带句号 | `Numbers traced to sources` |
| `Automatically runs nineteen checks after each render finishes` | 8 个词，动词开头；`validate_spec` 报"超过 7 个" | `Built-in self-check` |
| `Nine Canvas Ratios` | 每个词都大写 | `Nine canvas ratios` |
| `Best-ever cinematic color grade` | 普通格用了最高级 | `Cinematic color grade` |
| `Over 60 skills` | 数字取了整，对不上材料里的 63 | `stat` 格：`"value": "63"`，标签 `Skills`，`facts` 写出处 |

## AI 腔检查

词表是 keynote-deck-builder 那份，一行一个词：`../../keynote-deck-builder/references/ai-tone-words.txt`（相对本文件所在的 `references/` 目录）。写完标签，在仓库根目录跑：

```bash
grep -nFf skills/coding-helper/keynote-deck-builder/references/ai-tone-words.txt <file>
```

`<file>` 换成 `bento.json` 或交付说明。每条命中过一遍删词测试：把词删掉，或换成一句大白话，句子少了具体信息吗？没少，就是 AI 腔，换成能被检验的东西，如一个数或一个动作；少了，是术语或本义，照用。词表只有中文，英文标签用同一个测试自查。
