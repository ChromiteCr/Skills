## 1. 十三辙 / Rhyme groups

中文歌词押的是**辙**，不是拼音全等。"光 / 长 / 上 / 亮 / 望 / 想 / 唱"同属江阳辙，全部互押。

| 辙 | 韵母 | 例字 | 音色 | 拖长时 |
|---|---|---|---|---|
| 江阳 | ang iang uang | 光 长 想 唱 | 最响亮 | 好，副歌首选 |
| 中东 | eng ing ong iong | 风 梦 中 空 | 响亮偏后 | 好 |
| 言前 | an ian uan üan | 天 看 远 暖 | 开口+鼻收 | 好，最好用 |
| 发花 | a ia ua | 家 花 大 啊 | 最开最亮 | 好，高音位首选 |
| 遥条 | ao iao | 好 少 笑 早 | 开口收圆 | 好 |
| 怀来 | ai uai | 来 海 白 在 | 开亮 | 好 |
| 由求 | ou iu | 走 手 留 够 | 中等收圆 | 尚可 |
| 灰堆 | ei ui | 谁 泪 飞 会 | 中亮 | 尚可 |
| 梭波 | e o uo | 歌 我 火 落 | 中性偏暗 | 尚可 |
| 乜斜 | ie üe | 些 夜 月 别 | 窄亮 | 一般 |
| 人辰 | en in un ün | 心 人 春 深 | 窄+鼻收 | 差，长音发闷 |
| 姑苏 | u | 路 苦 住 哭 | 暗 | 差 |
| 一七 | i ü er | 你 去 日 里 | 最窄 | 最差 |

用法：

- **一个段落一个辙**。换段落可以换辙，换辙本身就是情绪转折的信号，别浪费
- **副歌用开口辙**（江阳 / 发花 / 遥条 / 怀来 / 言前）。副歌押一七辙或姑苏辙，唱到高音会挤住
- 押韵位置 = 每行末字。行内有停顿时，停顿前那个字押不押都行，押了更紧，全押会显得刻意
- **宁可空一行不押，也不要倒装凑韵**。语序被扭到"心中的伤痛渐渐地被抚平"那一刻，AI 味就出来了。
  真押不上就换整句的说法，或者接受这一行不押
- 相邻两行末字不要用同一个字，也不要用同一个双字词的两半

## 2. 陈词黑名单 / Cliché list

疗愈、励志、青春题材的高危词。**不是绝对禁用，是浓度控制**：

- 一个段落里出现 ≥2 个 → 这段已经滑向套话，重写
- hook 里出现 ≥1 个 → 这个 hook 基本等于没有，换
- 全篇抽象情绪词（下面第二、三组）超过 5 个 → 整首在讲道理，不在讲事

**意象组**：星光 月光 阳光 光芒 微风 晚风 海洋 彼岸 远方 天堂 翅膀 花开 岁月 时光 泪光 伤疤 港湾 灯火 荆棘 迷雾 黑夜 黎明 星辰 大海

**情绪组**：治愈 温柔 拥抱 绽放 闪耀 璀璨 勇敢 坚强 迷茫 彷徨 释怀 沉淀 救赎 破碎 蜕变 煎熬 疲惫 不安

**句式组**：所有的X都会Y / 总有一天 / 不必X / 不用X / 你值得 / 慢慢来 / 别害怕 / 你本来的样子 / 终会 / 终将 / 这就是最好的 / 请相信 / 会好的

替换策略只有一条：**把抽象换成能拍下来的东西**。

| 套话 | 换成 |
|---|---|
| 心里藏着好多疲惫 | 洗到第三遍那只碗还在手里 |
| 所有煎熬都会过去 | 那条消息我看了六遍没回 |
| 温柔治愈所有不安 | 楼下面馆的灯还亮着 |
| 你已经很勇敢 | 你今天出门了 |

判据：这一句能不能拍成一个镜头？拍不了就是在讲道理。

## 3. 可唱性 / Singability

词是给人唱的，不是给人读的。终稿必须过这一节。

- **长音位用开口音**。长音位 = 每行末字、行内停顿前那个字。开口音见第 1 节前六个辙。
  长音落在 i / ü / u 上，歌手会自动改口型，听起来像另一个字
- **一字一音**。字数模板就是节拍数，一个字对一个音符。想在一拍塞两个字就是字数超了
- **句末避开连续四声**。连着三个去声收尾，整句往下掉，情绪跟着垮
- **避免同声母连缀**。"时时是事实"这种在唱速下会糊成一团
- **鼻音收尾别拖太长**。-n / -ng 结尾的字拖满两拍会变成哼鸣，短促句尾没问题
- **换气**：停顿处就是换气点。两个换气点之间超过 12 个字，唱的人接不上
- **三遍读法**：默读（看字数）→ 出声读（听拗口）→ 按拍子拍手读（找卡壳）。
  拍手读卡住的地方，九成是字数错了或断句错了

## 4. 字数模板怎么读 / Reading the `xxx` template

用户给的模板长这样：

```
主
xxxxxxxxxx
xxxxxxxxxx
xxxxxx
xxxxxxxxx

预副
xxxxxxxx
xxxxx xxxxx
```

规则：

- **一个 `x` = 一个汉字 = 一个音节 = 一个节拍位**
- **空格 = 停顿 / 换气 / 分句**。`xxxxx xxxxx` 是"五字，停，五字"，不是十字一口气
- **空行 = 段落分隔**，段落名写在段首
- **"细微变动"= ±1 字**。但同一段落里位置相同的行必须保持同长，
  因为它们对应的是旋律里重复的那一句；改了就对不上
- 模板本身携带信息：行长递减 = 情绪收紧（预副常见），行长突然变短 = 落点，
  最后一行短于其他行 = 收束

如果用户只给了模板没给段落名，按行数和长度推断段落功能，推断结果要说出来让他确认，不要默认。
