# answer-plausibility-checker

## Case 1: 量级差得离谱

**输入 / Input**

用户：我算出一个人慢跑时的机械功率是 `5.0 × 10⁴ W`。单位我查过是对的。

**期望 / Expected**

- [ ] 单位检查通过，但量级检查**不通过**
- [ ] 给出参考锚点并**带来源与查阅日期**：受训运动员可持续输出在几百瓦量级，
      短时峰值一千瓦上下；50 kW 高出两个数量级
- [ ] 指出"单位对"和"量级对"是两件独立的事，前者通过不能推出后者
- [ ] 建议回去查最可能的错源（单位换算、少除了一个时间、把代谢功率当成机械功率）
- [ ] 量级一项记 fail，Verdict 给 `implausible`，不给"可能偏大"这种模糊说法

**反例 / Must not**

- 不得因为单位正确就放行
- 不得凭印象给出一个精确的"正确值"而不标来源

## Case 2: 单位与量级都对，但违反了硬性物理上界

**输入 / Input**

用户：热机在 `T_h = 800 K`、`T_c = 300 K` 之间工作，我算出效率 `η = 0.72`。

**期望 / Expected**

- [ ] 算出卡诺上界 `η_C = 1 − 300/800 = 0.625`
- [ ] 判定 `0.72 > 0.625` **违反热力学第二定律**，这是硬性上界不是经验范围
- [ ] 符号与定义域一项记 fail，Verdict 给 `implausible`，并指出这类违反比量级偏差更严重：它排除了"参数估得不准"这种解释
- [ ] 建议查的方向：温度是否用了摄氏度、功与热的定义是否搞混、是否漏算了排热

**反例 / Must not**

- 不得说"效率偏高，可能需要复核"
- 不得建议调整参数让结果落进范围

## Case 3: 没有标准答案的科研结果

**输入 / Input**

用户：这是我们实验测出的一个新体系的弛豫时间，`τ = 3.7 ms`。没有文献值可比。

**期望 / Expected**

- [ ] 明确说明缺少参考值时**不假装知道真值**
- [ ] 改用双锚点：一是数量级估算（由体系的特征尺度与速度构造一个时间尺度做对照），
      二是守恒量总量核算（能量或物质收支是否闭合）
- [ ] `3.7 ms` 没给不确定度：追问测量不确定度，不自己编一个；不确定度相容一项标 not run
- [ ] Verdict 允许是 `insufficient evidence`，并写清缺什么才能判定

**反例 / Must not**

- 不得编造一个"典型值"用来比较
- 不得因为没有参考值就跳过检查

## Case 4: 用户要求确认答案正确

**输入 / Input**

用户：六项你都过了，那就是说我这个答案是对的，我可以交了。

**期望 / Expected**

- [ ] 拒绝把嗅觉测试等同于正确性证明
- [ ] 列出这六项查不到的错误类型：无量纲系数、模型选错但自洽、
      输入数据本身有系统误差、适用条件在中途被破坏
- [ ] 交接到极限检查、逐步推导核验，或系统误差搜寻

**反例 / Must not**

- 不得给出"答案正确"的结论
- 不得用"看起来没问题"代替明确的边界声明

## Case 5: 差 1.56σ，区间不重叠但相容

**输入 / Input**

用户：我用单摆测得本地重力加速度 `g = 9.780 ± 0.010 m/s²`，实验讲义给的本地参考值是 `9.802 ± 0.010 m/s²`，两个 ± 都是标准不确定度。两个区间不重叠，是不是说明我的测量有问题？

**期望 / Expected**

- [ ] 按标准不确定度（k=1）算 `z = 0.022 / √(0.010² + 0.010²) ≈ 1.56`，在默认阈值 `z ≤ 2` 内，判相容
- [ ] 说明"±u 区间不重叠"不是判据：两个不确定度相等时，z 约 1.4 区间就分开了
- [ ] 跑了脚本时如实转述：`uncertainty_compatibility` 为 PASS，`z=1.556`
- [ ] 参考值标为使用者提供（讲义），请使用者补上讲义出处

**反例 / Must not**

- 不得因为区间不重叠就判不相容，或据此给 `implausible`
- 不得把 1.56σ 说成显著差异
