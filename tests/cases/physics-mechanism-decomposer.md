# physics-mechanism-decomposer

## Case 1: 旋转硬币的终止行为（IYPT 型）

**输入 / Input**

用户：硬币在桌面上旋转，快停时声音频率越来越高然后突然停止。是什么让它停下来的？
我能改变的：硬币的半径与厚度、桌面材质、环境气压。

**期望 / Expected**

- [ ] 现象陈述分三栏：可观测事实、待解释的部分、现象消失的边界
- [ ] 能量收支表列出储量（平动 + 转动动能、重力势能）与各条流出通道，
      **每一项都归到一条具体机制**；收支不闭合时指出还缺一条通道
- [ ] 候选机制至少覆盖：接触点滑动摩擦、滚动阻力、非弹性形变、
      空气黏性耗散、空气惯性阻力、声辐射
- [ ] 每条机制给出带指数的标度律，并标注来源档（推导 / 量纲 / 文献 / 猜测）
- [ ] 可分辨观测量一栏给出气压扫描，并**写清一个关键事实**：
      降低气压主要改变空气密度 `ρ`，而气体黏度 `μ` 在连续介质区与密度无关，
      所以气压扫描能分开惯性型与黏性型空气耗散，对固体接触耗散几乎没有影响；
      不写清这一点，实验结果会被误读成同时检验了两条机制
- [ ] 完备性自检四项都做，清单里至少有一条标为【猜测】的未定量机制

**反例 / Must not**

- 不得直接下结论说"就是空气黏性导致的"
- 不得把"欧拉盘效应"这种现象名当作机制
- 不得虚构文献结论或具体的实验数值

## Case 2: 用户已有一个解释，要求确认

**输入 / Input**

用户：我认为水滴在热锅上能存活很久是因为下面有一层蒸汽膜托着它。你确认一下对不对。

**期望 / Expected**

- [ ] 把使用者的解释作为候选之一进清单，**不给它特殊地位**
- [ ] 至少再列出其他候选（蒸发潜热带走的热、穿过蒸汽膜的导热、辐射、
      表面张力维持液滴形状、重力压扁、表面粗糙度与润湿）
- [ ] 指出"有一层蒸汽膜"是一个**待验证的机制**，不是已确认的事实；
      并给出能检验它的观测量
- [ ] 说明要确认它必须做量级比较，只说"合理"不算

**反例 / Must not**

- 不得回答"对的，就是这个原因"
- 不得因为使用者已有倾向就跳过其他候选

## Case 3: 两条机制只差一个系数，不算可分辨

**输入 / Input**

用户：我有两个模型，A 预测 `F = 0.5·ρU²A`，B 预测 `F = 1.2·ρU²A`。
我打算测一次力来判断是哪个。

**期望 / Expected**

- [ ] 判定两者**不可分辨**：结构相同（同样的指数、同样的变量依赖），只有前因子不同
- [ ] 说明前因子常有几倍的不确定度，可以被"调"掉，一次测量分不开
- [ ] 给出可能可分辨的方向：找一个两模型指数或符号不同的量，
      或找一个只有其中一个模型依赖的参数
- [ ] 若确实只差系数，如实说明这时该做的是精密标定而不是机制判别

**反例 / Must not**

- 不得建议"测一次看更接近哪个数"
- 不得把系数差异说成机制差异

## Case 4: 实验设计改动了三个参数

**输入 / Input**

用户：我想验证表面张力是主导机制，打算把水换成乙醇再看现象有没有变化。

**期望 / Expected**

- [ ] 指出换液体会同时改变 `σ`、`μ`、`ρ`（还有蒸气压与润湿性），
      **判据里的参数没有被独立改变**，结果无法归因
- [ ] 给出能相对独立调节的手法：低浓度表面活性剂主要降 `σ` 而 `μ` 几乎不动；
      甘油–水混合主要改 `μ` 而 `σ` 变化小；改环境气压主要改气体的 `ρ`
- [ ] 若确实改不动，说明改不动，并给出退而求其次的方案（同时测两个观测量做联合约束）
- [ ] 不把"换液体后现象变了"当作机制已确认

**反例 / Must not**

- 不得认可这个实验设计
- 不得替使用者编造乙醇与水的具体物性数值而不标来源与温度条件

## Case 5: 无执行能力

**输入 / Input**

宿主不支持代码执行，用户在消息里给了各机制的表达式。

**期望 / Expected**

- [ ] 手工完成同量纲检查，并把这一项标为**人工检查**而不是"已验证"
- [ ] 排序结论仍逐条给出比值与各量来源
- [ ] 不假装跑过 `dimcheck.py`
- [ ] 不因缺工具而省略可分辨观测量那一步
