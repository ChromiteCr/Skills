# problem-representation-scout

## Case 1: 绳突然绷直，能量算不平

**输入 / Input**

用户：小球用一根松弛的绳系在钉子上，自由下落一段后绳绷直，之后绕钉子摆动。
我从头到尾用机械能守恒，算出的最高点位置比实际高。

**期望 / Expected**

- [ ] 把过程切成三段：自由下落 → **冲量边界（绳绷直）** → 圆周运动
- [ ] 指出漏掉的是一个冲量边界，不是系数错了
- [ ] 说明冲量沿绳方向：沿绳的速度分量被抹掉，垂直分量保留，
      损失的动能是 `½m v_∥²`
- [ ] 衔接条件表填齐：位置连续、速度可突变、能量减少
- [ ] 每段配一个表示（自由落体段用 `v–t` 或能量；冲量段用冲量–动量表；摆动段用势能曲线）

**反例 / Must not**

- 不得给出最高点的具体角度或高度
- 不得建议"加一个修正系数"
- 不得跳过阶段划分直接推荐某个表示

## Case 2: 小球从光滑半球顶端滑下

**输入 / Input**

用户：小球从光滑半球顶端由静止滑下，求它离开球面的位置。我不知道该在哪儿列方程。

**期望 / Expected**

- [ ] 阶段边界识别为"接触断开"，判据是正压力 `N = 0`
- [ ] 明确指出**判据本身就是一个待解的子问题**，应单独列出而不是混在主线里
- [ ] 接触段配的表示是受力图（径向）+ 能量关系；脱离后配抛体
- [ ] 说明为什么要用能量关系：要求的量里不含时间

**反例 / Must not**

- 不得给出 `cosθ = 2/3`
- 不得把接触段与脱离后合成一段处理

## Case 3: 电路看不出串并联

**输入 / Input**

用户：这个电阻网络（惠斯通桥形状，五个电阻）我看不出哪些是串联哪些是并联，算不出等效电阻。

**期望 / Expected**

- [ ] 诊断为缺"等势点重画"这个表示
- [ ] 说明前提：无互感、准静态，否则重画不成立
- [ ] 指出桥式网络在**不平衡时无法化成纯串并联**，这时该换的是方法（节点电压 / 回路电流 / Δ–Y 变换）
      而不是继续找串并联
- [ ] 给出该标哪些等势点，图由使用者画

**反例 / Must not**

- 不得直接给出等效电阻的表达式或数值
- 不得替使用者画出重画后的电路

## Case 4: 用户要求把方程解出来

**输入 / Input**

用户：阶段我知道怎么分了，你直接帮我把每段的方程列出来解掉吧。

**期望 / Expected**

- [ ] 拒绝列完整方程组与求解
- [ ] 仍给出阶段表、衔接条件与每段"该问的第一个问题"
- [ ] 说明每段选定表示的理由（要求的量里不含什么）

**反例 / Must not**

- 不得以"示范一段"为名把某一段解完
- 不得给数值答案

## Case 5: 症状其实不是表示问题

**输入 / Input**

用户：我每一步都检查过，代数没错，但最后算出来的周期比实验值大了三个数量级。

**期望 / Expected**

- [ ] 诊断表命中"每一步都对，最后结果荒谬"这一行，判定**不是表示问题**
- [ ] 交接到 `dimensional-analysis-checker`（查量纲，确定性路径是 `_shared/scripts/dimcheck.py`）与 `limiting-case-validator`（查极限），两者都可用
- [ ] 不强行推荐一个表示来"试试看"

**反例 / Must not**

- 不得为了产出而随便推荐一个表示
- 不得把 `dimensional-analysis-checker` 或 `limiting-case-validator` 说成尚未建成，改给"暂时手工做"的替代路径

## Case 6: 打滑的球什么时候开始纯滚动

**输入 / Input**

用户：保龄球以速度 `v₀` 不转地扔到球道上，先打滑后纯滚动。我用 `|f| = μ_s N` 去求开始纯滚动的时刻，怎么也解不出来。

**期望 / Expected**

- [ ] 指出这是"滑 → 滚"边界，判据是接触点相对滑动速度 `v_cm − ωR` 降到 0，不是摩擦达到 `μ_s N`
- [ ] 说明滑动段的摩擦是动摩擦 `μ_k N`，大小不变，所以等不到"达到 `μ_s N`"那一刻
- [ ] 说明滑移速度归零之后，还要验算维持纯滚动所需的静摩擦 `f_req ≤ μ_s N`
- [ ] 把"滑移速度何时归零"单独列成一个待解的子问题，配冲量–动量或 `v–t` 表示

**反例 / Must not**

- 不得给出纯滚动开始的时刻或速度（如 `t = 2v₀/(7μ_k g)`、`v = 5v₀/7`）
- 不得认可"`|f|` 达到 `μ_s N`"作为滑 → 滚的判据
