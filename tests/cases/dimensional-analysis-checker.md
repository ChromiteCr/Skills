# dimensional-analysis-checker

## Case 1: 公式被写反了

**输入 / Input**

用户：弹簧振子的周期我推成了 `T = 2π√(k/m)`，`k` 是劲度系数，`m` 是质量。帮我看看。

**期望 / Expected**

- [ ] 建符号量纲表：`k` 是 `M T^-2`，`m` 是 `M`
- [ ] 指出 `√(k/m)` 的量纲是 `T^-1`，而左边是 `T`，等式两边不一致
- [ ] 明确指出第一处不一致出现在哪里，而不是笼统说"量纲不对"
- [ ] 结论标 `fail`

**反例 / Must not**

- 不得直接给出正确公式 `T = 2π√(m/k)` 当作答案交出（可以指出是分子分母的问题，改正由使用者做）
- 不得说"差不多，就是写反了"就跳过

## Case 2: 量纲通过但系数错了

**输入 / Input**

用户：小球在黏性流体里的终端速度我写成 `v_t = ρ_p g d²/(9μ)`。量纲对不对？

**期望 / Expected**

- [ ] 逐项算出 `ρ_p g d²/μ` 的量纲是 `L T^-1`，与速度一致，结论 `pass`
- [ ] **明确写出量纲检查查不了无量纲系数**——`9` 换成 `18` 或 `3` 量纲都一样
- [ ] 建议下一步用极限、已知特例或原始推导来定系数
- [ ] 物理含义审计：说出这一项代表重力驱动与黏性阻力的平衡

**反例 / Must not**

- 不得因为量纲通过就说公式正确
- 不得凭印象断言正确系数是多少而不说依据

## Case 3: 超越函数的宗量带量纲

**输入 / Input**

用户：我写了气压随高度的分布 `n = n₀·exp(−mgh/T)`，`T` 是绝对温度。

**期望 / Expected**

- [ ] 抓出 `exp()` 的宗量 `mgh/T` 量纲是 `M L² T^-2 K^-1`，不是无量纲
- [ ] 指出缺的是玻尔兹曼常数 `k_B`（`M L² T^-2 K^-1`），补上后宗量才无量纲
- [ ] 结论标 `fail`，并说明这类错误正是量纲检查最擅长抓的一类

**反例 / Must not**

- 不得放过带量纲的指数宗量
- 不得替使用者把整条分布律重推一遍

## Case 4: 无量纲化的表达式，记号不明

**输入 / Input**

用户：这是我无量纲化之后的方程 `∂u/∂t + u∂u/∂x = (1/Re)·∂²u/∂x²`，帮我查量纲。

**期望 / Expected**

- [ ] 识别出这是已无量纲化的形式，所有变量都应是无量纲的
- [ ] 在使用者未声明特征尺度与特征速度之前，结论标 `ambiguous` 而不是 `pass` 或 `fail`
- [ ] 请使用者补出无量纲化用的特征量，并说明为什么这决定了检查能不能做

**反例 / Must not**

- 不得默认一套特征量然后给出结论
- 不得把"看起来是标准的 Burgers 方程"当作已核对

## Case 5: 用户要求给推导盖章

**输入 / Input**

用户：量纲你查过了没问题，那就是说我这个推导是对的，你直接确认一下我好写进论文。

**期望 / Expected**

- [ ] 拒绝把量纲一致等同于推导正确，并说明量纲检查是最便宜的一关，不是充分条件
- [ ] 列出量纲查不到的几类错误：无量纲系数、符号、遗漏的无量纲函数、适用条件被破坏
- [ ] 交接到极限检查、逐步推导核验或与已知特例对照

**反例 / Must not**

- 不得因为使用者要求就给出"推导正确"的结论
- 不得含糊地说"应该没问题"
