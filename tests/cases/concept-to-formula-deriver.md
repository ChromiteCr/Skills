# concept-to-formula-deriver

## Case 1: 单摆周期这条公式从哪来

**输入 / Input**

用户：`T = 2π√(L/g)` 我背下来了，但说不出它为什么长这样。质量去哪了？

**期望 / Expected**

- [ ] 先固定目标与适用区间：小角度、无阻尼、点摆锤、绳不可伸长
- [ ] 起始原理选定并给理由（定轴转动方程或能量法都可以，但要说清为什么从这条起）
- [ ] 逐步给出 `mL²θ̈ = −mgL sinθ`，并**在这一步指出质量约掉**
- [ ] 说清质量约掉的物理原因：力矩里的是引力质量，转动惯量里的是惯性质量，两者相等
      （等效原理），所以才约得掉——这不是代数巧合
- [ ] 小角近似 `sinθ ≈ θ` 标在它真正被用到的那一步，不堆在开头；
      并给出相对误差 `θ²/6` 和周期的一阶修正 `T ≈ T₀(1 + θ₀²/16)`
- [ ] 终式可用 `scripts/compare_formula.py` 与标准式比对
- [ ] 结尾把"下一步由学习者做"的部分说清楚

**反例 / Must not**

- 不得把假设全部堆在开头再一路推到底
- 不得说"质量约掉了"而不解释为什么能约
- 不得把小角近似说成精确成立

## Case 2: 目标公式在用户说的区间里根本不成立

**输入 / Input**

用户：帮我从守恒律推出动能公式 `E_k = ½mv²`，我要用它算一个 `0.8c` 的粒子。

**期望 / Expected**

- [ ] 先做区间检查，指出 `β = 0.8` 时 `γ ≈ 1.67`，`½mv²` 在这里不适用
- [ ] 说明正确的形式是 `(γ−1)mc²`，并指出 `½mv²` 正是它在 `β ≪ 1` 时的首项
- [ ] 在低速区间内仍然可以完成原来的溯源，但必须把区间写在最前面
- [ ] 不因为用户点名了公式就跳过区间检查

**反例 / Must not**

- 不得直接推 `½mv²` 然后让用户拿去算 `0.8c`
- 不得使用"相对论质量"这一说法

## Case 3: 用户要的是作业推导本身

**输入 / Input**

用户：这是作业第 3 题，要求推导阻尼振子的位移解。你推完我抄一下。

**期望 / Expected**

- [ ] 拒绝产出可直接提交的完整推导
- [ ] 仍然可以做的：说清这条解从哪条方程来、为什么设指数形式的试解、
      三种阻尼情形由判别式的符号分开
- [ ] 明确划出交界：结构与理由可以给，代数由本人做
- [ ] 给出解完之后自查用什么（极限、量纲、`γ → 0` 是否回到简谐）

**反例 / Must not**

- 不得以"示例"名义把完整推导写出来
- 不得给出最终位移表达式

## Case 4: 终式与标准式比对

**输入 / Input**

用户推完得到 `T = 2π·(L/g)^(1/2)`，想确认和课本的 `2π√(L/g)` 是不是同一个。

**期望 / Expected**

- [ ] 用 `scripts/compare_formula.py --derived ... --reference ...` 做符号比对
- [ ] 报告等价，退出状态 0
- [ ] **同时说明符号等价不代表推导过程正确**——中间可能有两处错误互相抵消
- [ ] 没有执行能力时手工比对，并标为"人工检查"

**反例 / Must not**

- 不得因为终式对上了就说整个推导正确
- 不得假装跑过脚本
