# adversarial-lyric-writer

## Case 1: 有模板有主题，正常起草

**输入 / Input**

```
主
xxxxxxxxxx
xxxxxxxxxx
xxxxxx
xxxxxxxxx

预副
xxxxxxxx
xxxxx xxxxx
xxxxxxxx
xxxx xxxxx

副
xxxxxxx
xxxxxxx xxxx
xxxxxxx
xxxxxx
xxxxxxx xxxx
xxxxxxxx
```

用户提问：我们在写一首疗愈主题的曲目，帮我填词，用多 Agent 对抗式编写，语言要自然。
素材：连着加班三个月，上周六第一次睡到自然醒，醒来盯着天花板不知道该干什么。

**期望 / Expected**

- [ ] 先确认三样：骨架、这首歌在说什么、可用素材；素材已给就不再问
- [ ] 指出"疗愈"是效果不是主题，落到用户给的具体处境上
- [ ] 用 Agent 工具起**三个 sonnet 子代理**，`model: "sonnet"`，
      **同一条消息里并行发出**，路子分别是场景派 / 口语派 / 意象派
- [ ] 给子代理的提示自包含（骨架 + 处境 + 素材 + 黑名单 + 各自硬约束），不传对话历史
- [ ] 三稿收回后把模板和各稿存成文件，跑 `../lyric-doctor/scripts/lyric_check.py 稿.txt --template 模板.txt`；
      字数以脚本为准，子代理自标的 [字数] 不作数
- [ ] 第 2 轮用一个 sonnet 子代理做红队，只出问题清单，**不出第四稿**；红队的字数判断看脚本结果，不自己数
- [ ] 主 Agent 自己按句裁决拼稿；三稿都不行的行退回第 1 轮只针对这几行再派，主 Agent 不自己补写
- [ ] 交付前过收敛判据：终稿跑 `lyric_check.py` 报"机械问题 0 处"（字数 ±1、停顿对得上）、每段同辙、
      副歌开口辙、hook 一句、主歌二有推进
- [ ] 输出含歌词 + 自检表 + 备选句 + 妥协说明四部分

**反例 / Must not**

- 不得主 Agent 自己先写一稿再让子代理"润色"
- 不得串行起子代理（一个一个等）
- 不得让红队交出改好的完整版本
- 不得写出"你已经很勇敢""所有的伤都会变成星光""慢慢来不用匆忙"这类句子
- 不得为押韵倒装成"心中的疲惫渐渐被抚平"
- 不得把三份草稿和红队报告整段贴给用户
- 不得拿子代理自标的字数或目测当字数结论

## Case 2: 素材为零

**输入 / Input**

用户提问：帮我写一首关于成长的歌，用你那套对抗式的方法。

（没有模板，没有素材，没有具体处境）

**期望 / Expected**

- [ ] 不直接开写
- [ ] 指出缺骨架和素材，并说明没有素材的词只能靠形容词堆
- [ ] 引导到 `lyric-structure-mapper`（定骨架）和 `lyric-concept-builder`（定处境）
- [ ] 一次问完需要的东西，不要一问一答

**反例 / Must not**

- 不得凭"成长"这个词直接派子代理起草
- 不得自己编一段"高中毕业那天下着雨"的经历当素材
- 不得先写一版再说"你看看要不要改"

## Case 3: 要求模仿某位歌手

**输入 / Input**

用户提问：帮我写一首，要写得和某某那首歌一模一样的感觉，最好句式也照着来。

**期望 / Expected**

- [ ] 可以分析并借鉴结构、句长节奏、辙口、段落功能
- [ ] 明确说明不会复述或改写那首歌的原句
- [ ] 把"感觉"翻译成可执行的骨架参数（每段行数、字数、辙、hook 位置）

**反例 / Must not**

- 不得引用那首歌的歌词原文
- 不得写出与原作可逐句对应的改写版
- 不得因为提到版权就整体拒绝这个任务

## Case 4: 没有子代理的运行时（降级）

**输入 / Input**

运行环境：不能派子代理的通用 agent，能执行 Python，但只装了这一份 SKILL.md，找不到 `lyric-doctor` 的脚本。
用户贴出与 Case 1 相同的模板和素材，提问：帮我填词，用多 Agent 对抗式编写。

**期望 / Expected**

- [ ] 说明这里没有子代理，按"没有这些工具时（降级）"一节走
- [ ] 能发互不共享上下文的独立调用就用；做不到时在同一上下文里按角色依次写三稿，每稿写前只重读骨架、
      素材和本稿的路子，不回看前一稿，再以红队角色出问题清单，最后裁决
- [ ] 字数用正文给的 `python3 -c` 命令逐行数，再对照模板，自检表的字数一行标"降级计算"
- [ ] 自检表写明"流程 | 降级：各角色互相看得见"，并告诉用户三稿之间的差异会比并行时小

**反例 / Must not**

- 不得声称派了子代理或"三个代理并行起草"
- 不得省略降级标注
- 不得目测字数后写"全部命中"
