# symbolic-first-discipline-coach

## Case 1: 早代数字把"与质量无关"藏起来了

**输入 / Input**

用户：斜面上的滑块，`m = 2 kg`、`θ = 30°`、`μ = 0.2`、`g = 9.8`。我一开始就把数代进去，
算出 `a = 3.20 m/s²`。老师说我没看出重点，什么意思？

**期望 / Expected**

- [ ] 把符号保留到结构不再变化，得到 `a = g(sinθ − μcosθ)`
- [ ] 指出结构上的三件事：**质量完全不出现**；`g` 只是整体的比例因子；
      真正决定运动性质的是 `tanθ` 与 `μ` 的比较
- [ ] 指出 `sinθ − μcosθ = 0` 即 `tanθ = μ` 是滑不滑的临界条件，
      早代入数字之后这个条件就看不见了
- [ ] 并排给出两条路径的对照，说明代数字发生在哪一步开始丢信息
- [ ] 数值结果本身不重算、不代替使用者算

**反例 / Must not**

- 不得只说"应该先用符号"而不指出具体丢了什么
- 不得替使用者把数值答案重新算一遍

## Case 2: 两个参数只以组合形式出现

**输入 / Input**

用户：RC 电路放电，我想知道 `R` 和 `C` 各自怎么影响波形，所以分别扫描了两个参数。

**期望 / Expected**

- [ ] 指出符号解里 `R` 与 `C` 只以乘积 `RC` 出现，`R` 和 `C` 各自没有独立效应
- [ ] 说明这意味着参数空间实际上是一维的：**独立自由度比表面上少一个**
- [ ] 建议把扫描改成扫 `RC`，把时间无量纲化成 `t/(RC)`，两条曲线会重合
- [ ] 指出如果实验数据里 `R` 和 `C` 表现出独立效应，说明模型漏了物理
      （例如电阻的温度系数、电容的介质损耗）

**反例 / Must not**

- 不得建议继续分别扫描
- 不得断言实验一定会重合（那是待检验的预言）

## Case 3: 这时候确实该代数字了

**输入 / Input**

用户：我在解 `tan(x) = x/(1 − a·x²)`，符号一直保留，卡了两小时。

**期望 / Expected**

- [ ] 判定这是超越方程，**一般没有闭式解**，继续保留符号没有收益
- [ ] 说清"符号优先"的边界：符号做到结构不再变化为止，不是做到底
- [ ] 建议先无量纲化把参数数目降到最少，再对剩下的无量纲组做数值求解或渐近展开
- [ ] 指出即使数值求解，仍应报告解对无量纲组的依赖，而不是一个孤立的数

**反例 / Must not**

- 不得坚持"必须一直用符号"
- 不得替使用者解这个方程

## Case 4: 用户要求直接给数值答案

**输入 / Input**

用户：别讲结构了，我就要那个数，你直接算。

**期望 / Expected**

- [ ] 说明本 skill 的产物是结构对照，不是数值结果
- [ ] 仍然交付符号形式与它暴露出的结构
- [ ] 指出拿到符号形式之后代数字是一步的事，由使用者完成

**反例 / Must not**

- 不得为迎合而给出数值答案
- 不得因为边界不符就不产出符号对照
