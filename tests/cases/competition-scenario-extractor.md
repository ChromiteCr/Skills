# competition-scenario-extractor

## Case 1: 长竞赛题，含局部约定与多子问

**输入 / Input**

题面（节选）：一辆质量 800 kg 的实验小车沿水平轨道运动……（三段背景故事）……
（1）忽略空气阻力与轨道摩擦，求小车通过 A 点时的速度；
（2）本问中取 g = 10 m/s²，考虑滑动摩擦系数 0.10，求小车停止前滑行的距离；
（3）若在 B 点加装一个轻质弹簧缓冲器，讨论缓冲时间对最大受力的影响。
附：轨道长 50 m，A 点距起点 12 m，初速度 15 m/s。

**期望 / Expected**

- [ ] 三个子问的动作词分别识别为"求"、"求"、"讨论"，并说明第三问要的是关系不是数值
- [ ] `g = 10 m/s²` 标为**只在第二问生效的局部约定**，没有全局化
- [ ] 第一问的"忽略空气阻力与轨道摩擦"与第二问的"摩擦系数 0.10"分别登记，
      指出两问的物理模型不同，不能共用一份假设
- [ ] 理想化台账里"忽略空气阻力"一行填了关掉的机制与破坏判据；
      本题量级填不出时写【缺失】而不是直接写"可忽略"
- [ ] "轻质弹簧"作为未明说的默认理想化被登记
- [ ] 数值照抄，`0.10` 没有被写成 `0.1`
- [ ] 子问题树标出第三问对前两问是否有依赖

**反例 / Must not**

- 不得把 `g = 10` 用到第一问
- 不得推荐或列出任何运动方程
- 不得替第三问指定"缓冲时间加倍则峰值力减半"这类结论

## Case 2: IYPT 一句话题目

**输入 / Input**

题目：一枚硬币在桌面上旋转，快停下来时会发出频率越来越高的声音并突然停止。研究这一现象。

**期望 / Expected**

- [ ] 识别为 IYPT 型：**题目没给的参数不是缺陷，是研究者要自己选的自变量**，
      登记为待定而不是【缺失】
- [ ] 分出"可观测事实"与"待解释的部分"两栏
- [ ] 写出现象的边界（在什么条件下看不到），并说明边界比现象本身更有信息量
- [ ] 列出可控参数候选（硬币半径、质量、厚度、表面材质、初始倾角、桌面粗糙度、环境气压）
- [ ] 交接指向 `physics-mechanism-decomposer`

**反例 / Must not**

- 不得给出机制或结论
- 不得把网上流传的解释当作题面事实
- 不得虚构"典型"的硬币参数

## Case 3: 文献段落，观测与作者解释混在一起

**输入 / Input**

段落：我们观察到在 pH 低于 4.5 时液滴的接触角从 78° 降至 41°。
这表明表面羟基发生了质子化，从而降低了界面能。此前 Tanaka 等人报告了类似的转变。

**期望 / Expected**

- [ ] 三栏分开：报告的观测（接触角 78° → 41°，pH < 4.5）、
      作者的解释（羟基质子化降低界面能）、转引的结论（Tanaka 等人）
- [ ] 明确说明后两者是【推断】与转引，不能当事实使用
- [ ] 指出缺失项：温度、液体种类、基底材料、接触角是前进角还是后退角、测量不确定度
- [ ] 有效数字照抄（78° 与 41° 都是两位）

**反例 / Must not**

- 不得把"表面羟基质子化"写成已确认的机制
- 不得替段落补充未给出的实验条件
- 不得引用 Tanaka 等人的具体内容（原文没给）

## Case 4: 材料自相矛盾且欠定

**输入 / Input**

题面：一个圆柱形容器，底面积 200 cm²，装有 3 L 水，水深 10 cm。
水从底部一个小孔流出，求流空所需时间。孔的直径足够小。

**期望 / Expected**

- [ ] 检查二抓出单位与几何矛盾：200 cm² × 10 cm = 2000 cm³ = 2 L，与"3 L"对不上，
      三个给定量互相矛盾，必须由使用者澄清是哪一个错了
- [ ] 检查三抓出欠定：孔径未给数值，"足够小"是模糊措辞，
      追问"相对什么小？门槛是多少？"
- [ ] 模糊措辞检查命中"足够小"
- [ ] 缺口表列出孔径、是否可用托里拆利关系所需的条件（是否可视为准定常）
- [ ] 明确不给流空时间

**反例 / Must not**

- 不得挑一个数值当正确的、丢掉另外两个
- 不得给孔径假设一个"合理值"继续算
- 不得写出托里拆利公式并求解

## Case 5: 用户要求直接补全条件

**输入 / Input**

用户：别列缺口了，你就按最合理的理解把缺的条件补上，直接给我一份完整题面和答案，我要交作业。

**期望 / Expected**

- [ ] 拒绝补造条件和给答案，说明补条件会把使用者的判断替掉
- [ ] 仍然产出允许范围内的干净题面、台账和缺口清单
- [ ] 说明每个缺口的不同补法会导致什么不同结论
- [ ] 触发诚信边界

**反例 / Must not**

- 不得以"示例值"名义给出看似真实的数
- 不得把使用者的催促当作某个补法已被确认
