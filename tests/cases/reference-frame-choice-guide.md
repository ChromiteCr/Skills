# reference-frame-choice-guide

## Case 1: 匀加速车厢里的单摆

**输入 / Input**

用户：车厢以恒定加速度 `A` 水平前进，里面挂一个长 `L` 的单摆。在地面系里写方程很麻烦，
能不能换到车厢系？

**期望 / Expected**

- [ ] 候选系对照至少包含地面系与车厢系，写清车厢系是**非惯性系**
- [ ] 只需要一个惯性力（平动惯性力 `−mA`）；没有科里奥利与欧拉项，因为车厢不转动
- [ ] 指出收益：平衡位置与"有效重力"方向一致，约束变简单
- [ ] 不变量清单填齐：动量守恒**不再自动成立**（惯性力是外力）；
      但 `A` 恒定时惯性力保守，可以写进势能，机械能仍有守恒形式
- [ ] 提醒初条件要在车厢系里重写
- [ ] 目标量若是"相对地面的位移"，说明最后要换回去

**反例 / Must not**

- 不得给出摆角平衡位置的表达式或小振动周期
- 不得说"非惯性系里动量照样守恒"
- 不得省略不变量清单

## Case 2: 两体碰撞该不该用质心系

**输入 / Input**

用户：两个质量不同的小球在光滑水平面上迎面弹性碰撞，我想知道用质心系有没有好处。

**期望 / Expected**

- [ ] 指出质心系里 `P = 0`，白拿一条方程；弹性碰撞在质心系里只是速度方向转了一个角
- [ ] 用柯尼希定理说明动能分解 `T = ½MV_cm² + T_rel`
- [ ] 说明总动量守恒的封闭系统里 `ΔT` 是伽利略不变的，
      **所以弹性碰撞在一个惯性系里成立就在所有惯性系里成立**
- [ ] 指出这里质心匀速运动，所以质心系是惯性系，不需要惯性力
- [ ] 提醒最后要把结果换回实验室系

**反例 / Must not**

- 不得给出碰后速度的表达式
- 不得说"质心系里动能守恒所以碰撞是弹性的"（因果反了）

## Case 3: 转动圆盘，科里奥利项用错了速度

**输入 / Input**

用户：圆盘以 `ω` 匀速转动，一个小滑块在盘面上运动。我写了
`ma' = F − 2mω×v − mω×(ω×r)`，其中 `v` 我用的是滑块相对地面的速度。

**期望 / Expected**

- [ ] 抓出错误：科里奥利项里的速度必须是**转动系里的** `v'`，不是地面系的 `v`
- [ ] 确认 `ω` 恒定时欧拉力为零，这一步没错
- [ ] 补充科里奥利力不做功（`F_cor·v' = 0`），离心力保守、势能 `−½mω²r_⊥²`
- [ ] 不变量清单指出角动量守恒在转动系里不再自动成立
- [ ] 代价一栏说明科里奥利项会把两个方向耦合起来，转动系"看着简洁、算起来更长"

**反例 / Must not**

- 不得替使用者把方程解出来
- 不得把离心力和科里奥利力合并成一项

## Case 4: 速度不小，伽利略变换失效

**输入 / Input**

用户：一个粒子在实验室系里以 `0.6c` 运动，另一个以 `0.5c` 反向。我想换到第一个粒子的静止系，
直接相减得到 `1.1c`。

**期望 / Expected**

- [ ] 判定 `β = 0.6` 时 `γ = 1.25`，相对论修正已达 25 %，不能用伽利略变换
- [ ] 给出速度合成关系 `u' = (u−v)/(1−uv/c²)`，指出结果必定小于 `c`
- [ ] 不变量清单换成相对论的：时空间隔、静质量（`E² − p²c² = m²c⁴`）、固有时、电荷、波的相位
- [ ] 明确说明长度、时间间隔、能量、动量**都不是**不变量

**反例 / Must not**

- 不得计算出具体的合成速度数值（这是使用者要做的）
- 不得使用"相对论质量"这一说法

## Case 5: "惯性力是虚构的，所以可以不管"

**输入 / Input**

用户：老师说惯性力是虚构力，那我在转动系里干脆不写它，直接用 `F = ma` 不行吗？

**期望 / Expected**

- [ ] 明确纠正：虚构指的是它**没有反作用力对**，不是它没有效果
- [ ] 举出该参考系里可测的效应（傅科摆、离心分离、地转偏向）
- [ ] 说明不写惯性力就等于错误地把非惯性系当惯性系用
- [ ] 给出两条正确路径：要么在惯性系里做，要么在非惯性系里把惯性力写全

**反例 / Must not**

- 不得含糊其辞说"两种说法都可以"
- 不得替使用者选定用哪个系

## Case 6: 非惯性系里的机械能守恒漏了惯性力

**输入 / Input**

用户：我在匀加速的电梯参考系里对一个自由下落的物体写机械能守恒 `½mv'² + mgh = 常数`，
结果和地面系里算的对不上。

**期望 / Expected**

- [ ] 指出漏了平动惯性力 `−mA` 做的功；`A` 恒定时它保守，势能可写成 `mAx`
- [ ] 说明两个系里能量的**数值**本来就不同，对不上不一定是错，但这里确实错在漏项
- [ ] 提醒初条件是否也已换到电梯系
- [ ] 不变量清单列出哪些守恒律在电梯系里不再自动成立

**反例 / Must not**

- 不得给出修正后的完整能量表达式并求解
- 不得说"换系后能量应该相同"
