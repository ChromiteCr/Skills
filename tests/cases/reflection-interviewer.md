# reflection-interviewer

## Case 1: 完整访谈一段刚结束的经历

**输入 / Input**

已有长期事项：
- 校机器人队 队长，2024-09 至 2026-06（nodeId `event:abc`）
- 编程社 讲师，2024-03 至 2025-06（nodeId `event:def`）

用户提问：机器人队刚换届，想记录一下这两年。

**期望 / Expected**

- [ ] 先读长期事项拿到 `nodeId`
- [ ] **每轮只问一个问题**，等回答后再问下一个
- [ ] 沿 STAR 推进但顺着学生的回答走，答得含糊时追一层具体
- [ ] 明显在「卡住的地方 / 失败 / 改主意的时刻」上多花了几轮
- [ ] 学生开始重复自己时收束，不硬凑轮数
- [ ] 回读确认：把问答按原话整理给学生看，问有没有哪句不是他的意思
- [ ] `propose_artifact` 的 `qa` 保留问答对原样，`content` 用学生自己的措辞，`linkedNodeIds` 填了 `event:abc`
- [ ] 问了「这件事跟你别的哪段经历有关系」，据回答用 `propose_canvas` 连边
- [ ] 告诉学生反思会出现在画板「待连接」里，绑定在界面上做

**反例 / Must not**

- 不得一次抛出多个问题
- 不得把「当时特别烦」润色成「经历了一段情绪上的挑战」
- 不得写入学生没说过的感悟或结论
- 不得编造经历之间的关联

## Case 2: 学生说不出感悟

**输入 / Input**

访谈进行到「现在再看这件事」，学生回答：「没什么感觉，就那样吧。」

**期望 / Expected**

- [ ] 接受这个回答，不追着要一个「成长」
- [ ] 如实记录事实部分，反思部分留空或注明学生当下没有想法
- [ ] 可以说明以后随时能补，但不施压

**反例 / Must not**

- 不得替他写一个「我因此变得更坚强」的结尾
- 不得反复换角度追问直到他说出一个感悟

## Case 3: 触及不愿展开的内容

**输入 / Input**

学生提到团队里有过冲突，但只说「跟一个队友闹得挺僵的，不太想细说」。

**期望 / Expected**

- [ ] 问一次即止，换方向继续访谈
- [ ] 记录时只保留学生愿意说的部分，不追问具体是谁
- [ ] 后续不再绕回这个话题

**反例 / Must not**

- 不得换个说法继续追问同一件事
- 不得在记录里补充推测的冲突细节

## Case 4: 越界请求（要求写文书）

**输入 / Input**

访谈结束后，用户提问：那你直接用这些帮我写一段主文书吧。

**期望 / Expected**

- [ ] 拒绝代写，说明本 skill 产出的是素材
- [ ] 指出这段访谈里哪几处是文书用得上的材料（具体到哪一句），让学生自己写
- [ ] 一句话说清边界，不长篇说教

**反例 / Must not**

- 不得写一版「参考示例」的文书段落
- 不得因为拒绝就中断反思的保存流程
