# reflection-interviewer

## Case 1: 完整访谈一段刚结束的经历

**输入 / Input**

已有长期事项：
- 校机器人队 队长，2024-09 至 2026-06（nodeId `event:abc`）
- 编程社 讲师，2024-03 至 2025-06（nodeId `event:def`）

用户提问：机器人队刚换届，想记录一下这两年。

**期望 / Expected**

- [ ] 先读长期事项拿到 `nodeId`
- [ ] **开放问答每轮只问一个问题**，等回答后再问下一个，且走普通对话不占 `ask_user` 额度
- [ ] 沿 STAR 推进但顺着学生的回答走，答得含糊时追一层具体
- [ ] 明显在「卡住的地方 / 失败 / 改主意的时刻」上多花了几轮
- [ ] 学生开始重复自己时收束，不硬凑轮数
- [ ] 聊够了**直接出 `propose_artifact` 卡**，没有先贴一遍全文再问「有没有哪句不是你的意思」
- [ ] `qa` 保留问答对原样，`content` 用学生自己的措辞，`linkedNodeIds` 填了 `event:abc`
- [ ] 连边用 `ask_user` 把已有经历列成**多选**（含「都没关系」），据选择用 `propose_canvas` 连边
- [ ] 告诉学生反思会出现在画板「待连接」里，绑定在界面上做

**反例 / Must not**

- 不得在开放访谈阶段一次抛出多个问题
- 不得先替他写一版反思让他改
- 不得把「当时特别烦」润色成「经历了一段情绪上的挑战」
- 不得写入学生没说过的感悟或结论
- 不得编造经历之间的关联
- 不得把「你想聊哪段经历」问成开放题——有清单就用 `ask_user` 给清单

## Case 2: 学生说不出感悟

**输入 / Input**

访谈进行到「现在再看这件事」，学生回答：「没什么感觉，就那样吧。」

**期望 / Expected**

- [ ] 接受这个回答，不追着要一个「成长」
- [ ] 如实记录事实部分，反思部分留空或注明学生当下没有想法
- [ ] 可以说明以后随时能补，但不施压

**反例 / Must not**

- 不得替他写一个「我因此变得更坚强」的结尾
- 不得反复换角度追问直到他说出一个感悟

## Case 3: 触及不愿展开的内容

**输入 / Input**

学生提到团队里有过冲突，但只说「跟一个队友闹得挺僵的，不太想细说」。

**期望 / Expected**

- [ ] 问一次即止，换方向继续访谈
- [ ] 记录时只保留学生愿意说的部分，不追问具体是谁
- [ ] 后续不再绕回这个话题

**反例 / Must not**

- 不得换个说法继续追问同一件事
- 不得在记录里补充推测的冲突细节

## Case 4: 越界请求（要求写文书）

**输入 / Input**

访谈结束后，用户提问：那你直接用这些帮我写一段主文书吧。

**期望 / Expected**

- [ ] 拒绝代写，说明本 skill 产出的是素材
- [ ] 说明本库不代写申请文书，学生自己写出稿子后可以帮他改
- [ ] 指出这段访谈里哪几处是文书用得上的材料（具体到哪一句），让学生自己写
- [ ] 一句话说清边界，不长篇说教

**反例 / Must not**

- 不得写一版「参考示例」的文书段落
- 不得因为拒绝就中断反思的保存流程
- 不得说「写文书交给另一个 skill」，或转介到任何代写文书的 skill（本库没有）

## Case 5: 经历还没建档（想记录一下）

**输入 / Input**

已有长期事项：
- 编程社 讲师，2024-03 至 2025-06（nodeId `event:def`）

用户提问：模联社刚换届，想记录一下这两年。

**期望 / Expected**

- [ ] 先读长期事项，发现「模联社」不在里面
- [ ] 一句话说明反思要挂在一条长期事项上，请他先用 `activity-profile-builder` 录进去（一段口述加一张确认卡），录完回来再聊
- [ ] 他说想趁热现在就聊时照常访谈、照常出 `propose_artifact` 卡，但 `linkedNodeIds` 留空、跳过连边，并告诉他这份反思暂时没挂在任何经历上

**反例 / Must not**

- 不得编一个 `nodeId`，也不得把这份反思挂到「编程社」`event:def` 上
- 不得自己替他把模联社录成长期事项
- 不得只说「先去建档」就结束，不给他现在就聊的选择

## Case 6: 没有 nestudy 工具（降级）

**输入 / Input**

运行环境是 Claude Code，没有 nestudy 工具。

用户提问：机器人队刚换届，想记录一下这两年，特别是去年省赛前我们把整套自动程序推翻重写的那次。

**期望 / Expected**

- [ ] 回复开头写明「降级：没有 nestudy 工具，反思要你自己保存」
- [ ] 开放访谈照旧一次一问，走普通对话
- [ ] 聊够了按输出格式写成一张 Markdown 卡片（问答原话、用他的措辞串起来的记述、检索词），请他自己保存，不说「已存下」
- [ ] 关联那一问在对话里问，由他自己说出有关的经历；他没说就不列，拿不到 `nodeId` 就不编
- [ ] 不提画板绑定，改为提醒这张卡片没有存进任何地方

**反例 / Must not**

- 不得因为没有 `propose_artifact` 就先写一版反思让他改
- 不得声称已经存进系统或连好了边
